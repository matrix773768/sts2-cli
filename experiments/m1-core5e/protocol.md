# CORE-5E 冻结协议

高预算 5C V2 唯一续策。复用 5D 训练和开发轨迹。自然数据用于实际 C→C 的一步分布 TD 和真实终局 Monte Carlo。真实死亡保留单独概率原子；存活效用保持开战 HP 及最大 HP 语义。TD 移动存活原子的带符号净战损，向相邻非均匀中心按距离分配质量，尾端饱和质量单列。目标网络固定 V2。

公开挑选完整方案后，在该回合的公开手牌、历史、敌方状态和牌堆信念不变的条件下，对可交换未知抽牌堆重新排列。所有方案同一环境种子、同一后续 V2。配对根等权，使用预定数量的独立估计世界的算术平均和平方损失，保留平局。世界数由根的公开属性和分组决定，不能由估计世界的终局决定。采集目标为 128 个开放训练根和 48 个开发根；原始世界与产生候选的 V2 预测不作为独立估计目标。开发世界分成两半独立检查均值误差和排序一致性。其他随机源固定，报告适用范围及不完整根。

拟合对照为 MC + 条件配对和相同优化计划下的 MC/冻结 TD 混合 + 条件配对。两个训练臂分别按开发条件均值的均方误差选一个检查点，NLL 破同分。开发整战另取 12 族各三个新种子。V2 以第 0 轮参与；新模型须在开发条件均方误差上优于 V2、开发胜场不少于 V2 且配对整战效用为正才可被选。满足条件者按效用、条件误差排序。预先保留开发整战效用最高的训练臂作独立挑战者，即使选模保留 V2，也可量出一次真实更新的能力。若有被选新模型，以它为主挑战者。

正式面板 64 个新成分族各两个种子，共 128 根。在读取其终局之前锁定挑战者；同高预算直接比较。主升级条件为开发选中、128 对都有终局、按族配对整战效用 95% 自助区间下界大于零且胜场不减。V2 高低预算可在同根做成本能力对照。两场 5D 失胜只作开放诊断。预测器胜负、严重战损、覆盖、实际干预、端到端时长单列。后续不依确认结果重新调整模型。

## 实施细则和补充诊断

每个配对训练根通常分配 4 个世界，事前编号能被 4 整除且回合至少为 3 的根分配 8 个。开发根一律 8 个。缺少两条完整方案、公开实例不可交换或任何一侧未匹配真实后继的根整组退出拟合，归档保留尝试。生成方案时可以用 V2 分数，估计世界在选案后才进入环境，两臂各自重新执行同一前缀。每个世界的牌堆重排仅改变合法、可交换的未知尾牌；敌方和后续独立随机流固定。宿主没有将重排顺序传给搜索器。

以原训练根的采样方差选取 12 个不确定性高的比较，另在首批全零比较中按固定哈希选 4 个。每根另开 12 个独立种子作精度审计。它们的结果全部排除在训练及选模之外。正式比较以冻结 5C 宿主的逐根行为为准；对任一策略发生公开复放异常的根，在已归档的 5D 隔离修复宿主上对各臂一并复核，另报恢复后的敏感性分析。

同输入的代际保留试验使用 V2 一次搜索生成并结算完整菜单，用新权重批量重评。实际 V2 回合方案为当前 incumbent，其中有真实 G2 回退；仅当另一完整方案超过它 1 效用才换案。不完整的 incumbent 继续原部署行为。在开发整战上单列，由每个完整回合的 switch 记录区别于原有 G2 干预率。

## 数据与复现

| 文件 | 内容 |
|---|---|
| panel.gz | 预分配的训练、开发、选模和独立确认根。训练和开发根保存 5D 的来源文件组及原索引。 |
| worlds-*.gz | gzip JSONL，每根一行。public 和 law 标识公开条件，plans 保留完整后继 law、原始概率和先验 V2 评分。worlds 记录环境专用重排种子、同根两侧已执行动作、实际命中 C、终局 HP 与效用。 |
| audit12-*.gz | 高采样方差与全零对照的独立 12 世界复评。更早的 audit-train 空文件来自 JSON 列表与内存元组的比较错误，未进入任何统计。 |
| transitions.gz | gzip JSONL，利用 file、i、c_index 定位冻结 5D 的实际 C；next_turn、hp_delta、endpoint 表示相邻 C 或真正终局。 |
| fit.json、mc.pt、td.pt | 共同基线，第 1 至第 8 轮开发曲线和逐根预测，两个训练臂各自离线入围的权重。第 0 轮权重沿用 5A evidence/v2.pt。 |
| selection、confirm、repair、cost | gzip JSONL，以 family 和 seed 配对。repair 只在发生异常的并集上重跑各臂，主表保留原始行。 |
| known.json、native.gz | 两例历史根的跨模型评分和真实续战；成本样本与确认翻盘的原生合法动作、终局与检查状态。 |

训练时真实终局的存活净损失和冻结目标的存活分布均向相邻有符号中心插值；沿用独立死亡类别与开战效用。每轮随机遍历自然 C，另采少量实际到达的分支 C。各条件根每轮参与一次成对均方损失，归一化系数与分到哪个 minibatch 无关；两个训练臂使用同一随机流。验证和条件分支推理均关闭 dropout，目标 V2 全程冻结。

在有固定游戏、5C 战斗宿主、5D 复放诊断宿主、DC1 构筑库与历史模型的 Windows 工作区，可从仓库根执行以下命令，在全新目录重新生成面板、训练、确认和核验。全部冻结的来源及数据指纹见计算账本。

```powershell
python experiments/m1-core5e/reproduce5e.py logs/core5e-reproduction
```
