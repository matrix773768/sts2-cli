# CORE-5H 生产与训练协议

从 CORE 5G、INFRA 2A 冻结身份和原 H5 tactical32/V2 出发。以牌组无序成分排除 2A 历史索引、全部 train/dev/reserve 和 5G 确认集。先冻结 128 个新确认族、每族两个配对世界，再冻结至多 960 个开放来源族，每族一个自然种子。确认与开放互斥。开发整战沿用 5G 的 64 个自然开发世界，5G 确认不开作新确认。

四个独立 worker 各有 40 个预分配槽，按来源族索引模四分片。每五槽有一个代表槽；每种角色在槽序上事前指定约四分之一为开发。每族从开局执行原 V2，扫描实际公开决策。参考要闭合，公开牌袋有至少两类且无已知顶底。分歧槽取首个 V2 与 5G 长程 MC 实际选择不同程序、公开后继分布有区别的回合。代表槽的最低回合按族哈希取 1–4，取随后首个符合可比性的根；若两模型同选，按族随机取另一个完整合法程序与 V2 配对。代表槽是此可比较域内的样本。每族至多选一个根，锁定即退出自然扫描；严格拒绝保留在槽分母，不因观察终局重选。

两侧程序按原菜单、G2 参考、0 裕量、预算 32 选定。第一侧是长程 MC 改选或代表槽另案，第二侧是 V2 方案。沿用 INFRA-2A 的公开前缀恢复、checkpoint、世界重排、实际菜单及两种 law 绑定、终局检查和严格整根资格。四世界为一个已发布 worker 单元，先算原世界及四对，再绑定同方案另算四对。前两块全部通过才进入训练/开发，原世界单列。每五槽固定一个审计槽，另外初始八差值极差至少 40 的根进行四世界复评，独立种子、同方案。复评失败单独记账。复评与开发标签从不参与优化。原始回复保留在 CORE 的运行目录。

模型输入、自然分布投影、死亡原子和开战效用沿用 5G。所有新模型从 5G 长程 MC 的共享参数出发。新增残差层末级零初始化，起点分布相同。原池化、容量对照逐实体 MLP、四槽集合交互分别对照同数据的充分 MC 加 2A/H5 原条件均值及 2A 实达后缀监督；主动臂另加新训练族八世界完整方案差的均方损失，不按符号或已见效用筛样。等根抽样，不复制共享前缀。使用两个固定训练种子；以自然 NLL、效用误差、条件误差和新开发根的实测后悔选点，再用开发整战选代表种子。

独立确认比较冻结 V2、5G 长程 MC、池化决策模型与交互决策模型。两挑战者中开发综合分数优者为主检验，确认前记录。仅当主检验按构筑族重采样的配对效用差 95% 区间下界大于零、全尝试胜场及严格完成数均不少于 V2 时升级。其余臂为研究对照。

确认前按开发单臂成本估算剩余预算。四个主要策略都进入 128 族确认；若仍在约 120 worker 分钟内，依次增加原池化无主动、交互无主动和容量匹配的逐实体主动对照。此顺序仅由实验问题决定。开发排序权重为自然 NLL 20%、原条件误差 10%、新开发根选择后悔 25%、共同终局配对效用 25%、全尝试胜数及严格完成数各 10%。同分优先名称排序。每种结构都保留两种子的完整拟合结果。
