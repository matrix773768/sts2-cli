# Predeclared matrix

Two fixed Q3 roots. Each root runs A stock, B one-time intervention, C repeated guard. Two independent process repetitions per arm. No additional candidate combinations.

- Regent Decimillipede B: on the first stock decision to play THE_GAMBIT, rank the remaining current legal moves with the unchanged stock scorer, allowing EndTurn. C uses the same exclusion on every such decision, treating commitment for an unfinished fight as unsafe.
- Defect The Insatiable B: at the first legal FRANTIC_ESCAPE with an active positive Sandpit stack count, play the first such instance in native option order. C uses that priority whenever the public active stack count is 1 or 2.
- Rebuild from the same fixture in each process and verify the unmodified prefix from the root. Divergent branches may consume RNG differently after intervention.
- Limits: 140 actions or 20 seconds in the combat loop, 3 seconds per action, 28 seconds per process, 180 seconds per matrix, 256 MiB managed heap per process. Repetitions do not count as independent counterfactual routes.
