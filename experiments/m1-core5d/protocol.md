# CORE-5D 数据与决策协议

主确认先固定 48 个新牌组、每族两个独立种子。主比较为 V3 高档减冻结 5C V2 高档，96 对全部解决、族配对效用 95% 自助区间下界大于零且胜场不减少才推荐代际升级。低档沿用同一公开转移、完整补全和执行接口，比较低档 V2/V3 与高档 V2/V3。冻结 5C V1、5B 高档、G2、G2-search 同根评价。历史确认族仅用于排除重复牌组。主面板终局不参与超参和选模。

256 个开放训练供体各产生一个新的自然世界，24 个不同开发族用于配对排序与校准，另 12 个开发族各两个种子用于比较两个候选检查点的实际整战效用。所有自然标签的续策固定为 5C 高档 V2。只记录真实执行到达的 C 与原始终局，截断、错误单列。对合法替换一个完整回合后的状态也恢复同一高档 V2。G2 是公开比较参考和策略回退动作，单独运行的 G2 战斗只进入能力对照。

探索在预分配的回合附近选择，依据完整方案的公开资源差异、预测效用接近程度及首动作层次选取，允许同首动作的不同后续和未触发干预的根。训练共用自然根的实际前缀与未知实现，不能用真实后继选择动作。保存原始后继概率、C 或终局效用、实际匹配分支、配对终局。每一侧只有实际 C 有分布标签，多后继方案只在方案层面计算期望差监督。共同死亡、效用相同及缺失的比较分别计数。局部教师诊断另外在开发开局固定公开手牌、信念和遭遇条件，独立重排未观察的尾牌，同一世界内两方案共用条件，第一组选择、第二组复核。诊断终局不用于拟合。

从 V2 初始化共享网络，约束自然分布漂移，同时拟合真实双 C 或带已知终局的方案差值。先按开发配对和自然分布指标筛选两个 epoch，再按开发整战效用、胜场、离线综合指标破同分。独立确认仅使用最终权重。所有时长按各 worker 的实测墙钟累计。

## 执行记录与数据字典

第一批训练和吞吐测量后追加同一 256 训练族各一个种子、同一 24 开发族各两个种子，冻结在 `augmentation.gz`。第二批训练世界仅贡献自然 C。两个入围权重均在 24 个选模世界全部完成才比较效用。低档在高、低代际比较前固定为图转移 192、结算 40、公开参考 160、扩展 10，两种首张牌优先于同牌多目标，保留四种补全风格，每风格的新增请求额度为 24/56/56/56。门控和合法执行与高档共用。

| 工件 | 存储与含义 |
|---|---|
| panel、augmentation | gzip JSON 对象。每个世界含 family、spec 和种子。确认去重忽略牌序和升级，训练与确认不共享基础牌组。 |
| train、train2、dev、dev2 | gzip JSONL，一行一场。states 为实际 C，trace 是公开决策的回合与动作位置，用于离线复建前缀。terminal 缺失的行不用于训练。 |
| pairs | gzip JSONL。plans 的四元组依次为后继类型、冻结编码哈希、已知终局效用、原始概率。C 的效用在读入模型时计算。每侧 outcomes 记录真实命中分支、动作和恢复续策后的终局。同一方案可有许多未走到的 C。 |
| teacher、reference | gzip JSON 数组，worlds 保存仅供环境复建的牌序及同世界两臂的真实终局。前两个世界用于诊断选案，后两个用于收益复核。reference 另记同动作回退根。 |
| confirm、selection、cost | gzip JSONL，一行一策略一世界。映射跨臂依靠 family、seed。queries 给出原始质量、调用、干预与执行结果。cost 对确认表中 16 个固定位置单独计时。 |
| progression、run、recovered | gzip JSON，原生运行命令、上个地图存档和实际资源。地图存档属于环境。relic-panel.json 给出到达每个开局的动作区间及准备分布权重。 |

在具备历史冻结游戏、模型、5A/5B/5C 宿主和 DC1 开放供体资产的环境，从仓库根运行以下命令，在新目录重建主学习与确认实验。训练复现保持分片数及遍历顺序。原生采集独立于该流程，可按归档命令重放，或用 progression5d.py 的单个变体以及起点和步长两个参数生成新路线。relics5d.py 构建分层索引和重载证据。历史采集器中两处动作字段兼容问题及修正后重跑分别保存在 run 与 recovered 文件。

```powershell
python experiments/m1-core5d/reproduce5d.py logs/core5d-reproduction
```
