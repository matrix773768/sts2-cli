# CORE-5A frozen protocol

Fit on the 408 open CORE-4 train families, two fresh seeds per family. Use 52 separate development families for epoch selection and an end-to-end comparator with optimizations disabled. Use 96 newly generated deck compositions and three fresh seeds each for independent five-arm confirmation. Reuse the DC1 deck generator and the legal act, encounter, HP and source strata of hash-selected training donors. Reject unordered deck compositions already in the DC1 family registry and within this panel. CORE-0 remains sealed. Family-cluster bootstrap with 10,000 resamples on common resolved worlds. Promote V2 only if the lower paired utility bound exceeds zero against G2, G2-search and repaired V1 and wins do not decrease against any of them. The historical V1 arm uses the CORE-4 host and interface.

Each trajectory records public C snapshots, root HP, terminal, family, world seed, policy and split. Only resolved main trajectories with the repaired, frozen V1 continuation enter distribution likelihood. Each even-index training family and each development family can supply one same-seed competing turn per world. Pick the eligible turn closest to turn 4, breaking ties by larger absolute predicted gap. Choose among covered rival first actions with a complete conditional turn or G2. Resume the same frozen V1 on both suffixes. Accept distinct post-turn double-C pairs for the CORE-4 regression loss. Evaluate the signed predicted preference on development worlds, separate from teacher construction and gradients. The pair outcome is a noisy single-world estimate. Opening seeds are simulation keys and never enter search.

Reuse the CORE-4 12-epoch update, development NLL selection, architecture and original +1 and complete-mass intervention rule for this comparison. The threshold can be revised in a separately frozen study. Unresolved runs remain visible without fabricated labels. Report search coverage per query, all-arm paired results by family, actual terminal HP and severe damage (death or loss of at least half the opening HP). Time full worker lifetime including host/model setup, search, environment and compressed data writing. Record both summed worker seconds and batch elapsed time.

## Conditional teacher and recorded fields

On development openings with a covered rival, keep the full public observation and belief equal and keep the encounter seed fixed. Independently permute the unseen tail four times. Compare both complete conditional plans with the same deck permutation and the same repaired V1 suffix. Choose the higher mean terminal utility on the first two worlds (ties retain V1), then measure the chosen switch relative to V1 on the last two. Variation is conditional on the opening and encounter RNG. These terminal outcomes are diagnostic and excluded from V2 fitting.

The primary V1 and V2 query fields describe the model-selected candidate and direct G2 reference. On a paired row, `skip` denotes the single altered turn, `gap` is predicted main minus alternative utility and `main_used` is the main row's intervention flag. The altered query retains the main comparison scores and mass; `used` and `result` describe execution. Join using family and seed. For G2-search, `plans/searches` measures action-level plan adoption. For the three complete-turn arms, `used/queries` measures turn-level adoption.

## Reproduction

Run from the repository root with Python, CPU PyTorch and the frozen local game/solver dependencies used by CORE-4. Build with `python experiments/m1-core5a/build_host.py logs/core5a-host3` in a fresh checkout with the CORE-2 build available. Run `python experiments/m1-core5a/study.py logs/new-core5a` to create a fresh run using the committed panel. Its evidence subdirectory contains the new training shards, fit and independent fights. The archived early development timing files predate prefix batching. Use `benchmark.py` for the controlled final-interface comparison. The benchmark, audit and teacher scripts each take one fresh output directory. Run the artifact tests with `python -m unittest discover -s experiments/m1-core5a`.
