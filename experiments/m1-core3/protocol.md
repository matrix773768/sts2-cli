# CORE-3 experiment protocol

Use open DC1 train roots, excluding every CORE-0 benchmark family. Group by the frozen DC1 family key before generating samples. Assign deterministic hash-ranked families modulo ten to eight train folds, one development fold and one independent confirmation fold. CORE-0 confirmation remains sealed. Use one greedy frozen G2 continuation. Store one fight per row, including caps/failures and terminal resources. Only resolved fights supply targets. A fight is the sampling unit for splitting, and uncertainty is clustered by family.

Train from scratch on death or signed winning net HP change from each observed pre-draw C. Compare a numeric baseline with an encoder of named mechanisms. Select epoch and encoder by development categorical NLL; confirmation is reported once. Deployment uses the selected model, direct payoff for a real terminal, and incomplete probability as unresolved. Count the cost from the common root to C exactly once.

For a bounded teacher audit take the first 12 development families in manifest order and the first 12 confirmation families for an independent single-turn deployment comparison. Freeze the public opening hand, condition fresh suffix permutations on it, and require the same public menu. Compare G2 with distinct executable complete-turn policies. Rank on selection worlds, evaluate on separate reference worlds under the same frozen continuation. Report unmatched roots and paired actual terminal utility; no promotion on prediction metrics alone. Positive deployment mean with a family-bootstrap 95% lower bound above zero is required to recommend an upgrade. No confirmation-based tuning.
