## 2. 保留并拓展 L0–L5 架构

| 层 | 稳定职责与下一阶段扩展 |
|---|---|
| L0 游戏执行 | 合法规则、环境隔离、状态复制、合法条件采样；从 INFRA 使用可靠原生或外部模拟器 |
| L1 战术搜索 | 公开完整回合图、条件程序、单动作和多回合搜索；允许精确与采样两种后继接口 |
| L2 状态表示 | 原始公开状态、规则共享、动态实体、牌区/信念、费用与触发生命周期、敌人相位；可扩展辅助结构特征 |
| L3 价值与策略 | 原 C 分布价值为基线；新增行动/候选引导、实体交互、多任务辅助、可选 B 或局外价值接口 |
| L4 执行与预算 | 合法菜单与观察绑定；搜索、模型及真实回退共同构成策略；选择性深度、昂贵教师及快速生产策略 |
| L5 经验与迭代 | 自然、反事实、搜索教师、真实后缀、独立验证；训练版本与部署版本分开，允许拒绝更新 |

M1-INFRA 贯穿 L0–L5，M1-RUN 在同一环境上消费战斗资源结果并回传局外价值。不要为新后端一次性重写全部策略或全规则目录。保持统一公开状态与真实资源边界，允许同一语义的不同物理实现。

### 2.1 战术边界和公平信息

- A：提交 EndTurn 的动作边，含已付资源、状态及见证。
- C：敌方行动及相应结算完成、下一回合初始抽牌前的战略状态，含已完成 setup 和待执行钩子。真实提前胜/负直接为终局，额外回合标注阶段。
- B：初始抽牌及结算之后的公开玩家决策；执行和重规划可在任一合法公开节点进行。
- R：回合内/结算中的一般随机事件。条件随机性由公开信念定义；未知机制显式记录。敌人行为按已知确定或条件规则处理，确有随机时合法采样/积分，不能假设与实际玩家行为无关的固定曲线。

引擎内部完整状态键用于私有缓存与恢复，公开键才用于公平决策。保留牌实例、已知顶底、未知多重集、动态资源、历史及必要信念；两个相同摘要但不同公开条件分布不能直接合并。禁止用私有牌序、真实未来 RNG 或私有句柄影响选择、预算和采样种子分配。

### 2.2 从精确回合图到合法采样搜索

机制压缩搜索（Mechanism-Compressed Search，MCS）作为长期战斗搜索方向，以价值函数统一评价战略结果，以机制知识压缩或重组合法搜索空间，以自主学习处理剩余复杂性。机制负责候选、依赖、等价证明及计算分配。沿用公开观察条件策略与 C/真终局评价；不另设抽象战略目标生成层，遍历方式及是否穷尽由规则支持和预算决定。

完整回合方案 μ 是关于未来公开观察的条件策略，不是提前知道抽牌后的单一序列。沿用冻结续策 π 的分布价值 Z，完整已知概率时按 `Σ pᵢ Z(Cᵢ)` 混合，真终局用实际值；期望效用由同一开战资源口径计算。

允许对合法公开条件世界采样 Cᵢ，估计 `Q(h,μ) ≈ (1/K) Σ V(Cᵢ)`，同时记录 K、采样协议、方差及失败。条件策略选案与独立评价世界隔离；不能对每个私有世界分别求最优知情动作再取平均充当 NOSL 策略。未解决概率质量不归一化为成功分布；采样失败不补死亡，估计精度与覆盖限制分别报告。精确图与采样搜索可混合：低分支、确定性机制精确处理，高复杂随机部分合法采样。

继承机制约简：弃牌无序多重集，普通纯攻/防按组合、目标与资源分配；同费用同目标同类效果采用有条件支配；力量/敏捷/易伤等效果在无冲突时优先于受益动作。只有实际触发、费用、遗物计数、实例、顺序或敌方条件相关时保留局部排列。对无中间决策及顺序敏感机制的多抽使用多重集概率；否则保留必要顺序。搜索启发式不等于全局最优证明；模型编码相同不证明底层状态等价。

## 3. 未来学习体系

### 3.1 价值学习

当前主要目标为固定续策下真实终局的死亡独立类别及胜局带符号剩余净战损分布。终局效用按冻结开战 HP、最大 HP 和已付资源计算，不重复计费；正常80 HP域历史胜利效用100减净损、死亡-50。回血允许负损失；截断和 unsupported 不作为死亡类别。新增药水、金币、永久成长及局外条件时，保留完整真实资源账本，再以 RUN 的实际收益决定新目标，不能未经论证更改历史效用。

自然 MC 标签来自实际到达 C 和真实续策终局。TD 用实际 C→C 的 HP 差平移存活分布、死亡原子保持、非均匀桶投影；终局使用真实标签。固定 V2 bootstrap 对 H5 续策有近似偏差，后续比较同目标续策的目标网络、多步 TD 或 MC 混合，而不是永久使用旧 V2 先验。独立研究初始化、网络容量、优化强度与数据规模；5G 从头训练已具备可用性证据，但未取得整战优势。

### 3.2 策略学习与搜索教师

真正的策略迭代不仅学习 Z，还需产生可比于当前实际策略的改进。针对同一公开根生成当前部署完整方案和有意义替代方案，固定后续策略，使用共同条件世界得到真实效用差，优先学习可兑现的决策。分歧样本可以增加信息量，但与代表性随机根分层统计。以期望差、实际选择后悔值及改选收益为主要监督，不将单世界符号、有限全零或共同死亡误判为真实偏好。

新增自有策略网络，初期用于首动作、合法候选、完整方案或搜索优先级。标签可以来自已验证搜索教师的分布/排序、真实探索与回报；教师选择和收益复评独立。允许以 G2 初始化/回退作为现有项目内部资产，但不把复制 G2 视为最终目标。对同一状态，保留合法动作掩码和公开历史；无需将随机后续程序编码成知道未来的固定动作串。

目标是逐步形成：冻结当前策略 → 搜索/主动探索 → 真实经验与独立教师收益 → 更新策略和价值 → 同成本及能力验收 → 发布新策略。候选策略未优于旧策略时允许回退。可研究 Expert Iteration、策略梯度/PPO 或其他算法，但不预设某种方法必然优越。离策略数据需明确目标续策及修正或条件化；不同模型标签不能无条件混合。

## 5. 实验协议与经验生产需求

主自然规模曲线沿用 INFRA-2A 的 `primary_rank`，前945族保留5F顺序，主4096族及开发275族固定。H5/2A同续策自然可合并；条件训练166根、开发51根，主重排世界868对及原世界217对，另32根各4对独立复评。主/复评/原世界保留身份，按构筑族分区；合法条件根可来自失败自然前缀，不自动删除。独立复评可量化噪声，但训练分区的复评若纳入拟合须事前定义。真实后缀 C/终局标签只赋予实际到达状态，避免重复前缀和将所有分支当作独立自然战斗。

主动新增需求由实际学习瓶颈决定，而非默认继续扩容。每项交接写明目标续策、构筑和章节分布、候选产生规则、复评次数、预计准入、成本和停止条件。向 INFRA 申请大批自然或教师数据前，先用现有数据证明值得扩大，或说明规模曲线尚未达到有效区间。真实跑局开始后增加真实构筑分布，并保留原合成域控制变量。

主能力比较使用新构筑族和配对种子、相同后端搜索和模型预算。不同完整率按全尝试和共同完成两种口径同时报告；同族重采样，不以相邻 C 代替独立样本。NLL、校准、条件差与选择后悔值解释决策误差，但不能替代能力验收。保留高预算教师、低成本行为策略、无搜索/轻搜索等清晰对照。不要从跨分布的胜场变化推出代际单调增长。
