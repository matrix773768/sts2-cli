# M1-LS1 学习驱动战斗搜索闭环

## 接入点与信息边界

F3B C 的 `RouteSearch.Routes` 建立 FIFO，依次放入 Q1、AGGRO、DEFENSIVE、ENGINE。完整胜路触发提前返回。路线死亡时，现有诊断按锚点追加最多四类修复，初始战略已在队首。根节点的菜单与同一节点的观察会缓存。修复可以复用保留的预测前缀。同一初始战略的 Replay 会重新执行，即使前缀动作与另一战略相同。总转移上限按实际 `Advance → Step → CombatBeamSolver.Replay` 调用扣除，另外有 48 动作、12 秒热搜索和 448 MiB 峰值工作集限制。有限预算和提前返回让初始顺序真实影响成本和已运行的路线。

LS1 的独立宿主通过 [构建脚本](../experiments/m1-ls1/build.py) 给 F3B C 注入四个固定候选的严格排列。候选定义、出牌与选择语义、修复规则继续来自冻结代码。无排列覆盖时走原分支。F4 接收首胜动作和每步预测摘要，从同一个冻结入场根按合法菜单重新执行。完整重建成功后，F4 用剩余预算尝试局部改进，在同药水槽条件下按最高 HP、最早发现选定结果。LS1 沿用 B1B 的资源字段和 E3F 实装版本绑定。每根在新的原生进程加载，各对照组共用只读根，逐 RPC 核对原生审计和预测根稳定性。生产默认 F3B C/F4 无源文件改动。 [F3B C](../experiments/m1-f3b/RouteSearch.cs) · [F4](../experiments/m1-f4/QualitySearch.cs) · [B1B](../experiments/m1-b1b/run_probe.py)

学习器读取原生 `combat_play` Observation 的白名单字段。手牌使用可见牌、费用、类型和可出牌状态，卡组使用 N2E 的无序多重集，敌人使用当前显示的 HP、格挡、Power 和来袭。遗物及药水 ID 与当前公开菜单交叉核对。排序发生在第一次预测搜索之前。根摘要、种子、精确续体、牌堆次序、未揭示敌招、任何搜索产生的未来状态均在学习张量之外。原生公开菜单构建与 N2A.1 受限预览各有来源，LS1 只在入场排序，当前手牌的 N2A.1 专用动态伤害预览未输入模型。 [N2A.1](../experiments/m1-n2a1/PublicInteraction.cs) · [N2E](m1-n2e-shared-card-semantics.md)

**全部本轮路线属于研究侧预测搜索。** F3B/F4 的后端仍从精确私有根建分支。其后续菜单、锚点、实际抽牌和分支结局可受隐藏 RNG 影响。要取得正常 SL 资格，需要当前节点专用的试探／重载接口、带实际揭示时间与试探来源的公开历史、阻止策略与候选生成从未揭示状态取值的能力边界，以及正式预算下的端到端原生重放与资源核验。E3F 修复覆盖已知的猎杀者致死终局差分。敌方侧终局差分仍需审计，EndTurn 胜路保留对应风险标记。

## 经验合同、采样与训练

[搜索经验 schema](../experiments/m1-ls1/experience.schema.json) 以根 × 搜索调用为记录单位。公开输入、候选轨迹、锁定资源、版本和审计各有具体字段。候选记录启动时的剩余 Replay 上限、实际转移、终止类别和首胜成本。恢复阶段只记录根和命令故障时，没有候选标签。单条策略死亡、动作截断、转移耗尽、墙钟／内存中止、不支持、验证失败及低 HP 分别可判读。没有任何穷尽证明，因此本实验无“战斗已证不可胜”标签。所有已执行战略共享所属战斗根，报告分母是根数。

原始宿主先冻结四个试跑根的 12 个 F3B C/F4 单元。新宿主关闭学习后逐项匹配候选序列、分支结局、成本、路线摘要和锁定资源。两阶段采样固定一个 worker，记录阶段墙钟上限及转移预约。正式试验有 48 个训练根、12 个选模根、24 个独立合成报告根、2 个来自同一 F3A 辅助局史的可达开发根及 8 个反馈根。合成构筑覆盖铁甲战士的力量、多段攻击及攻防／抽牌，以及静默猎手的小刀生成、准确和敏捷。入场 HP 30–64，遗物和持有药水随根变化，主动药水关闭。训练与选模使用 BOWLBUGS_WEAK 和 CHOMPERS_NORMAL，报告额外留出 TUNNELER_WEAK 和 EXOSKELETONS_WEAK。按核心配方家族、去升级的完整配方、共享局史、种子和配对块核验隔离。封存测试集未读取。合成根的自然可达性标为未知。两条既有 F3A 根单列，局史样本量为 1。 [冻结基线](../experiments/m1-ls1/baseline.json) · [协议](../experiments/m1-ls1/protocol.json) · [根清单与版本](../experiments/m1-ls1/evidence/contract.json)

训练和选模在每根分别运行四个原战略，单候选最多 48 次首胜 Replay，关闭修复，只给完整胜路付费重建。有限预算死亡、行动截断和转移截断的效用为 0。验证胜路的效用为 0.70 + 0.18 × 锁定 HP 比例 + 0.12 × 未使用的候选预算比例。不支持、墙钟和内存截断、验证失败及已知终局差分排除在拟合外。两种学习模型共享 128 维逐卡编码宽度、12 维逐卡隐层、均值汇聚、12 维联合隐层和 Sigmoid 头。身份模型使用卡牌 ID 与升级，机制模型使用 N2E 有序效果节点以及卡牌属性。每种均固定三个初始化，Adam 学习 30、60 和 90 轮，按选模效用 MSE 选冻结轮次。人工统计使用来袭压力、攻击、格挡、成长与生成计数确定顺序。分数相同时保留原顺序。 [模型与特征](../experiments/m1-ls1/model.py)

## 独立搜索结果

比较三档总 Replay 预算 64／128／256。每档最多先用一半做 F3B 首胜搜索。另一半保证可以付费重建完整首胜，F4 使用剩余预算，实际未用的转移据实记录。合格门槛为完整预测胜路、每步成功重建、正 HP 与既定药水规则。总搜索墙钟包含搜索 RPC、F4 重建和改进，以及模型实际公开特征准备和推理。建根和额外审计 RPC 单列。首胜墙钟包含实际首胜 RPC 与推理。另有首胜锁定耗时估计，在首胜墙钟上加 F4 完成 incumbent 重建的热耗时。

首胜耗时、首胜 Replay 和锁定资源仅统计合格胜路。64 档四个机制胜局中三次恰好是宿主首个预测请求，首胜墙钟 776–1083 ms。相同三个根的首次之外的同根对照为 33–87 ms。冷首调用不均衡和小样本使该档墙钟不适合做稳定倍率估计。训练候选只使用 48 次首胜 Replay，三档推理分别按 32／64／128 次首胜预算评分，也包含预算外推。 [逐档原始汇总](../experiments/m1-ls1/evidence/summary.json)

机制模型排出的序列在三档各改变 24/24，实际执行前缀改变 9/24、17/24、17/24。128 档对基线新增两根、丢失一根，共赢七根的首胜路线、首胜 Replay 和锁定 HP 相同。256 档十根两组均赢，其中一根改走另一条首胜路线并改善 18 HP。共同胜局的首胜 Replay 配对差最小 −45、最大 +35、中位数 0。Card ID 与机制模型在全部 72 个合成单元给出相同顺序。人工统计 256 档共同胜局的 HP 配对平均增加 5.6，范围 −5 至 +22。三档均未显示机制表示超越 Card ID 或全面优于人工统计。胜局锁定金币 P50 均为 99，保留的药水数量 P50 均为 1，逐根药水槽和 HP 可查账本。

64／128／256 档在 12 个未见遭遇根上，四组均是 3／6／7 胜。128 档机制模型在 TUNNELER_WEAK 多找到一条，EXOSKELETONS_WEAK 少一条。该档铁甲战士为 7/12 对基线 5/12，静默猎手为 2/12 对基线 3/12。BOWLBUGS_WEAK 的 6 个报告根在所有档均未获胜。两条 F3A 根均因 N2E 卡牌与遗物覆盖不足回退，部分药水也超出覆盖，四组各为 0/2、1/2、1/2。合成报告组无回退。26 根共 312 个单元有 98 个合格胜路、214 个到首胜转移上限。该批无 RPC 失败、墙钟中止、预测器不支持或重建拒绝。

## 反馈与复现

样本总量按根计。四根试跑耗时 16.6 s、1,669 Replay。60 根采样耗时 210.7 s、8,694 Replay，候选效果为 57 胜、162 条策略死亡、21 条动作或转移截断。第一版用 192 条训练候选和 48 条选模候选，各模型每初始化 2,137 个参数，三初始化共用 1.7 s 的训练阶段墙钟。Card ID 和机制模型分别冻在 90／60 轮，选模 MSE 为 0.1090／0.1127。纠正后的正式报告耗时 126.8 s、31,872 Replay。新反馈及再次训练耗时 29.0 s、672 Replay。

首轮报告出现参数容器解包错误，所有支持机制的学习调用触发回退。初次报告和反馈账本保留在原本机运行目录。修复时保持冻结参数、划分、单元次序和单次预算，在新目录复跑完整对照。既有报告标签未参与模型或协议调整。复跑前登记了额外批量上限 46,592 + 768 Replay，覆盖同一次纠错复跑。正式报告采用修复后的结果。推理预检现在使用训练样本验证两种冻结模型可以正常评分。 [纠错预算账本](../experiments/m1-ls1/recovery.json)

冻结 v1 在 8 个新根执行学习引导的 48 次首胜／96 次总预算搜索，6 胜、2 个转移截断。8 根均记录了重排，2 根改变了实际执行前缀。6 个胜路及两个首选战略死亡一起提供 8 条同口径追加训练记录。其余已尝试路线保留在同一经验合同。v2 使用 200 条训练候选，仍用原选模组。报告根完全排除在两代拟合外。账本按根原子写入，预约、根及模型摘要、预算、旧数据摘要与父模型提供追溯。v2 已完成再训练，其自身的独立搜索表现待另一批根测量。 [逐根经验](../experiments/m1-ls1/evidence/ledger.json.gz) · [v1 参数](../experiments/m1-ls1/evidence/model-v1.json) · [v2 参数](../experiments/m1-ls1/evidence/model-v2.json) · [归档摘要](../experiments/m1-ls1/evidence/artifact-hashes.json)
