# M1-H1 复杂战斗存活路线能力差距

2026-11-18。**A10 Infested Prisms 具备可复现的同根原生胜利见证。** M1-L2 的受限 Evaluate 未找到胜路。提高额度后的 Evaluate 和启用生产协调器的配置都找到了胜路。协调器选中的 18 步路线经原生重放，于第 5 回合结束，75 HP 起步、64 HP 存活、敌人全灭。现有证据确定了受限配置的能力差距，尚不足以判定长期战略评价失效。

## 版本与配置审计

固定 STS2 v0.113.1 / Build 26660232、Windows x64、CoreCLR 9.0.7、CombatSolver 0.51.5 源码 `78e4545e825e58c3d999354b1ffcd54241b1d2cf`，冻结 DLL SHA-256 `d286a18c7c0a06769aa636ec00cac53f3fb71de749028858c1e1a7062282ab13`。截至查询时 GitHub 最新公开 Release 仍是 0.51.5，发布标签对应 `3677d4c`，页面显示发布后主干已有更新。未确认这些主干变化对本夹具有何影响。全部数据来自固定 DLL。[上游 Release](https://github.com/Torch1230/CombatSolver/releases/tag/v0.51.5)

实验分支上限保持 32/18/24。生产协调器可分配组合成员、比较终选、做无胜升级、药水反事实和追加搜索。2,400 是配置成员额度，15 秒是软期限和调度输入，总展开及请求墙钟可以超出。每进程硬限 50 秒，批次 220 秒，384 MiB 托管堆限制。首领追加要求 Boss、已完成主搜索范围、没有接管、未达组合提前结束条件等。Evaluate 可执行单树原有机制，但常规模式没有协调器负责追加专项及激进 Power Commitment 成员。

A 的四个终选均为 TimeLimit、无完整胜路。Decimillipede 的 B 路线包含选牌，保留为模拟胜利见证。Infested Prisms 的 B 运行还发现一条 6 HP 赤字、需一瓶药的模拟胜路；相对于无药见证只节省 5 HP，低于 Smart 策略折算的 9 HP，未选中。两条获胜的正式终选均为无风险完整胜利。Queen 没有观测到被终选丢弃的完整胜路，其 Boss Tempo 实际执行 468 展开 / 4,247 转移，观察 160 个前缀、保留 23 个，专项触时限且未改善。The Insatiable 在硬停前未观测到 Boss Tempo 开始记录，无法评价完整协调器结果。现有日志无法排除所有内部曾发现但未上报的路线。

**同额度控制。** Infested Prisms 在普通 Evaluate 的 2,400 节点 / 15 秒 / DOP 2 也返回完整胜路，2,209 展开 / 12,929 转移 / 12.78 秒 / 227.5 MiB，第 6 回合、20 HP、零药，边界 None。该路线未做原生回放。协调器与此档相比有更低预测战损，但两种模式同时改变多项调度及策略，且每格只有一测，不能将差异单独归给某个机制或估算稳定速度收益。

## 原生见证及长期机制

Infested Prisms 源于既有 A10 生成测试夹具（种子 `NOVELTY-DEV-20260915-02`，25 牌、4 遗物），不是自然跑局。Decimillipede 与 The Insatiable 同属既有生成测试夹具。Queen 是人工压力夹具。版本库已有的自然路线 `tests/boss_reward_run_1.jsonl` 是 The Kin 的原生胜利，属于不同根，未用于本组因果对照。

原生重放使用新的隔离 Harness 进程和同一请求，逐字比较根续用戳与 live 戳，按卡实例状态键及 occurrence 选择手牌、按 Combat ID 选择目标，使用原生队列执行。18 步无药水和选牌，第 5 回合触发原生战斗结束，玩家 64 HP、存活敌人 0，CombatManager 已离开战斗。无头宿主缺少 SaveManager profile，结算时有进度保存警告；未验证奖励界面、存档落盘或完整逐动作内部状态差分。见 [原生轨迹](../experiments/m1-h1/native-results.json)。

- 敌人起始 171 HP，Vital Spark 使技能带 3 层污染，提高本回合受到的攻击伤害。首回合只有 1 能量，路线先刮削取得零费候选并打出高速脱离，首个敌方回合损 11 HP，之后一直保持 64 HP。
- 第 2 回合超频、折射及防御安排撑过早期。第 3 回合连续打出两张空值，夹有模组改造和爪击，结合虚弱、黑暗充能球、扩槽与抽牌。第 4 回合再次打出空值、第 5 回合折射击杀。路线包含跨回合铺垫、零费连接和牌堆轮转，并未打出能力牌。轨迹能定位这些动作的时间，无法单独估计某一步开始产生净收益的回合。也未证实存在必须满足的启动阈值或无限循环。
- `StateEvaluation` 已编码持续增益、资源、延迟伤害、可达手牌和投影洗牌等特征。能力承诺按登记卡、战术证据与预计期限创建和更新，可过期或兑现。Beam 专门从合资格候选留代表席位。Infested Prisms 的激进成员实际运行并入选，但其能力承诺创建、准入和兑现计数均为 0。不能从该成员获胜推断能力保路是来源。The Insatiable 日志存在一次创建与五次准入，最终进程超时，无可验证获胜效果。

## 归因与下一步

- **配置不足已确认。** Infested Prisms 在受限配置失败、更大单树预算成功，协调器也成功。这足以修正过去仅凭小预算未胜的解释。原生产 Medium 的完整实机体验仍未测量。
- **深度与成本待定位。** 已知胜路需要到第 5 回合，低档受时间边界限制。接下来用固定版本和原生见证逐前缀追踪生成、准入、保留、展开和终局接收，区分不可达、提前淘汰与单纯预算耗尽。当前没有观察到足以确认长期价值低估或关键分支被剪掉的证据。
- **模拟与执行。** Infested Prisms 的这条无选牌、无药路线通过原生重放。另一个精英的选择映射未验证。The Insatiable 的优先障碍是协调器阶段超出可用硬期限。Queen 首先缺同根胜利见证，继续作为负载对照。

## 复现与验证

从同时包含 `sts2-cli` 和 `CombatSolver-m1-cs1` 的工作区执行。扫描复用 M1-CS1 编译宿主，原生重放另建隔离宿主。

```powershell
python -B sts2-cli/experiments/m1-h1/run.py CombatSolver-m1-h1/repro
python -B sts2-cli/experiments/m1-h1/run.py CombatSolver-m1-h1/matched-repro --matched-evaluate
& sts2-cli/experiments/m1-h1/native.ps1 -Source CombatSolver-m1-h1/repro/dev-02-defect-elite -Output CombatSolver-m1-h1/native-repro
```

[协调器派生结果](../experiments/m1-h1/coordinator-results.json)和[同额度 Evaluate](../experiments/m1-h1/evaluate-results.json)包含策略、质量和关键日志。验证覆盖四个协调器请求（一个按上限终止）、一个同额度单树请求、原生隔离编译与重放、根戳及派生数据核对。正式求解器和游戏流程保持原样，未运行全量 pytest 或五角色批次。
