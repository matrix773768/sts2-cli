# M1-CORE-4 · 完整机制化战略评价与自主学习闭环

从 `065e5af94b493b12b1a8bad65b15fcb3fc400b0c` 出发，完成了第一个能在正常构筑的整场战斗中持续干预、回收终局经验、更新 C 价值并再次部署的 CORE 闭环。主确认有 100 个独立构筑族、五个冻结策略，500 场全部到达终局。更新策略 V1 与 G2 均为 49 胜，相对 G2 效用差 +1.38，按族配对的 95% 区间为 [−1.32,+4.70]。**预定升级门槛未过，默认部署继续使用 G2。**

冻结后的三组额外种子改变了对效应大小的判断。合并四个种子，在与 G2 均有终局的 398 对上，V1 为 199 胜，G2 为 190 胜。按族平均的效用差 +2.91 [+1.15,+5.01]。V1 相对首代 V0 的差为 +0.45 [−1.18,+2.17]。证据支持这套有界机制搜索产生部分可重复的收益；本次价值更新的额外收益仍有不确定性。[主确认](../experiments/m1-core4/evidence/summary.json) · [复核与分层结果](../experiments/m1-core4/evidence/replication.json)

## 机制模型与价值边界

模型在敌人完成行动、下一回合初始抽牌之前接收公开 C。一次编码将全局资源和可变数量的机制实体送入共享的 48→32 实体网络，四个注意力池及按实体数平方根缩放的求和池聚合实体，96 宽的读出层预测死亡及有符号 HP 损失箱的分布。共 31,596 个参数。模型从随机权重训练，同一实体网络处理牌、Power、敌人、遗物和事件。种子、构筑族、实体名称、敌种与行动标识均不进入数值张量。

- 用公开当前行动查本地规则图，从当前相位展开至五条边。攻击事件携带有序位置、基础伤害、段数和当前实际各段伤害。边携带后继攻击特征、回边、正反条件、阈值、历史可用性、重复上限和冷却。已执行次数和寄存器从动态状态读取。敌种与行动任意一致更名后，测试要求整个输入逐元素相等。
- 卡牌按区域、实例、升级、实际费用、基础数值、伤害/格挡/抽牌/能量等操作和变量展开。费用层记录资源种类、期限及触发清除。公开未知多重集按数量编码，已知牌顶底保留位置，弃牌位置不入模。复用了 CORE-2 动态快照、静态目录及 88 张牌的既有数值导出。Power 使用叠层、共享效果及前后触发，已知临界遗物使用计数和受影响的资源。
- 这种图投影仍会产生碰撞。同一深度、局部事件及邻接描述相同的复杂分支可能不可辨。睡眠类条件和一些寄存器只保留粗粒度条件标记。复杂卡牌程序、未分类 Power 的有效负载、setup 的完整待办顺序以及部分特殊费用只在原始 C 中保留得更完整。金钱和药水随终局记录，目前的效用头直接优化胜负和 HP。没有建立完整联合资源分布。[编码器与搜索接口](../experiments/m1-core4/semantic.py) · [学习数据合同](../experiments/m1-core4/protocol.md)

## 战术图如何使用战略价值

每回合复用 CORE-1R2 的生成期约简、公开抽牌分支及合法见证。在 128 次战术转移预算内，先在图上绑定冻结 G2 的逐公开决策，再按首动作轮转、对路径作固定散列排序，通常最多选 32 个 A，优先完整保留可找到的参考路线。路径散列仅用于候选抽取。A→C 使用真实结算、共享缓存与每条路线 8 次有界展开。批量计算去重 C，沿 R 的公开概率取期望，在决策节点优先覆盖完整质量，再比较效用。编译策略在真实观察后绑定动作；不匹配时交给 G2。每回合只采用一次新计划。

终局直接代入 DC2B 胜负及战损效用。对 C，先把开战到 C 已支付的 HP 加回预测的剩余有符号损失，再对分布计算期望。死亡效用 −50。未知质量按 −50 临时下界记账，保留其原始权重。只有候选和图上 G2 参考均有完整严格后继、且候选高于参考 1 个效用单位时执行。参考策略依赖规范化菜单和可表示的见证；实际 G2 轨迹另开独立臂检验。此规则有选择偏差，偏向能够在当前预算内结算且图上能复原 G2 的回合。[战术反传](../experiments/m1-core4/improve.py) · [实际执行器](../experiments/m1-core4/play_loop.py)

主确认 V1 查询 645 次，候选在 557 次上取得完整质量，G2 参考在 192 次上取得完整质量。57 次实际干预中，54 次执行到结束回合，3 次提前终局，其余 588 次由 G2 执行。产生 73,355 次战术及结算模拟调用、12,868 个回合内缓存结算条目、6,948 个按查询去重的 C。复放全部 100 场重新记录条件分布，核对种子、动作数、每个 C、终局和已有的每次查询记录。以每次查询质量为 1，参考缺口中约 169.77 份是图上无对应见证，65.72 份是预算停车，55.61 份是暂不支持的待选决策，42 份为随机目标。候选缺口中 53.25 份来自未识别的敌方条件。两种覆盖率的差异比增加网络宽度更直接限制了本轮实际干预。[逐类概率账本](../experiments/m1-core4/evidence/mass.json)

## 学到了哪些战略信息

独立确认 C 上，V0 在 G2 续策的 547 个 C 上 NLL 1.765，死亡 Brier 0.126，平均死亡预测 48.5%，实际 50.1%。V1 在 V0 续策的 544 个 C 上 NLL 1.732，Brier 0.114，平均预测 50.1%，实际 49.4%。长战斗贡献多个 C，这两组续策和样本有别。

| V1 同一批 C 的推理输入 | 分布 NLL | 死亡 Brier |
| --- | ---: | ---: |
| 全部机制 | 1.732 | 0.114 |
| 遮蔽未来敌方节点与边 | 1.819 | 0.112 |
| 遮蔽牌区、位置及所选费用层字段 | 1.764 | 0.115 |
| 遮蔽 Power 与遗物实体 | 1.779 | 0.111 |

未来行动及持续效果对完整分布的预测有贡献，两项遮蔽的死亡 Brier 却略有改善。牌区字段对 V1 的 NLL 有贡献，V0 的对应结果接近打平。遮蔽会改变输入分布，不能据此归因具体胜局。按族在独立确认中跳过一次实际中盘干预、随后双方都执行冻结 V0，28 对实际终局的效用差为 +2.54 [+1.12,+4.15]。V1 对取得双 C 且真实效用不同的 10 对排对 9 对。样本只覆盖 V0 决定干预的回合，单次干预优势不能直接累加为整战收益。[逐对预测与终局](../experiments/m1-core4/evidence/paired-check.json)

训练 C 涉及 99 个敌种。自然确认只有两族含训练 C 未见敌种。另以这两个遭遇分别配 100 个冻结构筑，使用遭遇所属的真实章节及变体，G2 与 V1 共执行 400 场。Haunted Ship 两臂均 100 胜，V1 效用差 +1.29 [+0.41,+2.26]，干预 51/456 回合。Nibbits 为 99 对 100 胜，效用差 +2.62 [+0.62,+5.82]，干预 63/501 回合。两者静态行动图均缺失，此处主要检验公开当前攻击、牌区、玩家机制及回退能否迁移。胜率接近天花板，仍缺少未见复杂敌方行动图和危险遭遇上的独立证据。首次替换遭遇时沿用了接收方章节，宿主拒绝不合法组合；该批次仅计成本，正式诊断使用完整合法的遭遇规格。[迁移实验](../experiments/m1-core4/evidence/transfer.json)

## 计算、复现与决定

CPU 训练 V0 44.2 秒、V1 10.1 秒。48 个已编码 C 的一次批量前向约 1.6 毫秒，含 Python 机制编码及装批约 41 毫秒。各任务累计墙钟约 60 分钟，包含并行分片、额外种子、独立反事实、迁移初次失败、定向复放和初始化训练复现；未使用 GPU。账本区分宿主真实动作、图转移与 A→C 结算，不计未单独插桩的引擎内部操作。冷启动、并行竞争及压缩写盘会影响每场部署时间。V0 使用已提交数据重新训练，检查点文件 SHA-256 与初次训练完全一致。[计算账本](../experiments/m1-core4/evidence/ledger.json)

复现入口为 `python experiments/m1-core4/reproduce.py logs/new-core4`。使用已有的 STS2、CORE-2 宿主及冻结 G2。数据、检查点、静态规则索引、逐根记录和训练曲线均可独立读取。CORE-4 测试覆盖身份更名、事件顺序、费用期限、顶牌、弃牌无序、分布归一、严格 C 边界、族隔离与实际干预门槛，同时运行 CORE-1R2、CORE-2、CORE-3 回归。[复现协议](../experiments/m1-core4/protocol.md)

**工程闭环成立，默认策略升级仍待独立确认。** 后续完整架构研究可直接使用 V1、128 转移、32 个多样 A、严格质量及 G2 参考门槛；V0 是区分更新效果所需的同架构对照。当前最有证据的瓶颈是参考路线在约简图上的缺失、部分敌方条件结算、同根不同长期效用的有效监督量，以及计算开销。两代模型在额外种子上均改善冻结 G2，但尚不能断言本次更新超越 V0，或在相近部署成本下超越 G2-search。
