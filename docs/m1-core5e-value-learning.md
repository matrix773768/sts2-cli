# M1-CORE-5E　条件价值学习与经验利用效率

**保留冻结高预算 5C V2。** 用多个合法条件世界估计同根效用差，降低了监督的抽样误差。加入一步分布 TD 后，更新模型优于同数据、同优化步数的纯 MC 更新，但两者在开发条件误差上均落后于第 0 轮 V2。两次 5D 已知失胜的战略选择得到保留。选模在独立确认之前完成，TD 作为训练后的挑战者接受了另外 64 个新构筑族的整战检验。[冻结协议](../experiments/m1-core5e/protocol.md) · [选模决定](../experiments/m1-core5e/evidence/selection.json)

## 同根条件监督

本轮从 `5bb7c68bbb66e25b419460743d09f74568ca3372` 出发。冻结 5C 高、低预算 V2、5D V3、G2 和 G2-search。沿用原 C 边界、共享机制编码、网络和完整条件搜索。监督的实际续策统一为**高预算 V2**。低预算战斗仅作能力与成本对照。

从 5D 归档的自然战斗恢复当前回合的全部前缀，优先选择正常中盘、公开预测尚有辨别空间的回合。一次正常 V2 查询生成图方案、G2 和完整条件方案。候选比较考虑攻防、敌方 HP、持续效果、牌顶、消耗及保留资源的差异，也保留同首动作的完整续法。选案完成后才为该根产生估计用的随机种子。环境端验证未知牌堆与公开多重集一致、忽略同类实例顺序合法、无已知上下牌及洗牌修正，再均匀置换。每次检查公开观察和信念完全相同，两个方案从同一前缀、同一重排出发，随后恢复冻结 V2。决策端看不到重排种子和实际尾牌。

这套实验估计的是**给定原前缀及其他随机流时，关于可交换未知牌堆的条件期望差**。模型使用的完整后继分布仍按公开概率结算。实例不等价、公开复放异常或实际后继未匹配时，整个比较退出拟合，原始记录保留。C 的匹配粒度与 5D 一样，是冻结网络输入或确切终局。它不能认证所有内部状态等价。[配对生成与执行](../experiments/m1-core5e/conditions5e.py)

训练根一般使用 4 个世界，事前编号和回合满足条件时使用 8 个；开发根统一使用 8 个。对每根取带符号效用差的算术均值，以等根权重拟合平方误差，平局保留。真实终局在方案分布中取常数，双 C 或多后继按各自原始概率求期望。仅实际到达的 C 可以获得该条续战的分布标签。训练的 293 次共同死亡中，有 9 次所在的同根比较在另一世界出现非零效用差，开发为 201 次中的 17 次。

**独立半组复评。** 开发根以四个排列的均值为参考，从互不重合的另一半单取一个世界，差值 RMSE 为 14.38；取另外四个的均值，降至 5.09。按根内样本方差估算，单世界标准差的均方根为 14.63，八世界均值的标准误均方根为 5.17。只有 15 根的两半均为非零，这些根中符号一致率为 93.3%。训练根相应的单世界和半组 RMSE 为 14.45 和 10.18。两个半组的共同条件相同，误差只反映本实验重采样的随机性。[逐项可靠性与退出原因](../experiments/m1-core5e/evidence/reliability.json)

5D 的 Huber 目标削弱大效用差的影响，平局减采样改变目标分布，附加符号损失又会奖励更大的排序间隔。为量出合并影响，我们在每个根的一半样本上，分别求算术均值与仿照 5D 三项设置的标量损失最优位置，另一半验证。开发 RMSE 分别为 **5.09 与 10.11**。这项标量检验隔离了损失的作用，没有复现旧网络的跨根参数共享和每个 minibatch 的归一化。[计算方法](../experiments/m1-core5e/reliability5e.py)

另取初次方差最大的 12 个训练根及按哈希抽取的 4 个初次全零根，逐根增加 **12 个完全独立的参考世界**，两侧再次合法续战，共 192 对，均未用于训练和选模。以这 12 次均值作参考，在高方差根上，初次单世界、仿 5D 损失最优位置、初次多世界算术均值的 RMSE 分别为 **43.35、29.06、15.37**；冻结 V2 的方案差预测为 22.90。4 个初次全零根中有 1 个在复评中出现非零差。这次复评依初次不确定性选根，反映高方差子集上的监督质量。[独立复评逐根结果](../experiments/m1-core5e/evidence/results.json)

## Distributional TD 与真实终局

没有重新生成自然训练战斗。510 场已解决的高预算 V2 轨迹提供 2,426 个自然 C，其中 **1,916 个有相邻下一 C，510 个直接接真实终局**。开发的 325 个 C 提供 255 条相邻转移和 70 条终局边；有一场在首个 C 前结束。用回合序号逐条验证相邻性，排除原档案中两场训练异常和一场开发异常。另有 1,366 个真实抵达的训练分支 C 用于 MC 辅助监督，包括 5D 已核验分支和本轮独立续战中的各次实际观察。[逐边索引](../experiments/m1-core5e/evidence/transitions.gz) · [数据装配](../experiments/m1-core5e/data5e.py)

对非终局转移，先用冻结 V2 预测下一 C 的分布。死亡原子的概率原样传递。每个存活原子的带符号剩余净战损加上本步实际 HP 差，再按距离投影到两侧非均匀桶中心。回血产生负位移；跨越中心不会丢弃质量。极端尾部饱和到端点，训练转移平均越界质量为 **0.000000192**。不折扣未来损失。真实终局直接投影实际净战损，死亡直接取死亡类别。开战 HP 与最大 HP 仍由原效用函数在评价时使用。[目标与投影实现](../experiments/m1-core5e/targets5e.py)

两个训练臂都从 V2 开始，使用相同批次、方案、学习率、网络和 8 轮更新；仅自然非终局目标不同。混合臂使用 65% 冻结一步 TD 与 35% 实际 MC。两臂都使用 25% V2 输出约束分布漂移。每轮遍历相同自然 C 与全部条件根，配对损失直接比较完整策略期望差。八轮中的每一轮，TD 臂的开发条件 RMSE 均优于匹配的 MC 臂。开发非终局边上，直接在 C 评分相对实际终局的 RMSE 为 35.62；观察一步真实转移再用冻结目标预测，降至 33.83。后者使用了真实的下一步信息，是目标质量诊断。此次没有获得超过 V2 的策略更新，也没有据此估算节省了多少未来战斗。[拟合曲线](../experiments/m1-core5e/evidence/fit.json) · [转移目标误差](../experiments/m1-core5e/evidence/transitions.json) · [两个入围权重的复训哈希](../experiments/m1-core5e/evidence/verification.json)

按 24 个开发族等权，TD 减 MC 的配对均方误差为 −10.16，95% 区间 [−25.98,+3.18]。TD 减 V2 为 +8.77 [−6.05,+25.68]。在这批轨迹上，TD 改善了更新后的点估计；独立族的统计精度仍不足以断言稳定优势。

## 上一代策略与成长取舍

共享菜单试验用冻结 V2 一次搜索生成完整方案、后继和公开执行表，以 **V2 实际会走的完整回合**为比较对象。TD 在相同的 C 和概率上重评；另一完整方案比 incumbent 高出 1 效用才替换。36 个开发世界共 163 次查询，有 146 次可对实际方案完整评分，113 次的原动作是 G2 回退。只有 1 次发生真正的代际替换，来自 G2 回退；整战与 V2 逐根效用相同。这里代际替换与原系统对 G2 的干预分别计数。[共享菜单执行器](../experiments/m1-core5e/incumbent5e.py)

- **MYTES，第 2 回合。** 对 5D 复盘中的 V2 原方案和 V3 失胜方案，TD 依次评分 25.34、12.36，MC 为 36.89、24.51，两者都保留原有排序。实际整战中 V2、MC、TD 均以 4 HP 获胜。
- **Vantom，第 2 回合。** TD 对恶魔形态方案评分 23.90，对 Cruelty 加火焰屏障评分 18.10；MC 分别为 30.08、28.01。V2 和 TD 实际以 2 HP 获胜，MC 以 11 HP 获胜。5D V3 在两个原种子均失败。这两根已知历史案例全部排除在独立确认依据之外。[共享候选交叉评分与实际终局](../experiments/m1-core5e/evidence/known.json)

## 新独立构筑族整战

正式面板使用 64 个成分独立的新构筑族，每族两个配对种子，覆盖 37 种遭遇。第一至三章分别有 38、40、50 个世界；历史确认族只参与牌组成分排重。主比较保持与 5C 相同的高预算接口、G2 回退和 1 效用干预裕量。表内使用实际走完整场后的预测器战斗结果，按 64 个族做配对自助区间。单次查询的网络效用预测没有作为胜负标签。

**TD 高预算减 V2 高预算的配对效用为 −0.90 [−2.74,+0.05]。** 两者共同获胜的 61 场中，TD 平均多保留 0.03 HP；另有一场 V2 胜、TD 负，反向翻盘为零。严重战损指死亡或净损失至少达到开局 HP 的一半。低预算 V2 与高预算胜场相同，各有一场独赢，配对效用差 −0.09 [−2.40,+2.46]。胜场相同仍允许根级策略差异。

三个策略在同一个根（编号 35）均触发 `Unused draw prefix`。这场在原宿主的三行都保留为异常，不填作死亡。在 5D 已有的隔离修复宿主上原样重跑，三者均以 **22 HP 获胜**。补齐敏感性面板后，V2 高/低预算都是 63/128 胜，TD 高预算为 62/128 胜，配对效用差及区间不变。第 0 轮已在开发阶段入选，此次独立验收也没有支持升级。[原宿主与补齐面板的逐臂统计](../experiments/m1-core5e/evidence/results.json)

**原生抽检。** 对成本样本的 16 根和唯一的胜负翻转根，各重放两条策略的实际动作。在 34 条原生复放中有 32 条逐步通过合法菜单、手牌/能量或待选检查，胜负与终局 HP 全部相符。唯一翻转发生在 LOUSE_PROGENITOR_NORMAL，原生游戏中 V2 以 11 HP 获胜，TD 死亡。第 112 根的两次原生复放均在等待下一决策时超时，原生胜负未知。整张正式面板的胜率仍属于整战预测器，上述抽检覆盖其中 17 根。[原生动作和终局戳](../experiments/m1-core5e/evidence/native.gz)

**端到端成本。** 正式高预算 V2、TD、低预算 V2 的 128 根 worker 时长分别为 771.0、1,067.2、553.3 秒，运行时的分片和并发负载不同。另在相同 16 根串行复测，高预算 V2 为 86.39 秒、TD 为 63.55 秒，均含设置、搜索、网络评价、真实执行与重置；逐根对局计时合计为 74.43 与 63.14 秒。两者分别执行 46,519、48,601 次模拟调用。固定顺序先跑 V2，这个时差包含启动和机器负载，不足以证明 TD 降低了同预算搜索工作量。[逐根成本](../experiments/m1-core5e/evidence/results.json)

## 计算账本与研究决定

计量共 **8,598.5 worker 秒，143.3 worker 分钟**，比建议的两小时多 23.3 分钟。初始条件世界生产约 60.3 分钟，追加 12 世界的不确定性审计 20.1 分钟，新独立确认 39.9 分钟，开发整战与共享菜单对照 10.7 分钟。其余为宿主构建、训练、复训、原生核验与回归。并行工作分别计时，没有将早期诊断失败、所有模块导入和文档制作计入账本。5 套受影响回归共 32 个不同测试通过，两种入围模型都从归档数据复训得到相同 SHA-256。[计算、冻结身份与文件哈希](../experiments/m1-core5e/evidence/ledger.json) · [回归记录](../experiments/m1-core5e/evidence/tests.json) · [增补测试及权重复核](../experiments/m1-core5e/evidence/verification.json)

保留 V2。将 MC、TD 入围权重作为可复查研究资产，停止沿同一协议继续微调。此次能确定的是，条件均值降低了部分高方差比较的监督误差，冻结 TD 提高了现有自然经验的利用效率；两者尚未产生独立整战代际收益。剩余限制包括未知随机流未被全部积分、相当比例的回合在所有已采世界上同效用，以及具有战略判别力的独立状态数量有限。5D 已准备的有遗物原生构筑继续保留，第二、三章分别只有 4 和 1 个独立种子，69 个实见遗物 ID 中冻结静态遗物表仅显式覆盖燃烧之血。本轮没有将它们混入训练或修改共享编码。[架构 TODO](m1-core-architecture-and-todo.md) · [训练协议与复现入口](../experiments/m1-core5e/protocol.md) · [MC 检查点](../experiments/m1-core5e/evidence/mc.pt) · [TD 检查点](../experiments/m1-core5e/evidence/td.pt)
