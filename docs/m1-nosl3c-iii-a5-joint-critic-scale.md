# M1-NOSL3C-III-A5 归一化 Critic 联合训练对照

**候选臂完成 36 次更新。** 回报预测整体上移，独立开发组的 MAE 和 RMSE 下降，胜败区分没有改善。更新 36 的 Sample 严格胜局比 A2 少三条，Greedy 多三条，Greedy 共同胜根则平均多损 14.13 HP。现阶段优先重新设计 Critic 的学习信号与梯度对照，暂不扩大此候选的训练规模。

## 协议与首批等价性

起点为 `port/v0.113.1@16029d7dea9cccaa8457b9a1a59e75134cb48cf2`。使用 A2 前 36 批的 864 个全池 999 HP 根、初始化种子、逐根行为种子与原 II-K.5 实际宿主绑定。4 worker、microbatch 4、128 动作上限、原奖励、严格认证、Adam、学习率、熵权重和全局裁剪保持。基线读取 A2 现有账本与评价。候选标记为 `nosl3c.hp-loss-actor-critic.v4.a5-normalized-100`。实验适配器在进程内对原优化器的两处目标表达式做有断言的替换，正式 v4 源码未改。

归一化目标为 `G/100`，最后仿射层初始权重及偏置也除以 100。Actor 使用 `G − 100 × stop_gradient(Vnorm)`，Critic 对归一化目标做逐轨迹平均 MSE，再乘原权重 0.1。首批 A2 的全部 1070 个决策，在共用公开历史上的 Actor logits 逐元素一致，解码价值最大差 2.98e−8，float32 优势差为 0。候选真实采集的 24 条逐根动作、logp、终局、认证资格及回报也逐项一致。按账本数值重算的优势最大差为 2.98e−8。首批门槛在优化前通过。

候选 594/864 条准入（516 胜、78 败），19610 个优化转移。A2 对应为 595/864（513 胜、82 败）、19797 个转移。候选其余为 158 规则风险、45 截断、40 原生差分、27 不支持，A2 对应 157、45、40、27。候选训练主墙钟 1525.29 s，A2 为 1541.54 s。训练和评价记录的 2087 个宿主均正常退出。只读校验覆盖所有 864 根及原生审计哈希、37 个事务快照。更新 0、12、36 的完整模型、Adam、Torch RNG 均在账本中，末次候选模型哈希为 `c91084c13aa666da8a1bf68b7b78757724d486027ec256bcaa814867cf98c75e`。

## 复现

从仓库根使用原冻结产物与 A2 证据，指定全新输出目录。

```powershell
$env:PYTHONUTF8 = '1'
$out = 'logs/nosl3c-iii-a5-repro'
python experiments/m1-nosl3c-iii-a5/joint.py $out
if ($LASTEXITCODE -ne 0) { throw 'A5 training/evaluation failed' }
python experiments/m1-nosl3c-iii-a5/analyze.py $out
if ($LASTEXITCODE -ne 0) { throw 'A5 verification failed' }
```

运行输出在 `logs/nosl3c-iii-a5-01`，含首批门槛、SQLite 快照和审计、逐更新指标、四组评价与 `results.json`。未重跑 A2、封存测试或全量回归。
