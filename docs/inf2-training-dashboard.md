# INF2 本地训练中心

## 双击打开

在 Windows 资源管理器中双击 [start-dashboard.cmd](../tools/training_manager/start-dashboard.cmd)。启动器使用 INF1 的 Python 环境设置，检查已有面板服务，再打开默认浏览器。面板地址为 `127.0.0.1:8765`。

面板打开后可以先审核任务和查看结果。**管理器在线**表示 INF1 进程仍在运行，**任务调度已允许**表示 INF1 可以选择符合条件的任务。单个任务还有待调度、运行中、等待安全检查点和已暂停等状态。

可选脚本 [create-dashboard-shortcut.ps1](../tools/training_manager/create-dashboard-shortcut.ps1) 创建桌面快捷方式。运行一次后可直接双击快捷方式。脚本只创建当前用户的快捷方式。

### 更新后重新打开面板

如果更新前的 Web 服务仍在运行，在「资源与设置」点击「关闭面板服务」，然后再次双击启动器。这会重新加载面板代码，INF1 保持原有运行状态。冻结时会依次查找 PATH 中的 Git、已安装的 Git for Windows 和 GitHub Desktop 自带的 Git，并验证当前项目的 Git HEAD。找不到 Git 时，面板会提示检查安装并重新打开。

## 启动 DC2B 初始训练

1. 在 **训练计划** 找到 **DC2B 初始训练**，打开 **审核计划**。检查输入资产、4,096 次更新、6 小时执行预算、512 个原开发世界，以及复杂构筑对照。
2. 点击 **冻结并查看配置**。核对冻结的配置、输入哈希和任务 SHA-256，再点击 **确认提交到 INF1**。
3. 在 **资源与设置** 选择 **Full · 全速模式** 或 **Idle · 空闲模式**。Idle 等待插电且达到无输入门槛。DC2B 的重负载阶段在 Light 中等待。
4. 在 **训练总览** 分别确认 **启动管理器** 和 **允许调度**。队列按 INF1 的运行模式和资源规则发车。若管理器已在线且调度已允许，提交成功后即可发车。

课程训练会核对初始任务成功终态、完整开发阶段记录、原开发账本与冻结模型身份，以及实际 `gate.json`。门槛未满足时，审核页显示具体原因。通过后仍需打开 **DC2B 课程训练** 并单独冻结和确认提交。两项正式配置的确认评测次数均为零。

## 暂停、恢复和关闭

| 操作 | 面板位置 |
| --- | --- |
| 暂停单个任务 | **任务队列 → 安全暂停**。等待“正在等待安全检查点”变为“已暂停”。特征缓存等阶段会等当前阶段完成。 |
| 恢复单个任务 | **任务队列 → 恢复任务**。INF1 使用当前配置、资源条件和已提交检查点。 |
| 停止所有计算 | **训练总览 → 安全暂停所有计算**。这会停止发车并让活动任务退出到安全边界。 |
| 恢复整个队列 | **训练总览 → 恢复调度**。手动暂停过的任务仍需单独恢复。 |
| 关闭 INF1 | **训练总览 → 安全关闭管理器**。等管理器显示离线。 |
| 关闭 Web 服务 | **资源与设置 → 关闭面板服务**。关闭浏览器标签页也可以离开界面，后台计算会继续。 |
| 取消或强制取消 | **任务队列** 中分别确认。立即强制取消会结束该任务的进程树，可能丢失当时未提交的工作。 |

Windows 进入睡眠、休眠或关机时，本地计算停止。重新登录后双击打开面板，查看队列，再按需要启动、恢复。

## 查看和复制结果

打开 **训练结果**。表格按 D2、G0-DC、G1、G2、G3 展示已测得的开发指标。训练曲线基于已提交的更新，每代详细卡片显示 HP 分层、经验生产、实际更新及耗时。正式结果缺失时显示“尚未生成”。隔离验收有独立卡片。

选择 **复制 Markdown 摘要** 可将计数、指标及门槛结果粘贴到 ChatGPT。浏览器禁用剪贴板时，面板会选中摘要全文，便于手动复制。使用 **原始 JSON 与运行日志** 打开对应的任务文件清单。二进制检查点可从任务输出目录访问。

**剩余执行预算**随已累计的受监督时间减少。**预计阶段剩余**只在有足够实测进度和吞吐时显示。

## 本机运行边界

启动器为当前 Web 实例提供会话凭据。手动输入地址仍要求有效的浏览器会话。若会话过期或服务重启，重新双击启动器。暂停、模式切换和其他控制请求使用同源会话与 CSRF 校验。文件预览限于已提交任务目录中审核过的日志、JSON 和检查点。

独立的 Windows 计划任务及 CLI 操作见 [INF1 手册](inf1-training-manager.md)。INF2 服务不负责开机启动。

## DC2B 八小时夜间训练

夜间计划接到与 DC2B 课程相同的 G0-DC 准入验证。打开「训练计划」→「DC2B 八小时夜间训练」→「审核计划」→「冻结并查看配置」→「确认提交到 INF1」，选择 Full。升级后请重启面板和空闲的管理器，以载入新计划及预算收尾逻辑。 [夜间协议与预算续接](m1-dc2b-night1.md)
