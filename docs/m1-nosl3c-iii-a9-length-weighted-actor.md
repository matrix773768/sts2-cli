# M1-NOSL3C-III-A9 Actor 轨迹长度加权训练对照

**保留 v4，暂不延长该候选。** 候选 36 次更新全部完成。相较 A2，末次 Sample、Greedy 严格胜分别多 2 条和 1 条，但共同胜根平均战损均上升。Sample 固定长战组的七个共同胜根平均多损 27.71 HP。候选降低了测得的梯度离散，策略结果未显示一致收益。

## 干预与核验

起点为 `port/v0.113.1@eb8d86ce3b7faf9a3e43077ed1623704b9d6ea82`。候选身份 `nosl3c.hp-loss-actor-critic.v4.a9-length-inverse-sqrt`。对完整优化批准入轨迹的实际决策数 T 计算 `wᵢ = Tᵢ^(−1/2) / meanⱼ(Tⱼ^(−1/2))`。每轨迹的 Actor 求和损失乘以 wᵢ，再按原批准入根数平均。Critic、熵、优势、Adam 和全局裁剪沿用 v4。轨迹长度来自动作过程，故此干预改变 Actor 优化目标。正式 v4 源码、采样、回报、资格、轨迹记录和事务合同保持原样。

- 在 A2 更新 12 的冻结批次上，全 1 权重与原 v4 的损失、联合梯度逐字节一致，保存权重与 Adam 状态精确复现历史更新。真实权重均值为 1，逐根分解后重建的联合梯度相对残差 4.67e−7；Critic 和熵逐项相同。另以 1、4、7、24 四种 microbatch 宽度调用同一优化适配器，每次仅调用一次权重函数，传入相同的整批 17 根长度并返回相同权重。
- 训练前检查全部初始参数与 A2 逐元素相同。在 A2 首批 1070 个公开决策上，Actor logits、价值和原优势均一致。第一次优化前，候选真实采集的 24 根逐根核对通过，动作、行为 logp、价值、终局、奖励和严格资格差异均为零。A2 更新 0 的既有评价作为共同起点。
- 沿用 A2 前 36 批根和行为种子、II-K.5 冻结宿主，4 worker、microbatch 4、auditor limit 4、128 动作预算、全池 999 HP 和原 mixed 奖励。只读验收覆盖 864 根及审计哈希和 37 个事务快照。更新 0、12、36 的模型、Adam、Torch RNG 保存在原事务库，末次候选模型哈希 `1dc1575dc8d335f78b0533754f052a7e3d6050608ba54370076ae571193cba7e`。

## 复现

从仓库根，使用固定宿主、A2 和 A8 证据及新输出目录。

```powershell
$env:PYTHONUTF8 = '1'
$out = 'logs/nosl3c-iii-a9-repro'
python experiments/m1-nosl3c-iii-a9/weighted.py $out
if ($LASTEXITCODE -ne 0) { throw 'A9 train or evaluation failed' }
python experiments/m1-nosl3c-iii-a9/analyze.py $out
if ($LASTEXITCODE -ne 0) { throw 'A9 verification failed' }
```

实际输出为 `logs/nosl3c-iii-a9-01`，包含离线核验、首批门槛、训练 SQLite、审计、评价、长度分组与 `results.json`。A2–A8 原始证据保持原样。
