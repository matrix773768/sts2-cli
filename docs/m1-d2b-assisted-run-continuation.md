# M1-D2B 辅助跑局的原生闭环

2026-11-18。基线 `8adef11fa99495174feec3dcf8c7569edbd20d19`，STS2 v0.113.1 / Build 26660232、CoreCLR 9.0.7、冻结 CombatSolver 0.51.5。使用 D1 与 D2A 已采集自然局史，未扫描新种子。

**3 场自然死亡分别从合法地图检查点独立重现，1 场找到并原生验收胜路，1 场真实重走并继续跑局。** 铁甲战士 A2 在第一幕第 12 层得救，推进两层，新增第 13 和 14 层两个严格根。自然分支及辅助分支均未到第二幕。

## 原生执行合同

1. 从只读源 bank 选定已记录原生死亡的自然局史。要求最后一战具有匹配楼层、进场动作和 SHA-256 的通过审计的原生地图检查点。独立冷恢复后重新执行冻结 Q1+Choice，整段已解析动作与原局史后缀匹配，且原生终局 HP 为 0，才允许搜索。已有胜局和 unsupported、timeout、execution_fault 都没有搜索资格。
2. 用 F3B C 的冻结搜索，在新进程先试无主动药水，再在首个条件没得到可用胜路时试允许白名单药水。工具支持 128、512 和 2,048 每条件额度，本批每条件固定 128。所有搜索使用预测器的内部 RNG，属于 offline-oracle。报告实际披露的转移数及计费上限。引擎出错而未返回转移计数时，整个条件额度保守计费。
3. 在另一个进程生成固定预测帧，对齐 F3B 胜路的逐步摘要，再独立进行 F3A 严格原生验收。验收要求动作路由合法、完整逐步状态相等，并在正确位置收到原生胜利结束回调。
4. D1 新开一个冷采样进程，核对相同检查点、源地图、合法出边、公开战斗根、原生 live 摘要、RNG 及永久资源。该进程用同一 F3A 动作绑定重走，逐步核对所有原生帧，并与独立验收比较动作、选择证据、最终公开奖励状态、战损及资源字段。通过后保持这个进程打开，让原有采样策略执行领奖、合法地图选择以及后续战斗。源文件字节和源清单在退出前复查。
5. 输出使用独立目录。D1 格式的清单保留原 RunRecord、失败根和独立复现的 Q1 死亡轨迹。F3B 预测与验收各有独立路线和验证记录。`rescue.json` 保存两次实际原生执行证据，包含动作、选择、结算、资源差分及阶段时间。辅助 RunRecord 引用原局史、失败根、进场前缀、救援和路线 ID，后续根标记 `offline_teacher_assisted=true`，血缘与划分继承父局史。源 bank 的自然根和原标签继续保留。

宿主版本按源 bank 完整匹配。D1 结果使用 `m1-f3b-build`，D2A 结果使用 `m1-d2a-build`。D2A 已基于 F3B 隔离构建，含 F3B 搜索和 D2A 的自然策略选择合同。两种宿主均实际启动并执行过搜索。本阶段共享改动是提取 D1 恢复与续跑入口、F3A 原生重放循环、F3B 固定预测帧准备；没有新的战斗规则、搜索规则或游戏 DLL 构建。

| 铁甲战士 A2 `iron-6-a2`，第一幕第 12 层 `INKLETS_NORMAL` | 10 次转移，原生验收 7/7 | 无需执行 | 重走 7/7 后到 `card_reward`，同进程继续 14 条命令至第 14 层新根 | 2 |

已知搜索转移合计 **140**。静默猎手两次因镜像 `Neutralize.OnPlay` 时遇到 `sts2headless.locpatch` 的 `NeutralizePrefix` 而未返回转移计数，按每次 128 计，三场合计保守计费 **396**。未调整 Harmony 补丁。`iron-4` 的两次候选耗尽分别计入账本。

成功根原始 Q1 为 13 HP 入场、3 步后 0 HP 原生死亡。胜路累计掉血 2，战斗结束锁定 11 HP，原生战后结算到 17 HP。金币增加 19，牌组、遗物、最大 HP 与药水槽保持。随后按原奖励策略取得卡牌奖励，打完第 13 层 `VINE_SHAMBLER_NORMAL`，并在第 14 层 `SNAPPING_JAXFRUIT_NORMAL` 开局处达到两个后续根的样本上限。后续根分别以 17 和 13 HP 入场，均独立冷恢复。辅助局史继续归原本的 development 集，新增独立局史和独立种子均为 0。

## 验证及后续边界

D2A 和 D2B 共 14 项定向回归全部通过，用时 42.42 秒。涵盖非死亡拒绝、Q1 死亡轨迹匹配、双重原生重走、奖励后的继续运行、源存档一致、失败计费，以及后续根再次冷恢复。三个结果清单通过 D1 Schema 校验，Python 编译和 Git diff 检查通过。本阶段未执行全量 pytest 或五角色兼容性批次。

当前入口每次处理一条已采样局史的一个死亡根。仅接收确定性地图策略的局史，随机地图策略需要先记录或重建父前缀消耗的策略 RNG。D2A 自然选择合同没有扩展到 F3B 预测和教师路线绑定。Neutralize 补丁边界与候选耗尽仍限制覆盖。下一阶段可先按死亡根逐条调度，在扩到更多独立局史前补齐随机地图策略 RNG 血缘，并按根记录失败类型和累计救援成本。

## 复现

从仓库根使用 [项目环境](PROJECT_STATUS.md) 中的原生 DLL、两个已构建隔离宿主和对应本地 bank。若缺少源数据，分别沿用 D1 的固定配置和 D2A 的两种子配置生成，宿主必须与各自清单版本一致。命令要求输出路径尚未存在。

```powershell
python -X utf8 experiments/m1-d2b/rescue.py logs/m1-d1-v1-w2 iron-6-a2 logs/m1-d2b/iron-6-a2 --cap 128
python -X utf8 experiments/m1-d2b/rescue.py logs/m1-d2a/reruns iron-4 logs/m1-d2b/iron-4 --host m1-d2a-build --cap 128
python -X utf8 experiments/m1-d2b/rescue.py logs/m1-d1-v1-w2 silent-8 logs/m1-d2b/silent-8 --cap 128
python -X utf8 -m pytest experiments/m1-d2a/test_native_choices.py experiments/m1-d2b/test_rescue.py -q
```

定向测试默认使用上述本地目录。替代目录可用 `STS2_D2B_RESULTS`、`STS2_D2B_SOURCE` 和 `STS2_D2B_D2A_SOURCE` 指定。
