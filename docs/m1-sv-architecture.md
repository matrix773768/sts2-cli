# STS2 AI：搜索与分布价值学习架构（M1-SV）

更新日期为 2026-11-24。SV1、SV3A 与 SV4A 已完成。当前阶段为 DC1，先调查构筑、难度和战损效用，再安排后续训练和搜索。
基准：`57d4fdb96a326d367d6e0e2250f3717fe0bcef61`，`port/v0.113.1`。
本文是新的研究决策记录，不覆盖 PRE0B/PRE1 历史实验；原 PRE2 大规模单动作 RL 计划暂缓。

## 1. 项目目标和信息约束

长期目标：利用忠实模拟、搜索和学习提高完整跑局胜率，最终挑战顶尖人类玩家；关注持久资源损失与尾部风险。现阶段固定 STS2 v0.113.1、CombatSolver 0.51.5-iik.3b，优先单人 Ironclad 战斗，再将战斗评价接入局外路线、选牌、事件、商店等决策。

- NOSL：仅依据当时合法公开历史选择行动，不输入隐藏牌序、种子或未来事件。
- SL：允许符合规则的重试及此前尝试合法获得的信息。重试可能保留随机实现，不等于独立重新抽样。
- Oracle：离线研究上限和协同发现，不直接提供依赖隐藏未来的 NOSL 最优动作标签。
- 接受 CombatSolver 的 prediction_only 结果，不恢复逐条 L3 原生认证。关注实际可实现的胜负、HP、药水、遗物计数、永久属性和卡牌变化；无关终局清理不作为准入门槛。发现实际模拟错误再修复。
- 目标模型不利用局内随机数影响局外奖励的关联漏洞；这不意味着不放回抽牌等事件独立。

**2026-11-24 确认的项目游戏规则前提：敌人行动是确定性的。** 给定充分状态及相关玩家行动，敌方行动不需要独立的随机策略分支；状态依赖的确定性变化仍须正确模拟。未知抽牌、随机生成牌、随机目标等真正随机机制另行处理。该前提来自项目负责人的游戏知识，不声称本次代码调查已覆盖每一种敌方效果；若发现反例再修正。结束回合的随机性主要来自抽牌等实际随机机制，而不是假定敌人随机选择意图。

## 3. 搜索与价值的职责分离

闭环：公开历史 → 回合状态图 → 候选后继信息状态 → 分布价值评价 → 合法战术选择 → 完整战斗经验 → 更新价值网络。

确定性回合通过完整搜索获得可达终点集合。若终局效用已经确定、资源变化进入状态且最优价值函数准确，选择终点价值最大的战术即可，不必显式规定成长/防御/爆发类型。随机回合搜索合法条件策略，而非依赖未知抽牌的固定序列。

以 h 为公开历史、μ 为回合内策略、π 为后续策略、Y 为最终战斗结果向量。若 μ 以概率 p_i 到达后继 h_i，则

$$Z^\pi(h,\mu)=\sum_i p_i Z^\pi(h_i),\qquad Z^\pi(h_i)=\mathcal L(Y\mid h_i,\pi).$$

这里混合的是概率测度，不是平均状态或分位数。相关已发生资源变化须计入状态或结果。期望效用目标下可使用 Expectimax；任意非线性风险目标不能直接逐节点贪心。后续研究风险预算、多候选分布或时间一致风险准则。

## 4. 完整回合状态图与等价化

默认完整搜索、状态缓存、循环检测；Beam Search 只作为复杂局面预算不足时的后备方案。

理想条件下（n 张不同的 1 费牌、E 能量、全部可交换且无随机/重复使用），序列与等价状态数分别为

$$N_{\rm seq}=\sum_{k=0}^{\min(n,E)}\frac{n!}{(n-k)!},\quad N_{\rm state}=\sum_{k=0}^{\min(n,E)}\binom nk.$$

5 牌 3 能量：86 对 26；6 牌 4 能量：517 对 57。这只是理论示例，真实图规模与转移成本需要测量。

- K0：保守完整预测状态键；K1：去除无关对象身份与表示差异；K2：更强的机制等价化（可选，未证明安全须隔离）。
- 模拟器内部键与公开信息键分离。等价要求后续合法行动、转移及收益语义相同，公开 HP/能量相同不足以证明等价。相关卡牌实例、费用、修饰、牌堆次序、Power、触发计数、待选择、随机信息和路径依赖资源均须保留。
- 合并节点而不是丢失行动来源：记录全部合法入边、首动作关系及路径见证。
- 普通攻击与格挡的顺序是否重要依赖状态。比较两种顺序的合法性及后继状态（含提前终局）；攻击计数遗物、下一次攻击强化、敌方血量阈值等均可能破坏可交换性。
- 局部可交换性不自动保证全局偏序约简安全。初期模型预测只用于排序和提示，不允许未经验证的硬剪枝。

## 5. 随机性与抽牌

搜索以合法公开历史对应的信念状态为对象。隐藏随机事件只更新信念，公开随机事件在结果可观察时按条件概率分支。敌人意图确定，但塞牌的隐藏位置仍可能随机。多数敌人向弃牌堆塞牌、少数向抽牌堆塞牌和部分插入限制目前来自项目负责人的记忆，留给 SV2A 清查。SV1 的多后继敌方状态机标记只描述 Solver 的实现路径。

已知牌顶可确定转移。未知均匀区用实例多重集合，下一张属于牌类 i 的概率为 n_i/N。单抽优先精确枚举。多张抽牌只有在顺序与触发确实等价时按无序组合合并。真实条件概率同时覆盖目标命中与未命中。目标导向抽牌研究命中、资源可执行性和收益兑现。未探索质量保留在上下界中，网络预测只作为近似值。玩家按新观察决定是否继续抽，计算预算单独管理。通常只在当前回合做完整战术搜索，按需前瞻未来一至两个回合。

少量结果精确枚举，大量结果条件采样，记录真实概率权重及未覆盖质量；搜索选优与独立评价区分。尚未解决的随机机制标记为随机边界，不把固定隐藏种子下的单个结果当作 NOSL 确定性转移。抽牌同时具有资源、协同及信息价值，后续行动可依据已公开抽牌结果调整。不同隐藏实现分别求最优再平均属于 Oracle，不属于合法 NOSL。

## 6. 分布价值网络与战略学习

第一代输出战斗失败独立类别与胜利终局 HP 分布；显式处理治疗、最大 HP 变化、高 HP 合成样本。后续扩展到药水和持久资源联合分布。保留原始样本及共同随机实现下配对结果。

稳定损失 5 HP 与 90% 损失 0、10% 损失 50 的期望相同，尾部风险不同。按分布计算死亡概率、超阈值概率、分位数及 CVaR。SL 还需结合可恢复性、重试成本与分支相关性，不能由单次边缘分布推出最优重试策略。保留期望效用基准，后续比较风险敏感决策。

保留两类边界观察：A 为玩家结束出牌、尚未后续结算；B 为下一回合开始、手牌等新信息已公开。A 可节省枚举下一回合抽牌的成本，B 更直接匹配决策状态；暂不锁定唯一方案。

SV3A 从 PRE0/PRE0B/PRE1 完整历史轨迹的公开决策和实际动作建立终局监督，以 P0/A2 的真实行为版本为条件。共享 PRE1 编码器，一次编码合法菜单后独立输出 V 和 Q。Q 只用已执行动作的观测终局监督。先用蒙特卡洛分类分布训练，再通过同根战斗检验直接 Q 决策和固定行为先验约束。后续每代冻结策略、搜索及价值版本，混合快速 Actor 和搜索增强经验，更新分布后独立评价。当前继续暂缓原 PRE2 PPO。

## 7. 后置的战术预训练与蒸馏

保留条件可交换性、条件行动交互、战术目标可达性和目标条件化策略四类任务。目标语言可由对象、属性/事件、约束与时间视野组成，从分支差异中自动生成有区分度的目标。保留等价、不可比较、不可达、条件反转样本。

$$B^*(h,a,g)=\sup_{\mu:\mu(h)=a}\mathbb P_\mu\{g(\tau)=1\mid h\}.$$

τ 为指定视野的轨迹。完整回合图提供不依赖弱教师的目标可达性监督。截断不等于不可达；不同目标的最优概率未必由同一个策略实现。目标语言只是监督工具，不是最终战略选择的固定瓶颈。

搜索价值系统成熟后生成更强的 Actor 监督、搜索先验及近似筛选标签，实际消融检验战略能力、战斗质量与效率。

各模块可以交错推进。SV1 的 2,048 根全部恢复，覆盖 80 个遭遇。确定性区域完整率 94.92%，所有路径到 A、真终局或 A 后边界的根占 41.60%。仅 31 根（1.51%）完成全部回合路径，均止于真终局。活动状态 P50/P90/P95/P99 为 17/156/337/703，K1 对应的宿主耗时为 17.59/159.78/300.01/681.00 ms。四 Worker 的 8.43 根/秒按回合根计。正式样本 K0/K1 均无缓存命中，重复基础牌控制从 86 个状态、171 次调用缩减为 21 个状态、59 次调用。规范文本时间占 27%，常规 Fork 占 6%。[SV1 实测](m1-sv1-turn-state-graph.md)

现有 A 是提交 EndTurn 前的稳定状态。价值批接口读取真实终局，并以触发前公开状态的 Q 评价 EndTurn 和未知事件。设计允许预算截断或 unsupported 交给廉价 Actor，SV4A 实测采用合法直接 Q。执行见证路径和触发动作后，等新信息公开再规划。保留确定性完整搜索，并行研究随机性、复杂长尾和安全约简。

SV3A 去重后获得 52,091 条训练和 6,057 条验证轨迹，四个模型各训练 20 轮。PRE1 初始化在两种种子上改善分布预测。确认中四个直接 Q 均超越冻结 A2，共同胜局少损失 16.7–20.0 HP。固定 Top-3 减少低支持动作但未带来总体收益。实战风险随实际延续策略变化，需要直接比较同状态的行动差及长局失效。[SV3A 实测](m1-sv3a-distributional-value.md)

SV4A 采用同一个 G0 进行固定权重搜索对照，并各完成 D、S 两代。探索版生产记录不同的实际行为身份，新条件经该行为的完整终局训练。新旧经验按显式配额混合，独立验证和配对战斗同时衡量新条件能力、历史保留、计算成本和延续偏差。[SV4A 协议](m1-sv4a-task.md) · [SV4A 实测](m1-sv4a-search-value-loop.md)

SV4A 实测新增 14,709 场完整经验，四代各执行 960 次更新。512 根确认中，固定 G0 加搜索增加 11 胜，共同胜局少损失 7.95 HP。D2 直接增加 6 胜，胜率差区间下限贴零。S0、S1、S2 同为 464 胜，新条件预测改善与部署胜率持平并存。D2 权重加搜索达到 468 胜。运行墙钟约为同权重直接推理的 2.1–3.2 倍，下一步优先比较选择性搜索的成本与收益，并在独立训练根诊断长局和动作相对价值。[确认矩阵与原始证据](m1-sv4a-search-value-loop.md#独立战斗评测)

### M1-SV1 原始执行与验收协议

1. 复用固定 CombatSolver、PRE0B 常驻宿主及合法行动协议、PRE1 轨迹。新增 `experiments/m1-sv1/` 与 `docs/m1-sv1-turn-state-graph.md`，不覆盖历史证据。
2. 实现预测状态复制/恢复/分支、K0/K1，尽可能在 C# 宿主内完成扩展、批量导出候选与统计。K2 可选，未证明安全须隔离。确保分支不污染父状态或其他分支。
3. 完整图搜索覆盖所有合法行动，包括结束回合、目标选择及待处理选择；检测循环，区分战斗终局、结束出牌边界、未知随机边界与预算截断。无法识别的随机动作标未知；可合法处理的确定性结算可继续到下一公开决策边界。不使用 Beam 或价值偏好剪枝作为默认算法。
4. 冻结至少 2,048 个代表性回合状态，按幕次、遭遇、HP、手牌、能量、机制及复杂度分层。优先用 PRE1 私有根配方及实际行动前缀精确重建，不能将公开观察直接当完整状态；重建失败计入分母。额外构造常规 3/4 能量、5/6 手牌和顺序敏感遗物计数等对照，标记合成来源。
5. 小型确定性图比较无去重穷举与 K0/K1 的可达终点、首动作可达关系、路径回放；覆盖重复牌、触发、阈值、费用、抽牌边界、提前终局、选择、循环。错误修复或保守隔离。这是 Solver 内部搜索测试，不是原生 L3。
6. 逐根记录尝试状态、覆盖率、不同状态数、实际转移数、缓存命中、终点数、随机边界、预算截断、复制/哈希/转移/序列化/通信耗时、内存；报告 P50/P90/P95/P99、最大值及复杂案例。仅在可行子集测量未去重序列数，不虚报大图去重比例。
7. 比较代表性预算与 Worker 配置；明确区分到随机边界的完整搜索与完整回合覆盖率。内部转移/s 或回合/s 不是完整战斗/s。实测条件允许才增加完整战斗吞吐对照，不假称随机边界已解决。
8. 保存冻结清单、版本/代码/配置哈希、复现命令、可恢复运行账本与逐根证据。大数据及权重留本地；提交代码、配置、测试和报告，用户按既定流程通过 GitHub Desktop 推送。

主要判断：普通回合图是否足够小、分支是否足够快、随机边界是否是主要瓶颈。成功不预设节点上限、胜率提升或原单轨迹吞吐；若少数复杂回合耗费主要预算，则单独处理；若多数回合过昂贵，则先优化分支与约简，再考虑网络引导。

条件族、具体随机实现和已公开决策状态分开记录。死亡概率、期望净战损和累计损失依赖所部署的策略。复杂度按静态互动与固定图预算下的公开分支测量。搜索收益表示当前策略的能力缺口。所有受测策略失败只能记录为当前未找到胜路。用独立世界复评经验强策略。

正常构筑的长期目标是接近必胜。生存风险足够低时，主要目标变为降低战损和保留持久资源。复杂协同、容易生存且仍可减少战损的样本保有高训练价值。训练池可动态扩展，开发、固定基准和挑战池保持独立。

II-E/v4 的对数＋线性目标使用截零净战损。DC1 恢复这一对照，并在离线用精确累计损失评估混合曲线。PRE1 的 HP 比例效用保留为历史基准。SV3A 的 999 HP 胜利比例桶相距约 32.23 HP，低战损学习需检验绝对净战损、累计损失、资源增长及其桶内联合信息。
