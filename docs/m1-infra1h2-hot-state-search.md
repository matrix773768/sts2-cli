# M1-INFRA-1H2 · 完整 Hot 状态与回合搜索

修正遥测的 1A 继续作为生产默认。新增的 `h-state` 在冻结自然面板上独立完成了 **1 个完整 Planner 回合**。该回合来自面板索引 0 的真实机械骑士战斗，涉及 41 个图节点、严格 G2 参考搜索以及 280 个条件查询。全自然面板有 607 个 Planner 回合，这次迁移占 0.165%。按修正 1A 的逻辑调用数加权为 1,305 / 340,976，即 0.383%。该回合最后由门控选择原 G2 动作；Hot 实际承担了作出该门控决定所需的搜索。

分支从 `ee1c1d6896b00b39912982912633d07602bf9d53` 起步。上游 CombatSolver 1.0.2 固定在 `131d10ae4499b56332787af61fe4a9306e65860f`，HotDraw 插桩二进制 SHA-256 为 `87aa4c0775b2c60a733186adeb161e98ac23c0e9d0d5c542a5aed2781d0fd899`。本轮复用了既有 G2、V2、面板、预算和经验写入器。

## B · 独立公开分支与战略 C

搜索入口从公开资源、可见牌区、公开计数和静态规则构造 Hot 值。机械骑士适配器从已知的首回合行动开始；尸蛞蝓适配器从已公开的上一个 C 与当前 B 恢复三只敌人的存活槽位、最大 HP、行动历史和 Power。规则注册表从同一战斗的原生初始化取得。分支中的生命、格挡、能量、手牌、选择、抽牌与敌方结算均在 HotKernel 中执行。搜索态的 RNG 为零，抽牌由公开信念提供合法实例，分支按原始无放回概率展开。初始未知实例按公开类型规范编号。

稳定子节点保存 17,256 字节的 `CombatHotState` 值、HotKernel 的 Cold sidecar 和不可变抽牌信念。子节点与兄弟分支共享未修改的 Cold 数据。选择确认及公开随机暂停从最近稳定动作父节点重执行；缓存经验证的公开事件地址与输入前缀。释放句柄同时释放关联前缀。实际环境仍由原宿主推进。

C 钩子位于敌方行动和回合准备完成之后、下一轮初始抽牌之前。由此导出牌区、实例费用与静态变量、公开信念、Power、敌方行动、资源及待执行钩子。当前独立导出资格覆盖经验证的费用和机制，遇到未支持的费用层、牌序变化、敌方机制或目标变更时返回具体原因。牌堆计数的**公开枚举顺序**也是冻结编码的一部分。早期版本将它按类型排序，尽管 C 字典比较相等，编码张量行序发生变化。最终导出沿用合法公开历史的计数顺序，数量来自 Hot 子状态。

六个真实机械骑士开局的一步差分得到 19 个普通或待选 B、3 个 R、6 个 C 的相同回复；8 条路径报告未支持。另有 33 个首抽后继得到相同回复。6 个根直接结束回合的完整 C、编码张量和同输入 V2 值均相同。在同一公开根下，三组不同的实际发牌、种子和公开实例编号得到同一搜索输出摘要。详见[分支差分](../experiments/m1-infra1h2/evidence/branches.json)和[公开信息测试](../experiments/m1-infra1h2/evidence/invariance.json)。

这两个子域的独立假设差分中，已验证的假设终局数为 0。原生实测胜利与私有轨迹终局属于 A 类。Hot 分支内部保留终局、HP、最大 HP 和金币，冻结参考终局投影只取 HP 和最大 HP；通用药水、遗物计数及跨战斗持续资源仍缺完整差分。非开局状态仅在尸蛞蝓专项中接入了公开历史。Cold sidecar 的共享沿用上游写时复制，本轮另外核对了兄弟分支互不影响以及已释放句柄失效。

### 5E 独立复评根 123

此处的 123 对应原自然训练索引 **87**、第二回合、三只 CORPSE_SLUG。初始公开牌堆有 9 种可能，玩家带 FRAIL，三只敌人各有 RAVENOUS 和不同的行动历史。该根在历史修正 1A 复评中用时 80.98 秒，占该负载约 71.7%。

独立 Hot 在该根上匹配了 35 个冻结回复，包括多目标绑定、普通决策、复杂抽牌的中间 R 和 10 个抽牌前 C。对已归档的两个方案，`graph/3` 的 SHRUG_IT_OFF 产生 9 个条件 C，`graph/1` 的 FORGOTTEN_RITUAL 路线产生 1 个 C。两条路线均复现公开状态、完整概率分布、冻结编码和同批 V2 值。归档菜单对更大集合一起估值，本次按方案单独估值，与归档菜单效用相差约 0.00000085 / 0.00000763。这里复现的是给定方案的独立执行及回传。根 123 的完整 G2 搜索遇到 CASCADE，约简图还缺多目标及随机后继的候选约简，当前 5E 菜单生成、条件世界续战仍全部走修正 1A。详见[根 123 的实际输入与逐边收据](../experiments/m1-infra1h2/evidence/slug123.json)。

## C · 完整冻结 Planner 对应

索引 0 的开局包含 IRON_WAVE、HEMOKINESIS、DEFEND_IRONCLAD、BURNING_PACT 和 FORGOTTEN_RITUAL。Hot 生成全部约简图节点、边、顺序、剪枝计数、联合向量和前沿。冻结 Python 控制器继续执行候选选取、严格单样本 G2、V2 估值、条件程序组合和门控。根据公开能力判断选择后端；若候选中途遇到不支持的机制，丢弃全部 Hot 结果，在未推进的真实根上按原逻辑预算重跑 1A。

| --- | --- |

单独测得该真实根的完整 Hot Planner 约 0.77 秒，对照约 1.26 秒；这一次测量不代表整场。两个实现均通过同一正常 Planner 入口。旧宿主物理复制、CLR 实际分配字节和网络包数量没有单独归因；上述数字是 Hot 内部实测计数。另一个简化牌组回合也通过全图和完整 Planner 验证，未加入自然面板分母。详见[完整策略对照](../experiments/m1-infra1h2/evidence/turns.json)和[前缀复用前的计数](../experiments/m1-infra1h2/evidence/before-prefix-reuse.json)。
