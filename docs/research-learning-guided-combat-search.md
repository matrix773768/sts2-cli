# STS2 AI：学习驱动极速战斗搜索主线（2026-11-19）

> 状态：**已确认的新研究主线；工程闭环尚未实现。** 本文件是未来开发的最新路线依据，不取代实际代码、阶段验收报告或 [PROJECT_VISION.md](PROJECT_VISION.md) 的长期目标。
>
> 基线：\`port/v0.113.1\` 在 M1-N2F-A.2 之后。原先 N2F-B 的固定弱策略卡组价值预测试验暂缓；N2E 机制合同继续复用。以 [PROJECT_STATUS.md](PROJECT_STATUS.md) 为准核对实时进度。

## 1. 新的主要研究问题

**能否让学习器根据合法可见的卡牌机制、构筑与战斗状态，预测值得尝试的战略或动作，从而使现有高速预测及 F3B/F4 搜索器在相同真实预算内更快地找到合格胜路，并在获得胜路后改善战损？**

长期将这种高质量、低成本的战斗求解能力用于局外卡牌、路线、事件和资源决策。最终衡量标准仍是**正常 SL 规则下的完整跑局表现**，而非单场神经网络预测误差。

主闭环：

1. **可信规则与数据**：原生／CombatSolver、公开 Observation、N2E 卡牌语义与合规根；
2. **搜索采样**：冻结 F3B/F4 或可核实的合法搜索，生成候选、完成与失败反馈、战略差异；
3. **学习**：训练公开信息条件的战略／动作先验与风险、价值辅助头；
4. **搜索接入**：在相同预算内使用学习先验调整战略提出、动作顺序或候选分配；搜索负责执行与验证；
5. **闭环评测与再采样**：比较完整胜路、资源与成本，对困难／多样构筑定向采样、冻结模型版本后迭代。

学习模块是**搜索指导器，不是规则模拟器、正确性裁判或不可绕开的上线前置依赖**。初期应保留原 F3B/F4 默认行为及可回退开关。没有验证的模型不进入生产默认路径。

## 2. 为什么不继续把小规模胜负预测作为前置关口

- N2E 已实现 22 张卡的静态机制合同、身份／机制表示、CardInstance 与 DeckSpec；4 张带显式缺口，部分动态预览仍为 null。
- N2F-A 在固定 initial-mean 下执行 320 条完整路线，143 胜／116 死／61 次动作上限截断；61 次截断集中 Shiv 构筑，正常终局覆盖不足，原协议在资格关停止，未进行原计划正式训练与报告。
- N2F-A.2 重用该 320 条数据，对 96 步内胜／死／未结束做十个背景的五折探索性训练：结构化机制 Log Loss 0.8288，Card ID 0.8607，简单机制统计 0.8136，分组先验 0.8293。**没有稳定超越简单对照**，且结果仍主要是弱冻结策略的有限预算行为预测。

这些实验验证了输入和训练流水线，不能证明共享表示无效，也不能作为新路线“先学会弱策略卡组胜率”的硬门槛。以后仍可开展条件战斗分布建模，但要明确**所评价策略、动作预算和策略偏差**，不把它混同为卡组内禀价值。

## 3. 模型与搜索的接口

- **共享机制编码**：复用 N2E 的有序效果、卡牌实例与公开合法状态；可将 Card ID 作为单独消融，不用未知效果的零填充冒充已知规则。能力逐步扩展到更多卡、遗物、公开牌堆／历史与真实可达根。
- **模型输出**：优先考虑战略级先验（AGGRO／DEFENSIVE／ENGINE 及机制条件的战略参数）、合法动作排序与搜索预算分配。第一轮只需选**一个最容易审计且接入成本较低的切入点**，不要同时重构 F3B、F4 与战斗求解器。
- **可训练对象**：\`prior_\theta(z_{\rm public},z_{\rm deck},a)\`、\`prior_\theta(z_{\rm public},z_{\rm deck},\text{strategy})\` 或受限状态价值／失败风险头。训练时可用搜索反馈作为条件期望、成对候选比较或排名信号；**不是把单个隐藏 RNG 的最优路径当作公开状态下的监督真值**。
- **经验合同**：记录任务前可见的入场／局中公开字段、候选战略／动作、分配预算、完整合法预测结果／截断／未找到、资源质量、模拟版本与时间。内部根、RNG、私有续体、分支结果仅限离线标签／审计，不进入正式推理。分开记录 candidate-proposal、search-probe、full-route 和 native-L3 证据。
- **有效性条件**：学习先验可以改变**搜索顺序、候选生成或在明确预算下的资源分配**；不能直接声明模拟结果正确，更不能用模型分数代替合法胜路检查。若策略建议无效，必须有原基线回退路径。

### 信息集与教师偏差

正常 SL 只允许在已进入的当前节点内进行合法存档／重载试探；跨节点选路不可回退，也不能把未进入的其它地图节点真实后果当作当前信息。第一次尝试的 NOSL 学生只看当时公开信息，后续合法重试可利用**已经实际揭示**的本节点知识。

搜索器可以离线使用精确内部状态复现模拟，但训练标签要按任务解释：
- 某一具体隐藏 RNG 下找到胜路是**该根上的搜索结果**；
- 公开状态条件的动作先验需跨多个合规种子／历史统计或使用不依赖隐藏未来的可验证辅助任务；
- 使用全知分支数据可用于**离线对照、失败机制、候选好坏评估或训练有合法含义的统计目标**，不得直接把全知动作当 NOSL“正确答案”；
- 不允许将搜索器消耗的 RNG 或预测未来编码为模型推理特征。

## 4. 训练数据与预算：追求多样、可复用、经济

与其用少量合成构筑重复生成终局，不如建设具有增量、缓存、版本、分组和质量标签的搜索经验流水线。

- 来源分开：synthetic、开发可达根、严格真实历史可达根；不将“可从原生人工构造”宣称为自然可达。
- 覆盖卡组机制、角色、敌方机制、入场 HP、遗物／药水、幕数和难度；保持训练／选模／独立报告按局史、构筑家族、机制与 RNG 配对块分组。
- 经验优先来自**有明显决策差异**的根：战略 A/B 不同、基线未找到胜路而替代先验可能覆盖、临界资源／风险状态和稀缺机制。避免全部以弱策略是否死亡作唯一标签。
- 保存可重用特征、根规格、候选、搜索前缀及原子结果；只有可证明等价的具体模拟状态才能复用精确结果，不以相似公开状态共享特定 RNG 的后果。
- 采样成本包含原生建根、训练搜索、学习、模型推理、在线探索／修复、验证和 worker 回收；区分热计算与端到端。不同预算对应不同质量标签，不合并为同一个“真实最优”目标。

允许比 N2F-A 更有代表性的中型实验，而不是连续用小样本“门槛”否决方向；但先基于实际系统吞吐制定可承受总预算，并优先保证闭环端到端可运行、具有回退及报告分组。

## 5. 核心评测（新主线的价值判据）

相同版本、硬件、战斗根、真实推理预算和正常 SL 规则下比较：

1. **首次胜路发现**：发现完整合法预测胜路的比例／时间／预测转移数；未找到、截断和模拟不支持单列，不能把未找到当无解。
2. **胜路质量**：在一致的成功定义下比较锁定战后 HP、药水消耗和其它后续资源，勿用低战损掩盖死亡。
3. **质量—成本曲线**：固定多档计算预算，比较 F3B/F4、其固定战略消融、学习指导版；模型推理成本计入端到端，报告相同质量下的速度及同成本下的收益。
4. **泛化**：至少按构筑背景、敌人、机制族和局史切片；原生真实可达根逐步补齐。训练样本、开发调参、模型选择、未见报告相互隔离，不能把被多轮观察过的开放数据称为盲测。
5. **低预算稳定性**：即使学习先验不正确，也不能使搜索崩溃、绕过合法动作、错误认证胜路；生产默认基线不变，可严格回退。

在这个阶段，模型本身的 Log Loss、Brier、动作匹配率可以作为**辅助诊断**，不能替代搜索胜率与质量—成本曲线。

## 6. 新的工程里程碑（工作代号 M1-LS）

### M1-LS1：搜索经验与学习指导接口的纵向切片

**优先实施。** 不再单独测试一个离线卡组预测器，而是在现有 F3B/F4 冻结代码附近实现一个最窄可运行闭环：

- 核查实际候选战略与动作排序接口、搜索调用成本及公开观察可用性；
- 选定一个低侵入的先验注入点（优先候选战略／路线顺序；若无法稳定注入，报告原因并选择合法的替代切入点）；
- 用现成公开根抽取带版本的搜索候选与反馈数据；在合理开发预算内增加机制与构筑覆盖；
- 训练一个**小型、可保存与可复现的学习排序器**（可以从机制编码＋轻量模型开始，不限定 PPO/Transformer）；
- 同一开发分布下完成 **基线搜索 vs 学习指导搜索** 的真实预测端到端 A/B。记录反馈质量与推理开销；
- 保持 F3B C/F4 冻结默认及已知差分合同不变，允许关闭模型即逐项恢复默认结果。

本里程碑以**闭环联通和首批可审计质量—成本数据**验收，不要求模型立即超过 F3B/F4、达成人类级胜率或上千倍吞吐。不允许为了得到正面结论自适应修改报告根。

### M1-LS2：增量数据生产与机制泛化

基于 LS1 真正测量的瓶颈，建设常驻／并行（在独立验证下安全）、完整轨迹压缩、困难条件定向采样与成组留出；扩大卡牌机制和可达根覆盖，研究跨构筑的搜索收益与模型不确定度，比较简单人工战略、ID 和机制编码。

### M1-LS3：学习战略—搜索—修复迭代

引入多预算战斗搜索与合法节点内修复，从胜路及失败前缀中反复产生经验，冻结模型版本、再评价真实 SL 质量—成本曲线。可考虑政策蒸馏、搜索指导价值、轻量强化学习，但必须计入总成本和合法信息边界。

### 后续：局外共享编码器与长期规划

当战斗求解的覆盖、成本、质量有稳定证据后，复用卡牌编码器并使用实际版本的战斗求解器生成节点结果**分布**，训练奖励／跳过／升级／删牌／路线等长期决策；以正常 SL 完整跑局胜率为最终评估。
