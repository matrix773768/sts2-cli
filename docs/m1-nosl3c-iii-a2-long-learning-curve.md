# M1-NOSL3C-III-A2 长程学习曲线与价值诊断

**84 次更新全部完成。** 在同一批 48 个独立开发根上，更新 84 相比初始化多取得 3 个 Sample 严格胜局和 6 个 Greedy 严格胜局。共同胜根平均战损分别降低 44.44 和 23.68 HP。Sample 的战损改善随训练较稳定，Greedy 的胜局增益在更新 12 已出现，之后波动。Critic 的均值缓慢上移，对胜败仍缺乏有用的幅度区分。下一轮优先做有对照的价值学习诊断，保留本次 v4 路径作为基线。

## 协议和复现门槛

起点为 `port/v0.113.1@406a59a0a95e4e886ee54f387b1bc91e9dbe2671`。沿用 II-K.5 冻结部署、P1 的 4 worker、II-E v4 严格训练。五角色、三幕、全池、999/999 HP，24 根/更、每根一次 Sample、128 动作上限、microbatch 4、auditor limit 4。模型、优化器、探索、mixed 奖励和严格认证合同沿用 A1。

训练前冻结 84 批和 48 个新评价根。训练种子与 A1 相同，前 12 批根规格逐项一致，行为种子按同一索引规则派生。更新 12 的模型 SHA-256 为 `beb98aefb2ad295b30fbbc5c0be0a8ef2de6dc8ee2420af99155b3c7deb8b428`，与 A1 一致，含模型、Adam 和 Torch RNG 的序列化快照也逐字节一致。通过后继续。评价根种子 73192202，行为种子域 43192202。2,064 个原生种子内部唯一，核对其与 P0/P1、A1 开发评价、II-K.5 两个固定套件和三份历史冻结账本无重叠。封存账本只读根种子。

全部 85 个训练快照及 2,016 个根和审计哈希通过只读校验。训练结束后在同一评价集串行执行全部十组，Sample 各检查点复用逐根行为种子，Greedy 在公开合法动作菜单取概率最大项。评价未参与优化或模型选择。预定快照 0、12、36、60、84 均读回重算模型哈希。更新 84 模型为 `180b1141d52fe836d5b7770c90c7be193c1c9a8b86bfd7e152274f2e8cd540a6`。

## 价值与优化过程

预测取首决策标量，实际值取同条严格终局的 mixed 回报。AUC 指胜局的预测高于败局的概率，平局计一半。评价每组严格败局最多四条，AUC 对根组成和极小预测差异敏感。Greedy 的实际回报还来自与训练不同的动作选择规则。

## 严格准入与成本

2016 次尝试中 1419 条（70.4%）进入训练，共 44,737 个转移。准入样本中 1270 胜、149 败，分别占样本的 89.5% 和 10.5%。按原始尝试计，严格胜占 63.0%、严格败占 7.4%。预测明确胜的 1270/1349（94.1%）和明确败的 149/161（92.5%）通过。其余 597 次分为规则风险 340、截断 96、原生差分 91、不支持 70。340 条 E3 终局风险占全部拒绝约 57%。资格按路线与机制选择，删去风险、困难长战及机制不支持会改变梯度看到的分布，已认证样本的胜率不能代表全分布。

差分按审计首差聚类，训练较多见的簇为 Sovereign Blade 续体 14、Fight Me 续体 8、MoveToDrawTop 菜单/动作 8、敌方阶段死亡边界 6 和 Discard 菜单/动作 6。不支持分为一般预测不支持 37 与 PendingChoice 33。评价另有 9 次 Claw 续体差分，跨检查点重复计数。簇记录首差现象，机制根因待验证。逐根审计及簇索引留在本地。

训练主墙钟 3554.74 s（59.25 分），其中采集和根事务 3369.58 s、优化 183.37 s、更新后 SQLite 快照提交 1.79 s。训练阶段采样合计 3561.82 s、10642.72 CPU 秒，峰值同时工作集 1492.73 MiB，训练启动宿主 4005 次。独立评价另用 793.21 s（13.22 分）。两段测得阶段墙钟合计约 72.6 分钟，冻结清单、阶段启动及离线分析另计。训练为 0.567 尝试/s、0.399 合格条/s，尝试速率与 A1 的 0.567 一致，低于 P1 单批的 0.610。认证累计 4681.00 worker·s，包含在并行采集阶段。训练和评价记录的 4965 个宿主生命周期均正常退出，未触发恢复。

## 复现

从仓库根执行并指定新目录，沿用本机冻结部署和 A1 原始证据。训练入口保持 SQLite 断点续跑、STOP 和每更快照。计划内停止后使用同一目录和相同配置恢复，保留先前证据。

```powershell
$env:PYTHONUTF8 = '1'
$out = 'logs/nosl3c-iii-a2-repro'
$curve = 'experiments/m1-nosl3c-iii-a2/curve.py'
foreach ($mode in @('freeze', 'train', 'evaluate')) {
    python $curve $mode $out
    if ($LASTEXITCODE -ne 0) { throw "A2 $mode failed" }
}
python experiments/m1-nosl3c-iii-a2/analyze.py $out
if ($LASTEXITCODE -ne 0) { throw 'A2 verification failed' }
```

本次输出位于 `logs/nosl3c-iii-a2-01`。其中 `results.json` 含逐更终局回报与 Critic 预测/误差分布、优势统计、逐检查点胜败配对和差分簇。训练 SQLite、逐根路线与审计、全套模型与 RNG 证据保留于原目录。
