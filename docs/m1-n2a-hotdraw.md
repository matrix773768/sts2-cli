调查起点 `863ac39b846dc1ef10773b10402ba7bc7caf824a`，分支 `port/v0.113.1`。实验使用 HK1A 冻结的 CombatSolver 1.0.2 `131d10ae4499b56332787af61fe4a9306e65860f`、STS2 v0.113.1 Build 26660232 和 CoreCLR 9.0.7。实现、夹具、构建及运行脚本位于 `experiments/hotdraw/`。构建核验原始 ZIP 和游戏 DLL 的 SHA-256，在新目录内解包并按冻结锚点插桩，记录覆盖代码、Solver、Harness、.NET 及 RitsuLib 文件身份。HK1A 的固定世界 Oracle、生产 HotSearch、旧 NOSL 模块、冻结产物与数据按原入口保留。[N2A.0](m1-n2a0-technical-investigation.md) · [M1-N §16–18、§24–26](m1-n-research-design.md) · [M1-SV §6–11、§22–24](m1-sv-research-design.md) · [HK1A-Perf](hk1a-perf.md)

## 实现与公开信息边界

| 组件 | 实现与契约 |
| --- | --- |
| [构建覆盖层](../experiments/hotdraw/build.py) | 在冻结副本的 `DrawCards` 移动牌顶前插入解析器，在 `HotPiles` 监测 Move、Remove、Add、Shuffle，及在 `HotRng` 原始消费前设守卫。三个 `RequestChoice` 入口保留选择过滤，研究时枚举到实例级。未挂载解析器时走原执行分支。 |
| [公开信念](../experiments/hotdraw/Belief.cs) | 有序顶、按稳定身份排序的可交换未知实例、有序底、洗牌代次。顶优先，中段逐实例以 `1/N` 赋权且无放回，最后取已知底。洗牌增加代次、清空顶/底约束并用当时弃牌重建未知集合。未观察整堆排列。 |
| [根绑定与试探](../experiments/hotdraw/Session.cs) | 稳定玩家根由受信任调用者提供公开组成、位置约束及原生 UID 到研究实例的映射。夹具用显式注入配方作为实例来源。导入重映射卡牌、Power 引用、挂起卡记录和 Cold 附件，保留完整实例结构，含动态量、附魔、费用及溢出修饰。公开根按研究身份重构未知区，清空原生 RNG。公共 JSON/键使用公开字段和命名定义，排除真实牌序、原生 RNG、敌人私有 AI 状态及内部定义编号。键供审计比较，搜索不做合并。 |
| [随机事件及选择](../experiments/hotdraw/Resolver.cs) | 带序号、来源及结算阶段，记录剩余抽数、嵌套深度、支持集、概率、观察时点和已消耗前缀。选择与抽牌分别保存输入，按同一序号空间校验，地址包含事件种类、来源、阶段、深度。研究随机结果从不写进玩家菜单。 |
| [研究搜索](../experiments/hotdraw/Search.cs) | 单线程、无 Beam 和转置。稳定决策和真实选择取 max，自动结算调用冻结热核。NOSL 对公开抽牌结果取期望，Ideal 在指定普通抽牌节点取 max。未观察的洗牌只更新后验，共享同一后续决策。逐实例事件仍可重放，只有热核确认实例字段等价且无 UID 引用时，才按公开结果合计概率并共享续策。研究 Oracle 使用原牌序和 RNG 的有限树，另保留原版 HK1A 搜索入口。 |

部分执行以专用控制信号退出冻结调用栈，`Step` 和嵌套抽牌的 finally 在捕获前完成。每次试探从父 hot 值、写时复制 Cold、独立信念进度、干净 Scratch 和对应 RNG 模式重放。已有选择被逐次校验，未消费输入报 Error。暂停返回事件、`NeedsChance` 或 `NeedsChoice`，由调用者扩前缀后重放。非法输入、容量或未建模路径使用独立错误/边界，只有 Completed 发布完整子状态。终局由 `HotCombatOutcome` 单独记录。

普通耗尽洗牌使用可交换条件模型。公开分支让原洗牌代码负责移堆、计数和 Hook，替换顺序生成，延迟到逐张可观察结果处再展开。固定世界的私有审计保留原生洗牌算法和流计数，每次 `UnstableShuffle` 的外层 `NextULong` 与研究逻辑洗牌事件对应。研究分支使用公开后验，无需真实 RNG 来补全结果。均匀模型适用条件由根提供，并未对任意历史下的原生 PRNG 条件独立性作证明。

重复实例的比较复用 `AreChoiceEquivalentCards` 对状态引用、Cold 费用/变量、升级、活跃费用修饰、附魔和卡牌动态字段的检查。已资格化路径中，满足该检查的未知副本只相差研究身份，目标与玩家动作对这种重命名保持一致。按单张公开结果保存一个代表的续策，同时保留各原始事件的实例索引。会使不可见实例差异影响续策的更复杂根仍需增加信念语义。

## 已接入机制与边界

- 受测普通抽牌包括单抽、连抽、顶/底约束、空堆和多实例重洗。以冻结代码逐张重新建立支持集；正在结算的 Play 区按原顺序离开。
- 受测公开确定性触发包括 The Abacus 洗牌格挡、Void 的抽牌失能、Iteration 实际二层抽牌、Dark Embrace 耗尽后抽牌。Prepared 在两次抽牌后出现真实弃牌选择，Burning Pact 先选择耗尽再触发抽牌。Headbutt 从弃牌区回收到已知牌顶。满手、No Draw、无牌可抽和提前终局具有独立检查。
- 跨回合限定于受测弱 Fuzzy Wurm Crawler 遭遇的合法路径。回合开始手牌按每张事件结算。其他遭遇、未资格化的卡、Power、遗物、附魔及更一般的根约束保留诊断边界。
- Havoc 的牌顶自动打出、PerfectFit 改序和 Confused 的随机费用已有拒绝夹具。非空重洗、未知牌区的非普通取牌、嵌入未知牌堆内部的移动、随机生成/费用/目标等路径通过内容白名单和事件守卫退出。规则注册/镜像序号和冷数据保留供执行，哪些字段可公开仍需完成新机制资格后逐项扩展。
- 本版输入是配方或可信历史已提供完整公开组成的稳定根。普通动态更新已覆盖列出的游戏机制。任意原生根的公开历史重建、复杂开手规则、多段位置约束、隐藏随机插入或先发生并延后观测的通用信念分组留待后续。搜索入口未包含药水。效果超出书面和测试覆盖时，按未建模路径处理。

## 正确性、原生对账与搜索结果

验收由 [原生夹具 Harness](../experiments/hotdraw/Harness.cs) 和 [运行脚本](../experiments/hotdraw/check.py) 执行，机器结果见 [results.json](../experiments/hotdraw/results.json)。

Solver 与 Harness 的 Release 构建均为 0 警告、0 错误。15 个独立小夹具全部通过。另执行冻结 Harness 的 `--check-hot-layout`，7 项全部通过，覆盖布局、打包与结构相等、千次 RNG 对齐、牌区与费用生命周期。原生对账覆盖下述定向路线。

### A · 概率及公开信念

`draws` 的两张打击与一张防御分别得到 2/3 和 1/3。相同打击共享一个公开结果和续策，修改费用和动态变量后分开。三张牌连抽两张逐实例回放 6 条有序路径，每条 1/6。已知顶先取、已知底保留到中段耗尽，拒绝不可交换根。`known` 验证 Headbutt 置顶，`nested` 验证弃牌，`exhaust` 验证耗尽及 Dark Embrace，`shuffle_multi` 验证三实例重洗后两抽的 6 条有序路径和概率总和。空堆、禁止抽牌、满手与提前终局均未产生额外事件。

### B · 分支隔离与事件重放

A/B/A 和反向遍历得到相同子状态、事件和合法菜单。Prepared 的事件顺序为第一次抽牌、Iteration 二层抽牌、玩家弃牌选择，重复试探之后只结算两张抽牌、一次 Void 失能和一次弃牌。错误事件序号、非法抽牌 UID、过期选择与未消费前缀均报 Error。

### C · 公开信息公平性

`order` 互换两张真实未知牌，替换私有 Shuffle 流，并重编号原生实例后重新映射。得到相同公开键、候选及顺序、条件概率、指定结果后的公开键与合法菜单、公共事件记录、Ideal 和 NOSL 的首动作及价值。把两根的公开已知牌顶设为不同卡，公开键随之变化。

### D · Oracle 与原生对账

Prepared、Shrug It Off 和结束回合分别核对固定世界捕获、指定脚本重放、同构建默认 Step 及原生执行。固定世界路径与默认 Step 的打包热态及 Cold 相等，原生牌区顺序和实例语义键、HP、能量、格挡、敌方意图、Power、抽牌/出牌历史及 10 路 RNG 状态相符。Prepared 的原生选择候选序列一致且收到一次选择请求。Shrug It Off 触发 The Abacus，原生结算 14 格挡、消耗一次 Shuffle 流。原生导入不还原热核局部 ShuffleEventCount，原生对照采用 RNG 增量，热核内部另验计数。结束回合出手 HP 66、能量 3，按日志抽五张。普通出牌斩杀另核对原生 Victory。完整原生 RNG 只在进程内比较，机器结果保存各流增量。

### E · 可手算的搜索语义

确定性斩杀、单抽斩杀和连抽联合目标分别通过实际热核搜索。先选择再观察的手算树给 1/2，先观察再选择给 1。保留 1/4 未解决质量的手算树报告下界 1/2、上界 3/4；事件预算为零的受测斩杀根保留未解决质量 1。对选择性 Ideal 关闭该节点取 max 后，回到 1/2。固定合法后续策略与精确 NOSL 同为 1/2，指定节点放宽后 Ideal 为 1。

## 成本与复现

| 项目 | 本次结果 |
| --- | ---: |
| 冷启动加原生根准备，15 次最小／中位／最大 | 3.30／3.46／3.60 s |
| 固定世界 Pommel Strike 直接 Step，探针未挂载 | 4.28 μs |
| 指定结果下研究单抽／双抽 Step | 16.72／24.35 μs |
| 单抽三实例分支／双抽六有序实例分支的总成本 | 134.70／202.53 μs |
| 17,256 B 热态复制及读取 | 1.59 μs |
| 双抽试探的信念和位置更新计时 | 3.27 μs |

微测每项 500 次，研究路径先做 100 次暖跑。直接 Step 使用同一构建的默认热核路径，包含值复制，不含 Pack/Hash 和研究快照开销。信念计时包含抽牌解析、等价检查及重定位，属于 Step 的子集。实际搜索的首个 NOSL 运行包含首次 JIT 等开销，六个计时根为 0.11–186.03 ms。以同进程随后执行的 Ideal 为例，连抽联合目标展开 10 节点、5 个完整转移，用时 0.412 ms，其中 7 次前缀重放共 0.144 ms，约 24.3k 节点/s 和 12.1k 完整转移/s。随机深度 1 有 2 个事件节点及 6 条实例边，合计展开 4 个公开后继。深度 2 有 2 个事件节点及 4 条实例边，合计展开 3 个公开后继。双卡核心 38 节点、19 个完整转移，用时 0.325 ms。短根计时易受 JIT 和环境波动影响，微测与端到端搜索均不外推训练吞吐。主要可测成本来自多次恢复、Scratch 与子状态构建，信念维护成本随牌组、实例和事件复杂度增加。

构建和运行使用新的输出路径。以下命令在仓库根执行。

```powershell
python experiments/hotdraw/build.py logs/hotdraw-build-new --archive ../hk0-isolated-131d10a/upstream.zip --steam "$env:USERPROFILE/Desktop/STEAM"
python experiments/hotdraw/check.py logs/hotdraw-build-new/build.json logs/hotdraw-check-new
```

运行脚本逐例新建进程，每个夹具上限 35 秒，三个小搜索模式使用明确的节点和视界限制。冷启动包含游戏程序集初始化、原生建根与夹具注入。性能分栏测量值复制、固定世界 Step、公开试探、单抽/双抽枚举、信念与前缀重放。抽样只描述当前研究宿主和负载。

## N2A.2 接口

下一阶段可将研究搜索的动作/事件见证和父快照交给独立的重复验证器。对同一公开协议保持成对的 Oracle／NOSL／Ideal，记录统计支持与实际可重放路径。启动、有效输出和失败预算分别计量。任何候选周期均逐步验证实例、费用、Power、计数器与敌人状态。两卡夹具中已有可复放的短周期轨迹供首批候选；数学无限证明和正式循环提取留在后续阶段。当前结果未启动训练、常驻宿主改造、DC3A 扩展或正式评测。
