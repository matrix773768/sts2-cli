# M1-SV4A 搜索增强与持续价值学习闭环

采用与 SV3A 相同的单人 Ironclad 合成战斗分布及 prediction_only 合同。游戏 STS2 v0.113.1 Build 26660232、CombatSolver 0.51.5-iik.3b，CoreCLR 9.0.7。历史证据继续单独保留。工作包含搜索对照、直接路线 D、搜索路线 S 各两代生产和价值学习。[任务与验收](m1-sv4a-task.md) · [SV3A](m1-sv3a-distributional-value.md)

## 冻结与搜索合同

共同祖先 G0 使用 PRE1 初始化 71393001 第 20 轮，权重 SHA-256 为 `3f60c9820379fa8417bf25554b92855754803e494f41851c721ea1f3d7e03dbf`。与该轮 `resume.pt` 的模型张量逐项相等，绑定的优化器先前执行了 8,840 次更新。G0 的价值条件为冻结 A2，在历史 SV3A 开发和确认集分别赢 456/512 和 449/512。SV4A 用新冻结根重新测量。

SV1 的独立 overlay 保留原预测复制、合法菜单、未公开事件探针与边界分类。公开线协议以未合并的树保留每条入边，省略内部状态键、RNG、隐藏牌序、内部摘要和重复序列化的整条路径。按公开观察重建历史和可执行见证，同一稳定节点一次批编码评估全部合法动作。A 和未公开事件触发点用 Q，真终局直接计算效用。Solver 中尚未核实的敌方内部路径仍受 SV1 守卫控制，不将其解释为真正随机的敌人意图。

所有合法首动作的直接 Q 都参与排名。这是搜索停止方案，执行对应一步，随后在真实公开决策重新求值。更优边界则执行经核对的完整确定性前缀。预算、unsupported 和无法逐次恢复的组合待选仍有原地直接 Q 候选，不赋终局或可达性标签。遇到计划状态不吻合，会清除剩余前缀。下一步公开状态始终由实际预测战斗给出。随机触发器之后不沿旧路径继续，A 提交之后同样重新观察。终局效用对照每次实际收到的胜负和 HP。

生产每次实际决策先以 .05 概率抽取合法均匀探索，抽到不同动作时丢弃剩余计划；否则遵循当前确定的选择。所记概率是该步在已执行历史及规划口径下的真实混合条件概率。低支持仅用冻结 PRE1 参考 Actor 做离线调查，无额外硬筛选。完整行为定义包括模型 SHA、条件槽、宿主和搜索配置、效用、回退、探索及采样。生产和无探索评测拥有不同身份。

## 正确性和预算预实验

手工早胜用例得到真实终局，核对了实际 Solver HP 及胜利状态。两个隐藏牌序不同、初始公开观察相同的对照具有相同公开选择及候选摘要。32 根端到端验证在第 8 根停下后恢复，搜索运行含实际计划执行和新信息后重新规划。历史冻结资产及不同训练、验证、开发、确认队列以种子和去升级牌组族排除重叠。

冻结审计核对 65,535 个历史种子、62,187 个历史去升级牌组组合和 15,776 个新根。新根的种子和牌组组合各自全局唯一。历史封存分区只参与私有配方去重，其轨迹和终局继续封存。11 个确认候选的模型、条件与预算锁定后才运行确认战斗。

## 续训与恢复

生产根的训练/验证归属在模型运行前按牌组族哈希判定。只对实际完成的终局构造标签。历史数据复用原缓存，最新与上一代新经验分别保存独立清单、压缩终局记录和特征分片。训练为 5 轮 × 192 次更新、batch 512。第一代配额 256 历史 + 256 当代，第二代 256 历史 + 154 当代 + 102 上一代。每来源按轨迹权重选择分片及随机决策。验证保留独立牌组族及历史 H 和当前/上一代条件，按等配额联合 V/Q NLL 选择最优轮。实际 GPU 度量采用 BF16 训练及 FP32 验证。

策略条件使用原先分配的 16 个嵌入槽中的下一个槽。从父模型所用条件复制嵌入值，新槽清零优化器矩，其余优化器状态和旧身份继承。每代重新启用余弦学习率日程。(G_{i+1}) 的实际部署和生产都使用上一轮已学习的实际生成行为条件。固定 A2 的交叉评价另行登记。

四个搜索臂的 S0/S1/S2/D2-search 整批用时约 84/94/121/118 秒，单根中位约 0.89/0.99/1.15/1.27 秒。S0 的累计推理等待、图 RPC 与 Solver 转移分别为 319、128、58 秒，Solver 含在图 RPC 内。以同权重实测，S0 的墙钟约为 D0 的 2.57 倍，D2-search 为 D2 的 3.22 倍，S2 为 S2-direct 的 2.14 倍。绝对吞吐受宿主和运行时环境波动。本次收益主要体现在共同胜局 HP 和严重战损，足以支持在高风险决策试验选择性搜索，持续全量搜索采集的额外成本仍需单独论证。

### 动作支持度

每臂随机抽至多 256 根，每根抽至多四次实际行动，以冻结 PRE1 Actor 的概率作参考。Owl 的 Cascade 先验约 14.2%，高于 5% 的低支持阈值，排名在 Top-3 之外。

## 下一阶段

优先优化搜索性能并测量选择性启用的收益。在独立根上验证何时启用搜索，针对推理等待、重复公开节点和复杂待选分支测量节约量。同权重搜索已显示可复验战损收益，整场启用增加约 2.1–3.2 倍墙钟。与继续扩大通用自采量相比，先对独立训练根中的长局、高置信失败和低支持决策补配对监督，更能定位续训停滞。SV2 仍应验证公开条件随机世界，约半数候选边界的后续需要当前 Q 估计，尤其影响抽牌和随机目标情景。

## 复现

从仓库根运行。大型产物位于 `logs/m1-sv4a-*`，历史 SV1、SV3A 资源只读保留。

```powershell
python -X utf8 experiments/m1-sv4a/build_host.py logs/m1-sv4a-repro-host
python -X utf8 experiments/m1-sv4a/campaign.py logs/m1-sv4a-repro --host logs/m1-sv4a-repro-host --until pretest
python -X utf8 experiments/m1-sv4a/campaign.py logs/m1-sv4a-repro --host logs/m1-sv4a-repro-host
python -X utf8 experiments/m1-sv4a/support.py logs/m1-sv4a-repro logs/m1-sv4a-repro/support.json --confirmation
python -X utf8 experiments/m1-sv4a/audit.py logs/m1-sv4a-repro logs/m1-sv4a-repro/evidence.json
```

相同参数重跑会校验冻结清单、模型和策略身份，跳过已提交的 SQLite 根，训练从最近完成轮恢复。`--route D` 或 `--route S` 可单独运行路线及开发评估。两路完成后再运行完整命令会形成确认矩阵和固定世界诊断。新经验和评估各自用独立本地目录。

正式归档完成后用同一命令恢复，确认候选锁的内容与时间戳、再生成证据索引的 SHA-256 均保持一致。SV4A 与 PRE1 共 7 项回归通过。

正式执行使用现有 SV3A 和 PRE1 依赖，训练入口为 `logs/m1-pre1-cuda/Scripts/python.exe`。`best.pt` 是实际部署权重，`best-train.pt` 绑定同轮优化器供下一代继承，`resume.pt` 保存当前代最近完成轮。单局步级记录和搜索摘要在每臂的 `results.sqlite`。整次实验可用[证据索引](../experiments/m1-sv4a/evidence.json)检查来源及 SHA-256。
