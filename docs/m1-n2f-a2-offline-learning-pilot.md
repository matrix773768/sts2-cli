# M1-N2F-A.2 现有战斗数据的有限预算学习试验

**结论 B：结构化机制编码有相对 Card ID 的探索性信号，但没有稳定超越分组先验或简单机制统计。** 本轮研究属于 `exploratory / offline / reused-development-data`。新增战斗 Rollout 为 0，未启动原生游戏或 CombatSolver。N2F-A 原协议因正常终局覆盖率不足而停止，本次分析保留该决定和原账本。

## 数据与冻结协议

只读取 N2F-A 已生成的训练专用数据、账本、协议和产物摘要。程序校验归档 SHA-256，逐条对照 320 个唯一根的账本、预算记录、角色、遭遇、配方、配对、规格及卡组摘要，并验证 N2E 身份表示往返和机制表示一致性。原始标签 143 胜、116 死、61 次 `truncated`，未发现其它终局。三分类视图固定为 0=`win`、1=`death`、2=`unfinished`。最后一类明确表示第 96 步尚未结束。所有标签均为既有 `prediction_only` 轨迹的有限预算观察。

输入沿用 N2F-A 的公开入场字段及完整卡组多重集。根 ID、组标识、卡组摘要、种子、隐藏 RNG、轨迹与终局资源均在学习特征之外。原 selection/report 组与封存集未读取或执行。每折从两族各留出一个相同编号的基础背景，共 256 条训练、64 条留出。四格、两遭遇及全部种子随背景一起划分，全部 320 条各获得一次留出预测。划分与配置在拟合前写入[冻结协议](../experiments/m1-n2f-a2/protocol.json)。

## 模型和预算

| 模型 | 输入与结构 | 每次初始化参数量 |
| --- | --- | ---: |
| 分组先验 | 当前训练折的机制族 × 遭遇类别频率，加 1 平滑 | 8 个独立概率参数 |
| 简单机制统计 | N2F-A 统计特征与线性 Softmax 头 | 117 |
| Card ID | 128 维身份特征、12 维共享卡编码器、均值汇聚、12 维联合层 | 1,887 |
| 结构化机制 | 与 Card ID 同形，输入为 N2E 有序机制节点及静态属性 | 1,887 |

三种学习模型每折均用固定种子 17、43、101，各训练 90 轮，平均三组概率。Adam 全批 CPU，学习率 0.015，L2 为 0.002，沿用原隐藏层和特征编码，输出头使用三分类交叉熵。无检查点选择或超参数搜索。三分类 Brier 为逐样本三类平方误差之和后取平均，除数只有样本数。混淆矩阵的行是真实类别、列是预测类别，顺序均为胜、死、未结束。

## 四格交互与研究边界

以下为 D11−D10−D01+D00 的概率差，三维依次为胜、死、未结束，每族使用 40 个种子配对块。这里只分析已经观测到的有限动作预算终点。

| 机制族 | 观察差 | 先验 | 统计 | Card ID | 机制 |
| --- | --- | --- | --- | --- | --- |
| 力量 | (−.050, +.050, .000) | (.000, .000, .000) | (.000, .000, .000) | (−.004, +.004, .000) | (−.005, +.005, .000) |
| Shiv | (+.275, −.050, −.225) | (.000, .000, .000) | (−.001, .000, .000) | (+.003, +.010, −.013) | (+.037, .000, −.037) |

Shiv 中机制模型捕捉了观察差的胜与未结束方向，但幅度偏小。组内先验理论上给四格相同概率。集合模型的非零差异显示预测对配方变化敏感，但其总体概率分数未优于更简单的统计模型。干预是替换卡槽，改变了卡牌属性及冻结策略出牌路径。未结束仍可能在更长预算下胜或死。这里的数值只适用于冻结 initial-mean 的 96 步结果，无法推断最优策略的卡牌协同或长期选牌收益。

这些背景和标签已有公开分析。留出的是完整背景，两个核心卡牌对及受测敌方机制均已出现；本轮没有新卡、新敌方机制、跨机制族迁移或独立报告证据。Shiv 未结束模式可能主要反映冻结策略行为。**暂不启动 N2F-B。** 下一条独立研究方向是根据规则和短动作序列设计机制辨识任务，检验在低于完整战斗的成本下能否学习更有区分度的表示。

## 计算成本、验证与复现

Windows、Python 3.10.11、NumPy 2.2.6，OpenBLAS 单线程。正式首跑端到端 39.0 秒，三视图编码 7.4 秒，模型运行期间 Python 跟踪的分配峰值 21.0 MiB。每折每模型含三初始化的训练耗时，统计为 0.10–0.22 秒，ID 为 2.64–3.13 秒，机制为 2.63–3.00 秒。先验拟合少于 0.01 秒。使用已编码单例测量，各折 P50／P95 的范围（毫秒）为先验 0.0018–0.0021／0.0025–0.0030，统计 0.19–0.28／0.20–0.43，ID 0.58–0.79／0.64–2.16，机制 0.47–0.68／0.74–1.38。时间包含测量期间的内存跟踪开销，不宜视为部署延迟。最大同折单初始化 Log Loss 差约 0.15，所有拟合均产生有限参数和有效概率。
