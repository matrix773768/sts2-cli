# M1-CS5 铁甲战士对海洋混混的 SL 概率原型

2026-11-17。十类首手的两回合最小累计战损为 **1、3、6、8、11 HP**，精确权重分别为 **600、300、300、30、30 / 1,260**。两条代表性完整路线分别以 **3 和 11 HP** 的战损获胜，达到了各自的两回合下界，且通过原生逐步差分。完整战斗仅验证这两个固定牌序，尚无完整分布。

## 固定根与概率

沿用 [M1-CS4](m1-cs4-combat-distribution-validation.md) 的离线宿主与原生差分工具，Windows x64、STS2 v0.113.1 Build 26660232、CoreCLR 9.0.7，CombatSolver 0.51.5 基线提交 `78e4545e825e58c3d999354b1ffcd54241b1d2cf`。使用 `M1CS1`、A0、`SEAPUNK_WEAK`，在首回合玩家出牌边界捕获单个海洋混混 **45/45 HP**、铁甲战士 **80/80 HP**、3 能量、99 金币、燃烧之血、无药水。原生战斗牌池为 5 打击、4 防御、1 痛击。原生对照观察到海踢→旋转踢→吐泡再轮回，吐泡回合后力量 +1。

合成模型给十张牌的 **1,260** 个牌名排列等权，来自 `10!/(5!4!)`。每个情景从同一个已进入战斗的根分叉，将排列前五张及后五张分别赋给初始手牌与抽牌堆。保留其余状态及 RNG，所有尝试从同样的根出发。后续随机消耗由实际动作决定。权重是实验定义，未经真实种子条件化。

## 两回合精确枚举

穷举每个行动边界能支付的三种牌与结束回合，保留所有出牌次序，包括第一回合不花完能量。同名副本的语义键经检查相同。痛击、打击、防御均不抽牌、生成牌或读取手牌位置，第二回合恰好取完保留的五张牌。两次敌方行动结束后、第三回合取牌前截断，避免把弃牌顺序及后续洗牌引入此等价关系。上述条件下，首手多重集决定两轮合法的牌型动作树；成员的概率来自对完整牌名排列计数。另对每类首、中、末三个完整牌序独立求解，共 **30** 个顺序，所有保存的端点及路线逐项相同。两条原生对照验证了不同首手下的回合与牌序推进。未对 1,260 个顺序逐一运行原生引擎。

## 完整战斗与缓存

第三回合起使用原有预测洗牌和回合推进。按完整牌序分别搜索两根，逐根两版都从同一 RNG 状态启动。DFS 上限 6 个玩家回合、3,000 节点、6 秒，找到胜路后用已经发生的不可逆累计失血作下界。缓存实验仅在本夹具内使用预测状态指纹、上游对照状态全文（含有序牌堆、RNG 计数及续用戳）与累计失血共同作为键。它只影响实验遍历，未修改生产算法。

两根虽然未穷尽完整树，但胜路的累计战损分别等于其严格两回合下界 3 和 11。在本次的**累计失血**目标下，后续回复无法撤销已产生的失血，故这两条胜路各自证明了对应固定情景的整场最小值。该证据覆盖 2 / 1,260 个合成牌名排列，尚未建立同首手在洗牌后仍共享最优战损的关系。

## 原生验证与复现

对上述两条完整路线各启动一个隔离进程，用原有卡对象重建手牌与抽牌堆顺序，并从原生捕获同一根。共 **38/38** 原生动作通过合法性、逐步 HP、能量、有序牌堆、Vulnerable 等 Power、怪物行动记录、RNG 计数与续用戳差分。两根和胜利边界均零字段差异，Shuffle 计数均由 1 到 3，金币均 99、无药水。胜利锁定 HP 为 77 / 69，燃烧之血结算后为 80 / 75。验证复用 CS4 的离线计时及 UI／回放写入适配，宿主仍产生进度保存告警，未对奖励、进度存档及可见 UI 做差分。

从工作区根使用 PowerShell 7，沿用 CS1 基线 DLL 及 CS4 工具：

```powershell
& ./sts2-cli/experiments/m1-cs5/run.ps1 -Results CombatSolver-m1-cs5/repro
```

原始数据在 `CombatSolver-m1-cs5/results/`，分别为 `grouped`、`orders`、`full`、`native-a` 和 `native-b`。定向验证覆盖 Release 编译、权重和端点对账及两条原生完整路线。Steam 文件、CombatSolver 正式策略与主项目生产模拟器未修改。
