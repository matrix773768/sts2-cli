# M1-NOSL3C-III-A3 梯度与回报尺度诊断

Critic 的梯度并未消失。加权 Critic 的全参数梯度范数在五个代表批次为 11.69–51.15，且大部分落在独立输出头。到更新 84，共享参数上的 Actor 梯度约为 Critic 的 113 倍，全局裁剪再把送入 Adam 的合成梯度缩至 1.29%。与此同时，更新前价值头在现有参数下的输出绝对上界仅 4.38，训练终局回报仍在几十至一百多的尺度。证据支持共享网络的 Actor 主导、全局裁剪耦合及价值输出尺度偏小同时存在，无法由本次测量量化各项对学习速度的因果贡献。

## 原始优化合同

记严格准入轨迹数为 N，轨迹 i 的决策数为 Tᵢ，V 为有符号标量，H 为当前合法菜单的策略熵。每条轨迹使用同一个无折扣终局回报 G，胜局 +100、败局 −50，再扣除 `10 ln(1 + 净战损/10) + 0.05 × 净战损 + 0.2 × 回合数`。Actor 的优势是 `G − stop_gradient(V)`，无标准化。

| 项 | 加入合成损失的量 | 归一化 |
| --- | --- | --- |
| Actor | 负所选动作 logp 乘优势 | 每轨迹逐步求和，再除以整批准入数 N |
| Critic | `0.1 × (V − G)²` | 每轨迹先除以 Tᵢ，再除以 N |
| 熵 | `−0.008 × H` | 在合法动作上计算熵，每轨迹逐步求和，再除以 N |

microbatch 为 4。按轨迹原顺序切组，组内按长度降序，按时间步只处理尚有效的轨迹，从零历史通过 GRU 推进。每 microbatch 的合成损失仍除以 **整批** N，跨组累积梯度后只调用一次全局 L2 范数裁剪。不再除以 microbatch 大小。历史 Actor/Critic/熵字段为加权及整批归一前的累积诊断值。Actor 与熵按决策累加，长轨迹的项数更多。Critic 的每轨迹时间归一使它仍是一条轨迹一个权重。

Critic 的 0.1 直接乘损失及梯度。Actor 的价值基线停止梯度，Actor 和熵都不直接更新 value head。Critic 不直接更新 actor head，但会经状态、输入编码、动作嵌入的递归路径和 GRU 影响共享参数。全局裁剪对所有已有梯度乘同一个 `min(1, 3/(‖g‖₂+10⁻⁶))`，之后交给 Adam。该系数度量梯度的实际缩减。Adam 的动量和二阶矩会改变参数步幅，不能将裁剪系数直接解释为参数更新缩小同样倍数。

## 回报尺度和可能机制

价值头形式为 `b + w·tanh(h)`，冻结参数下任意输入的输出绝对值都不超过 `|b| + ‖w‖₁`。五个更新前的上界依次为 2.58、2.66、3.14、3.77、4.38。上界会随训练参数变化。更新 84 的实际逐步输出约 4.000–4.028，接近当前正向容量边界。五批均无绝对激活大于 0.99 的 tanh 隐单元。在更新 84，历史 Adam 实际步使最后一层权重只移动 0.00395 L2，bias 增加约 0.00041。当前参数确实扩展输出范围，但幅度与目标尺度相差很大。

A 的全局说法缺乏支持。B 在五批共享参数上均成立，末期最明显。C 对裁剪后送入 Adam 的梯度成立，长期参数效果有待对照。D 中能直接确认的是当前输出尺度狭窄、胜败预测几乎无幅度差，以及共享梯度贡献的变化。现有证据无法分离表示不足、轨迹级回报本身的噪声与优化耦合。因而整体判断为 E。

## 下一轮最小对照

在预先冻结、按根划分的旧轨迹上，先做一次小规模 Critic-only 诊断。冻结共享编码，比较原始回报头与固定尺度 `G/100` 的同结构头，使用同一初始解码预测、相同数据顺序和优化步数。将归一化头的输出乘回 100 后比较留出 MAE、偏差及胜败排序，兼顾罕见严格败局。如果两臂都只学习均值，再检验共享表示是否能支持条件回报。如果归一化改善留出误差，才在短程联合训练对照中检查是否保留策略收益，并在 Actor 侧使用解码后的原回报单位。分项裁剪可作为后续隔离全局耦合的单因素对照。目前共享空间与输出头的梯度结构支持这一顺序，单独增大 Critic 权重会同时改变全局裁剪，难以直接解释效果。
