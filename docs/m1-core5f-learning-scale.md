# M1-CORE-5F　HotSearch 经验接入与学习规模曲线

**研究基线保留 V2。** 945 族比 128 族降低了自然开发 C 的分布误差；在最大规模加入一步 TD 后，三个种子的误差进一步下降。加入 44 个条件训练根的配对损失后，未测得额外整战收益。开发预选的挑战者在 192 个独立确认世界中取得 97 胜，V2 为 96 胜，两者均严格完成 179 场。共同完成世界的配对效用差为 +0.73，95% 区间为 [−0.02,+2.17]。

## C 语义与训练目标

沿用 31,596 参数共享机制编码，直接编码 H5 的抽牌前 C。逐项核对手牌、弃牌、消耗区的实例类型和顺序；共享编码消费公开 bag 数量、已知顶底、费用层、敌方 HP、能力、意图及可用行动历史。354 个 C 含非空费用层。112 个 C 的实际 HP 上限与开局不同，保留该状态的实际值，终局效用仍按开局 HP 和开局上限计算。7 个存活 C 的末端净损为负。存活按带符号净损作非均匀邻桶投影，死亡占独立原子，整战死亡效用 −50。本域初始上限 80，胜利效用为 100 减开局至终局净损。

表示仍有限制。H5 的 strategic 导出使用 known_enemies、空 events 和空 enemy_models；共享网络只消费已定义的机制字段，不能从空列表推断完整潜在敌方状态。牌袋按公开类型计数，同类型实例的费用差异在未见区域不能逐实例还原；手、弃、消耗区保留实例变量与费用层。H4 留存的同类实例顺序和部分能力辅助字段争议未由本轮裁决。本域没有活跃遗物或药水，未为这些字段追加信息。

用 5E 的 terminal_target、temporal_target 和完整方案均值损失。训练自然 C 为 4,635，3,693 条相邻 C→C、942 条接实际终局，另三场在首个 C 前结束；开发相应为 454、358、96。逐边检查回合号。非终局死亡质量原样传递，存活原子平移本步 HP 差后线性投影；训练边平均端点外质量为 1.63×10⁻⁷。V2 从旧高预算续策迁入，其下一 C 分布对 HotSearch 续策有系统偏差风险。MC 保留真实新续策终局锚点。

条件比较以四个重排世界内的同根配对差取算术均值。44 个训练根中 21 个均值非零，13 个根的世界差值有变化；12 个开发根分别为 4 和 2。原世界单独保留，开发原世界差与四世界均值的 RMSE 为 7.50。两套方案按 public_law 原概率积分，重算每个 C 公开键及共享编码键，将公开概率合并逐项核对 law。终局键校验状态、HP、上限及金币哈希，效用按实际胜负和 HP 计算。重算 V2 的 56 个方案差与生产值最大绝对差 0.000104。配对臂只增加同根期望差损失，未加任何条件后缀的逐 C 标签，便于隔离配对增益。[数据转换](../experiments/m1-core5f/data.py) · [逐根世界差及真实转移计数](../experiments/m1-core5f/evidence/corpus.json)

## 独立整战与基线决定

**保留冻结 V2。** 在预先选中的 TD＋配对模型与 V2 之间，179 个共同终局的配对效用差为 **+0.73 [−0.02,+2.17]**。96 个共同胜局平均少损失 0.125 HP。唯一胜负翻转在确认世界 189，幻影园丁精英，开局 44 HP，挑战者以 13 HP 获胜，V2 死亡。全尝试胜率由 96/192（50.00%）升至 97/192（50.52%），严格完成率同为 179/192（93.23%）。现有证据仍容许很小的负效用差。保留六个研究检查点，不据其他臂的确认结果重新选模。[逐臂分母、失败与配对区间](../experiments/m1-core5f/evidence/results.json)

## 计算、复现与下一批需求

新增独立整战 1,344 次，端到端合计 **858.55 worker 秒**，含子进程启动、加载、搜索、步进、写出与终局检查。拟合及其数据准备 87.77 秒，准入索引和开发复核 11.19、7.48 秒，主计量总计 **964.98 秒（16.08 worker 分钟）**。并行分片分别计费。发布校验、冻结开局、初始诊断、导入路径冲突的失败启动、测试、统计、文档和 Git 在主计量外。初次接入发现战中上限下降、开局 spec 无金币字段；改用实际 C 的上限和公开边界资源核验，全部 56 根概率与价值转换随后通过。既有 5E 条件和分布回归 7 项通过。全部原始整战与传输日志保留在 CORE 本机 logs/core5f-confirm，每个确认分片的跟踪文件摘要、逐世界结果、模型和宿主计量入库。[计算账本](../experiments/m1-core5f/evidence/ledger.json)

复现时在相邻工作树检出上述 CORE 和 INFRA 身份，保留 H5 宿主及 CORE 既有资产。从 INFRA 根运行 `python -B experiments/m1-infra1h5/verify.py`。从 CORE 根用 `python -B` 依次执行 experiments/m1-core5f 下的 freeze.py、audit.py、fit.py、development.py、confirm.py、results.py。完整重跑使用独立输出工作树及新的日志目录。检查点和输入清单随本报告提交。[六个模型及证据目录](../experiments/m1-core5f/evidence)

**建议 INFRA 下一批先试产 192 个独立条件根**。在相同单人 A0、无活动遗物域，从后续可复放的独立前缀中按章节 1/2/3 分配 48/72/72 根，至少 128 根位于第 3–6 回合。保留 48 个未经困难度筛选的代表性根，另 144 个优先选择两套完整方案在成长牌使用、持续资源、敌方阶段或即时防御上有公开差异的根。事前按公开信息选根，不按已见世界胜负筛样。每根预算 128，后缀固定 H5 战术 32＋原 V2，保留原世界及 4 个同根重排，两侧实际续战。可额外对事前随机抽出的 32 个完整根各增加 4 个独立重排，用于估计条件均值的重复性。建议隔离其中四分之一的族供开发。

按 H5 的 56/64 整根准入，192 次尝试约得 168 根；考虑中晚期和严格闭合筛选，计划区间暂取 **120–168 个完整根、480–672 个初始重排对**。H5 首批 64 根消耗 228.42 worker 秒，等比例约 11.4 worker 分钟；为后期前缀及额外重排给 **25 worker 分钟**的试产预算。先记录前 48 次的真实准入、成本、跨世界差方差，再决定是否用完余量。原 44 个条件训练根只有 21 个均值非零，开发更只有 4 个非平局，故优先补独立且有辨别力的条件根。本轮暂不请求追加千场自然战斗、跨预算教师标签或扩大网络容量。后续若需区分自然规模与抽样方差，先利用现有 945 族重抽嵌套曲线；改变续策、遗物域或资源分布时另建身份及确认面板。
