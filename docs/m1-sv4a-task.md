# M1-SV4A 搜索增强与持续价值学习协议

从 `20204548503051afb234a3581a6647964089e0f5` 的 PRE1 初始化 71393001 SV3A 模型共同起步。Ironclad 单人、prediction_only、合法公开历史。依赖 SV1 的可恢复预测状态与随机边界，沿用 SV3A 风险中性效用。独立验证前保持原封存集关闭。

## 运行与训练

- 先检查终局旁路、公开见证回放、隐藏世界不变性及随机后重规划。32 根端到端运行验证断点。128 个开发根以直接 Q 和 350、700、1,400 次 Solver 交互调用预算配对。按最佳胜场下两场以内的实测吞吐选择正式预算。
- D0 直接 Q，S0 同权重加搜索。两路线各运行两次生产、蒙特卡洛续训和开发验证。D 的每代完整目标为 5,000 局。S 为 2,000 局，按预实验吞吐与已冻结储备调整。经验的训练和验证份额在生产前按牌组族划定。
- 自己生成的经验登记完整的行为定义，包括价值模型、实际条件槽、宿主、预算、效用、回退和 5% 合法均匀探索。每次实际行动在给定当前可执行计划下记录抽样概率。评测策略关闭探索。后续策略使用已经学习过的实际生产行为条件。
- 第一代历史和最新经验各 50%。第二代以 256/154/102 的固定 batch 配额使用历史、最新及上一代经验。两路均为 5 轮、每轮 192 次 AdamW，批量 512，学习率 4.5e−5 后余弦下降。以合并来源的验证 V/Q NLL 选择。保留原策略槽、原优化器和新的槽位初始化证据。

## 独立评价

冻结两个新队列，各 512 根。确认矩阵包括 A2，G0 直接与搜索，D1/D2 直接，S1/S2 搜索，D2 搜索、S2 直接，以及 D2、S2 在共同 A2 条件下的直接比较。确认前冻结所有权重和策略配置。配对报告包含全部尝试、真终局、资源、长尾、搜索成本和置信区间。
