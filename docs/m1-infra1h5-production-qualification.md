## 可交付数据与千场成本

已交付 **1,041 场严格准入的自然训练战斗、5,089 个实际 C**。两个训练批次共尝试 1,120 个互不相同的构筑族，每族一个种子，整体准入率 92.95%。首批 475/512 准入后，为直接测量千场成本，另行冻结 608 个新训练族；其中 566 场准入、278 胜、产出 2,794 个 C。容量批次沿用相同的权重、战术 32 和机器配置，独立封存，开放面板仍只评价首次冻结的策略。[首批清单](../experiments/m1-infra1h5/data/manifest.json) · [容量批次清单](../experiments/m1-infra1h5/capacity/manifest.json)

两批自然生产实付 **1,253.79 worker 秒、1,090.36 CPU 秒、328.83 秒四 worker 活跃 wall**。按实际准入数折算，**1,000 场有效经验约需 1,076 次尝试、20.07 worker 分钟、17.46 CPU 分钟、5.26 分钟活跃 wall**，约产出 4,889 个 C。两版完整公开观测导出另外耗时 19.53 秒和 11.75 秒。将这两次导出的全部成本都计给自然训练集，每千场合计约 20.57 worker 分钟、5.77 分钟活跃 wall，这一口径也承担了首批开放和条件世界的观测导出。测量是同一台机器、两个冻结批次的结果；持续运行数日的尾部耗时尚未测量。

本轮生产、同期 1A、故障注入、定向重放、一次构建和实际公开观测导出合计 35.02 分钟（各独立 worker 的占用时间相加）。其中 H5 构建占 106.88 秒，定向规则回归从启动到产物封闭占 46.50 秒。源码开发、只读统计、哈希复核和 Git 操作另计。常规路径原生审核调用为零，计算开销集中在 Hot 规则分支、模型估值和真实续战。[容量与成本账本](../experiments/m1-infra1h5/results/capacity.json)

## 经验资格与版本管理

严格资格由合法动作、NOSL 公开观察、条件策略绑定、概率质量及实际完整终局共同决定。已选闭合程序的实际观察必须命中已估值的边，C 或终局必须属于原条件分布。参考未闭合的回合按冻结协议执行直接 G2，此时保留未解决质量。所有常规样本标记 `native_audit=not_run`、`native_receipt=null`。本次分发没有诊断续跑。历史原生审核代码及证据仍可用于定向调试和争议裁决。

每条记录通过 `run_id` 指向不可变的 plan，包含游戏、HotKernel、宿主二进制、实际源码摘要、Git 提交、.NET/Python/PyTorch、G2/V2 权重和输入身份。记录保存完整开局 spec、任务 ID、构筑族、种子、来源与 split、策略与行为 ID、预算、公开轨迹、真实 C、实际动作、条件程序、概率质量、胜负、终局资源或失败前缀。自然战斗、条件监督、开放评估、历史桥接分别索引。

原始公开观测另有一层按任务 ID 关联的数据，保留每次实际行动或待选之前的完整公开事实与菜单，支持重新编码。对所有准入轨迹，离线校验器逐步检查所选动作和目标、绑定的公开菜单、概率和终局。条件世界还验证两侧相同的重排种子、原分布命中，以及同公开信息下变更未来 RNG、私有牌序和编号时的非干涉检查。公开观测索引绑定确切的父数据集摘要。[读取入口](../engine/HotSearch/read_experience.py) · [离线校验](../experiments/m1-infra1h5/verify.py)

每个分片先在私有临时目录完成写入、摘要和收据，再以同卷重命名发布。所有任务封闭后才原子发布总清单。操作系统锁排除并发写入，已提交的分片按任务列表和字节摘要复核后跳过。进程错误保留 attempt，支持有界重试。已完成的机制阻断及监督失配保留在分母。冻结计划、源码、模型或宿主身份变化会拒绝沿用原批次。首批先提交 4 个分片，随后恢复并提交另外 37 个。独立故障注入在真实战斗已算完、分片发布前终止协调进程，退出码 73；当时可见分片为零。重试产生相同公开轨迹与终局，最终只发布一次；另一个写入进程被排除。[恢复实测](../experiments/m1-infra1h5/results/ledger.json)

研究使用 5D 训练来源的开局模板和 DC1 构筑生成器。比较前固定 64 个新牌组多重集、各自种子、战术 32、0 干预裕量、修正 1A 高预算 V2 及统计口径。生成时按无序牌组排除已知历史族和保留分区的重合，只使用构筑指纹，不读取确认集轨迹或结果。开放族与两批训练族互斥。每族一个自然世界，两个策略使用完全相同的开局和种子。没有根据这次开放结果再调策略。[冻结输入](../experiments/m1-infra1h5/cohort.json.gz) · [同期 1A 结果](../experiments/m1-infra1h5/results/reference-open.jsonl.gz)

## 中盘与条件世界

自有前缀在第二回合 B 点选根，根预算 128，后缀战术预算 32。每根预定原世界和 4 个重排世界，每个世界比较两套不同的闭合计划。计划及概率按本引擎导出。56 个完整训练根包含 448 条重排终局后缀、112 条原世界终局后缀，其实际 C 分别为 1,869 和 454。预定 256 对重排，实际尝试 244 对，整根准入 224 对。失败根的任何部分均可追溯，不能补入成功根的估计。历史 123 单独来自冻结公开前缀，首动作 3 与 2 的原世界终局效用分别为 78 与 75，四对重排均完成。条件数据带有独立的选根、根预算、重排和续策身份，供同协议的反事实或条件世界研究使用。

## CORE 使用边界

CORE 可以直接读取 `train/natural` 的准入记录，使用实际 C 与完整终局构建战略价值训练样本；两批训练自然数据具有相同冻结行为策略。为模仿行为或重建 G2 历史，可按需加载完整公开观测。条件数据应按根和世界配对使用，不得把同一根的各后缀当作独立自然战斗，也不要把它标成旧 5C/5E 高预算策略。开放与历史桥接分区留作验证。采集没有进行模型拟合。

从仓库根目录执行以下命令可导出两份可直接消费的 JSONL。每行的 `trajectory.states` 保留可重新编码的 C，`trajectory.terminal` 及 `spec.hp`、`spec.max_hp` 可用于冻结效用合同。`--public-views` 另外带出完整公开决策轨迹。输出目录使用已有的 `logs`。

```powershell
python -B engine/HotSearch/read_experience.py experiments/m1-infra1h5/data --split train --kind natural --public-views --output logs/h5-core-natural-first.jsonl
python -B engine/HotSearch/read_experience.py experiments/m1-infra1h5/capacity --split train --kind natural --public-views --output logs/h5-core-natural-capacity.jsonl
python -B engine/HotSearch/read_experience.py experiments/m1-infra1h5/data --split train --kind conditional --output logs/h5-core-worlds.jsonl
python -B experiments/m1-infra1h5/verify.py
```

首次训练覆盖单人 Ironclad、A0、三个 act、68 种遭遇、86 种牌，牌组 12–25 张，最大 HP 80，起始 HP 为 44、64 或 80。当前生产域排除活动遗物、宠物和非空药水槽。结论限于已运行的构筑和机制。长期服务吞吐仍受构筑分布、严格失败率及机器负载影响。[运行说明与命令](../engine/HotSearch/README.md)
