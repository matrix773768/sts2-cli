# M1-CORE-5H　主动决策监督与实体交互价值网络

**保留冻结 V2。** 新确认面板上，预选池化主动模型取得 119/256 胜，V2 为 117/256；237 个共同终局的效用差为 +1.09，按族 95% 区间为 [−1.41,+3.59]。主动选根找到可复现的高代价改选，也发现长程 MC 的真实错排。把 106 个新训练根加入损失后，方案差的数值拟合有所改善，开发选择后悔没有下降。热启动交互网络使真实搜索中的平均前向耗时增加约 48%，在本轮确认中与同种子池化主动模型取得逐场相同的终局。

## 问题与冻结输入

本轮检验两个问题。第一，在 V2 与 5G 长程 MC 已经选了不同完整程序的公开根上，补充配对终局监督能否减少代价较大的错选？第二，在相同机制输入上，让实体在池化前交换信息，是否比原网络和相近容量的逐实体网络更有优势？

CORE 起点为 `1afd5ea78ebc1555ca5725533b2a1f1ec3783146`，INFRA 工作树为 `80ca8165fee768ba4e2b55bfd367ee00df650616`。由冻结接口重新装配 2A 经验，主发布 ID 为 `dc7985a66a7cc0de2ac2a85f5dfa95cd804dc061286e366a7211bb1db43d4bb2`。逐项比对 5G 语料的家族/任务、转移、条件世界、复评及标签统计。自然训练为 4,096 族、19,936 个实际 C，有 15,849 条相邻边和 4,087 条终局边。自然开发为 275 族、1,314 C，历史条件训练/开发为 166/51 根。2A 的 13 个额外自然族不进入自然训练。继续使用独立死亡原子、带符号净损投影和开战效用。当前域开局上限为 80，存活效用为 100 减开局至终局净损，死亡效用为 −50。

新增全部真实后缀使用 H5 tactical32、原 G2、原 V2、零裕量。5G 长程 MC（5719，第 11,200 步）仅在生产时对同一菜单提供另一选择。5G 从头 MC（5719，第 6,400 步）另作历史预测对照。5G 两次交叉续战继续作为历史诊断，5G 确认构筑全数排除在本轮新确认之外。[发布接入收据](../experiments/m1-core5h/evidence/source.json) · [冻结生产及训练协议](../experiments/m1-core5h/protocol.md)

## 公开选根及配对生产

先冻结 128 个独立确认族、每族两个世界，再冻结最多 960 个开放研究来源族。按无序牌组 ID 多重集排除 H5、历史 CORE、2A 全部尝试与备用构筑，以及 5G 确认。各开放族从正常开局运行 V2。每次实际查询均在 tactical32 相同的公开候选与 G2 参考上比较；参考开放时按冻结规则直接回退。分歧只接受两个模型实际选择的程序不同、两案均闭合、公开后继 law 有区别、未知牌袋满足预筛的根。程序以首动作及完整公开绑定树识别，因此保留同首动作下的不同续法。

预分配 128 个分歧槽、32 个代表槽。代表槽的最低回合由族哈希固定为 1–4，从该回合开始取第一个可比较根；若两模型同选，就用族固定随机数抽取另一闭合程序与 V2 比较。代表槽反映有合法比较的可达域，不能估计所有回合的平均收益。训练/开发由根槽事前指定，每个构筑只贡献一个根。选根立即停止自然前缀，严格失败占用原槽，没有通过挑选未来终局替换样本。

复用 INFRA-2A 的前缀恢复、checkpoint、公开观察绑定、重排、两侧实际执行、真实终局及严格资格。CORE 适配层只指定根、预算 32 下的两套程序、世界序列和收据。每个根保留原世界，主标签为八个共同重排世界中“第一侧终局效用减 V2 程序终局效用”的算术均值。两侧从同一重排出发，干预回合之后都恢复原 V2。通过两个独立四世界块构成八世界标签；任何主块不完整，整根退出拟合。每五槽一个固定复评名额，另外对主世界效用差极差达到 40 的根追加四个独立世界。复评仅作验证，原世界、复评、失败前缀均不补作主标签。[选根与生产适配](../experiments/m1-core5h/collect5h.py) · [新开局与独立面板](../experiments/m1-core5h/freeze5h.py)

## 结构与受控训练

原网络用逐实体 MLP 生成 32 维表示，随后以四个注意力池和一个汇总向量结合全局特征预测分布。本轮在同一编码与原池化之间比较三种结构。

| 结构 | 参数 | 池化前表示 |
|---|---:|---|
| 原共享池化 | 31,596 | 各实体独立编码 |
| 逐实体容量对照 | 33,708 | 对每个实体加 32→32→32 的残差 MLP |
| 四槽集合交互 | 33,788 | 四个可学习查询按有效实体加权，汇成四个 16 维上下文；每个实体再以自身查询读取上下文并残差写回 |

两种扩展仅差 80 个参数。所有模型复用同一公开 C，手牌位置、已知牌顶/底、费用层顺序、敌方机制及其他原有位置特征保持在实体行内。屏蔽填充行，不添加私有牌序、敌人 ID 或外部权重。残差输出层零初始化，起点逐批复现同一长程 MC。测试检查实体行连同其机制位置特征一起置换时整网输出不变、添加填充无影响；在打开残差后，交互模型中改变一个有效实体能影响池化前另一个实体的表示，逐实体容量对照没有这条梯度路径。[网络实现](../experiments/m1-core5h/nets5h.py) · [结构与推理检查](../experiments/m1-core5h/evidence/network-checks.json)

三种模型都比较有/无新主动损失，训练种子为 5719 和 7213。每次从同一已充分训练的长程 MC 出发，再做 2,000 次 AdamW 更新，批量 64，累计呈现 128,000 个自然 C（约 6.42 遍），初始学习率 0.00008、余弦下降至 20%，权重衰减 0.01、梯度范数上限 2。自然 MC 使用真实终局分布；各臂还等根抽取两组既有完整方案差（系数 0.35）和八个 2A 已到达的后缀标签（系数 0.15）。主动臂另均匀抽取两个新训练根，按原始概率为两完整程序求期望，以八世界效用差作均方目标，系数 0.55。两种差值损失均以 45 效用单位归一化。同种子的自然、原条件、实际后缀批次在各臂相同。新增主世界只按根进入差值监督，未给未执行分支添加后缀标签。

在第 160、600、1,200、2,000 步分别测开发自然误差、原条件差及新根的效用后悔。检查点分数为自然 NLL 加上 0.006 倍自然效用 RMSE、0.003 倍旧条件差 RMSE 和 0.01 倍新根后悔。每个主动开发根比较两案，记八世界均值为 Δ；选择第一案的观测收益为 Δ，保持 V2 为 0，观测后悔为 max(Δ,0) 减所选收益。错误代价保留效用单位。用有限世界选“实测最优”会高估绝对后悔；模型间在同一根上的后悔差可以直接用实测选择收益差比较。开发用于选模，另用预留复评世界检验方向复现。[训练与逐步度量](../experiments/m1-core5h/fit5h.py)

## 独立整战的预选

开发整战沿用 5G 的 64 个开放开发世界。池化与交互的主动模型均在种子 5719 取得 26 胜、63 场严格完成，对 V2 的共同终局效用差均为 +2.48；种子 7213 同为 26 胜、63 场完成，配对差为 +2.29。按预定综合秩，两个主动代表得分分别为 2.95、3.15，事前选择**池化主动 5719**作为升级检验。无主动交互代表 7213 得分 2.18，用作独立监督对照。按各臂开发计时预测总成本为 117.61 worker 分钟，锁定五臂。预定顺序中的池化无主动和逐实体容量对照未通过余量估计，保留其双种子离线与开发整战结果。不同阶段并发负载影响耗时估计。确认开始后维持该名单。[冻结预选与开发分数](../experiments/m1-core5h/evidence/selection.json)

**主动分歧经验值得继续用于定位和验证高代价错排。** 此次八世界配对比四世界稳定，仍有 86/113 个分歧根方向未定。当前均方差监督虽改善部分数值预测，却没有减少开发中选错的代价。下一次生产优先保留同首动作不同续法，并在独立新族上预先按公开预测差、回合和敌方阶段分层。可先取 96 个分歧根、32 个代表根，维持 tactical32 V2 后缀和每根八个共同世界；对高波动根及固定随机审计子集独立追加四个世界。两种子、相同更新步数与完全相同的监督控制臂能更直接估计主动损失的边际收益。这里的分层建议来自本轮回顾，应在新面板验证。

**实体交互适合保留为从头学习的候选架构。** 下一次可将从头池化、逐实体与四槽交互在同数据上预选，然后用全新的整战面板检验能否兑现自然误差的优势。热启动交互的计算代价已有实测，当前缺少将其设为默认的能力依据。生产之外，优先量化参考开放的 38.3% 查询中能恢复多少有效比较，再决定扩充搜索覆盖和增加监督各值得多少计算。外部引擎与完整跑局继续独立推进。
