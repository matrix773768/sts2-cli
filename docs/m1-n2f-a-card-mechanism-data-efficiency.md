# M1-N2F-A 共享卡牌机制表示的数据效率与协同学习试点

## 研究设计

冻结 N2C `initial-mean`，预测固定策略下的单场条件胜率。每根独立原生建根，在合规的 N2A.1 公开观察上执行一次 NOSL 轨迹，使用原有 96 步上限并关闭药水。两个机制族分别为 `INFLAME × TWIN_STRIKE` 和 `ACCURACY × BLADE_DANCE`。后者用 N2E 的 Shiv 家族表达生成与增伤关系。

每族九个 15 张牌的基础背景，使用不同攻防、过牌或成长牌比例，同一背景和遭遇的四格只替换预定的防御／打击槽位。四格共享 HP、遗物和外部种子，背景牌升级规则固定。两遭遇使用 BOWLBUGS_WEAK 与 CHOMPERS_NORMAL，入场 HP 为 35、43 或 51。所有根均为 synthetic，自然跑局可达性为 unknown。逐卡检查 N2E 静态资格，名单排除了带已知终局差分的 PREDATOR。

5／2／2 个背景按族分配给训练、选择、报告。每一背景的四格、种子块和两遭遇同组。跨组完整卡组至少相隔两次 ID 替换。计划 320／128／124 次预测与 4 次独立原生复放，一组末尾四格预留给原生预算。报告阶段验证模型锁后才可以执行。基线 `a78466ec9275298e4467cc942fa4a1369476d5cb` 已含 N2E 与此前合入的架构文档，开始时工作区与本地远端跟踪引用一致。数据使用新种子域。[冻结协议](../experiments/m1-n2f-a/protocol.json) · [Manifest](../experiments/m1-n2f-a/manifest.json)

## 学习参数与评价

所有模型使用相同合法入场数据，包括当前／最大 HP、角色、遭遇、难度、幕、两种初始遗物标志及药水占用。完整卡组使用 N2E 多重集编码。根 ID、组标识、种子、RNG 摘要、卡组哈希、终局及配对账本只用于离线审计或评价。

- **统计。** 使用卡牌数量、平均费用、升级比例、即时节点类别计数及原始数值汇总，配合带 L2 的逻辑回归。
- **身份与机制。** 两者用同形的 128 维固定有符号特征散列、12 维共享卡编码器、均值汇聚及 12 维非线性联合层，最后输出胜率。重复条目按数量展开。身份使用 ID 和升级字段，机制使用槽位有序的嵌套效果节点、数值、目标、Power、家族、资格及未知节点。机制视图不含卡牌身份字段。固定散列保留序位且可能碰撞。跨卡组合由汇聚后的联合层建模。
- **训练预算。** 三种固定初始化，CPU NumPy 全批 Adam。使用每族前 1／2／5 个训练背景做嵌套数据预算，对 30／90／180 轮检查点按选择组 Brier 选轮数，同分取更短检查点，再平均三个初始化的概率。统计基线和神经模型共用相同根与检查点规则。报告锁包含协议、学习代码、开发数据和模型参数摘要。
- **评价。** 正常胜负参与 Brier、log loss 和校准。异常终局保留原因与缺失标签。用同配对块内四格差 `D11−D10−D01+D00` 比较预测和观察，四格缺一则排除该块。重采样在机制族内以背景为单位，整组保留遭遇、种子和所有四格。报告集每族仅两个背景，区间和校准都只用于探索。胜利 HP 采用锁定终局资源，作为描述统计。

## 泛化边界

报告组留出完整背景及其四格配方。配方在冻结后复核发现，报告背景使用的 BASH 和 SLICE 未进入训练组，两张牌均出现在选择组。报告误差混合了背景留出和训练阶段单卡缺失，无法单独估计全部卡牌已见条件下的配方泛化。两个核心具体卡牌对都出现在训练中，未见具体配对和未见机制族迁移尚未验证。学习曲线使用固定嵌套背景子集，点位同时改变了构筑覆盖，初始化重复不能替代独立构筑重复。当前实验也没有设置训练中已出现配方的专用未见种子测试组。

组合差以替换基础卡为干预，包含替换引起的其它卡牌属性差异和冻结策略的行为响应。共同种子只约束原始输入。开手、出牌选择及后续 RNG 可能分叉。只有两类特定组合及两类已有遭遇，而且胜率监督受固定评分器是否实际使用机制约束。

## 实际结果与停止决定

**训练组正常反馈覆盖率为 259／320（80.94%），低于预先冻结的 85% 门槛，试点在数据资格阶段停止。** 320 个独立根全部构建成功并各执行一次冻结预测策略。143 胜、116 负、61 次触及 96 步上限，无建根错误、unsupported 或其它异常终局。正常反馈中的少数类占 44.8%，触发停止的是覆盖率。预算剩余 256 次，选择、报告和原生复放实际执行均为 0。三类模型只完成接口实现和合成标签单测，未用正式数据拟合。各模型的独立 Brier、log loss、校准和推理成本均无实测值。因而本轮无法判断机制表示是否改善新构筑预测。

| 训练族／遭遇 | 胜 | 死亡 | 截断 | 正常覆盖 |
| --- | ---: | ---: | ---: | ---: |
| 力量 × 多段／BOWLBUGS_WEAK | 67 | 13 | 0 | 80／80 |
| 力量 × 多段／CHOMPERS_NORMAL | 53 | 27 | 0 | 80／80 |
| Shiv／BOWLBUGS_WEAK | 5 | 31 | 44 | 36／80 |
| Shiv／CHOMPERS_NORMAL | 18 | 45 | 17 | 63／80 |
| 合计 | 143 | 116 | 61 | 259／320 |

实际覆盖 10 个背景、40 个四格配方和 80 个配对块。80 个块内四根的开局 RNG 摘要一致，51 个块的公开开手至少有一格变化。143 个预测胜局的锁定终局 HP 中位数为 15，力量族 17，Shiv 族 9。该资源统计仅覆盖正常胜局。

## 四格诊断与下一步

按 D00、D10、D01、D11 顺序，力量族胜场为 27、30、31、32，各格 40 根且都有正常反馈，条件胜率的样本组合差为 −0.050。Shiv 四格胜场为 4、4、2、13，对应截断为 11、9、26、15。仅 12／40 个 Shiv 配对块具有完整四格，完整块的描述性组合差为 +0.167。对截断格以最终胜负的 0／1 取值范围求最坏界，纳入全部 40 块后的 Shiv 平均差可落在 [−0.600, +0.925]。这个区间反映缺失导致的识别范围，未加入种子或背景抽样误差。仅观察完整块会避开大量 D01 截断，无法据此确认正协同。

61 个截断根在最后一次公开决策的回合中位数为 24，玩家仍有 15 HP、敌人合计仍有 22 HP（均为中位数）。其 4,399 次实际出牌中有 3,548 次是 DEFEND_SILENT 或 BACKFLIP。15 条被截断的 Shiv D11 轨迹都先后打出 ACCURACY 与 BLADE_DANCE。这些轨迹表明，缺失不能简单解释为冻结策略从未使用两张核心牌。它们支持调查防攻权衡、长期伤害不足和公开预览缺口是否让该策略在此类配方中耗尽预算。轨迹本身未验证这些因素各自的因果贡献。[按遭遇、配方和出牌汇总](../experiments/m1-n2f-a/diagnostics.json)

**当前不进入 N2F-B。** 下一次应先用单独预注册的小型开放诊断验证两族在固定 96 步下的正常反馈密度，重点复核 Shiv 防攻比例及现有公开预览下的策略排序。下一份正式清单可让各卡先在训练背景单独出现，再冻结具体配对留出。现有 61 条截断记录保留为缺失，现有选择和报告清单保留原用途。若需要更高步限或新策略来诊断，应另行版本化其标签分布。

## 本轮成本与验证

训练组数据生成端到端 1,056.96 秒，约 17 分 37 秒。单根原生初始化中位 1,611.64 ms，预测 episode 中位 1,230.52 ms，单 worker 峰值工作集 130.7 MiB。上述为串行单根实测。原生轨迹抽查与正式模型训练均未开始。所有实际正常标签为 `prediction_only`。

8 项 N2F-A 定向测试通过，包含固定划分、输入无审计字段、参数量匹配、梯度、合成标签拟合、缺失四格界及模型／数据门槛。PowerShell Test-Json 验证 172 个对象，含全部 72 个预定卡组的两种编码、22 张卡定义和 6 个 N2E 示例。N2E unittest 6 项通过，Python `jsonschema` 依赖缺失导致原 Python schema 测试跳过。未运行全量 pytest 或五角色通关。

## 复现

Windows PowerShell 7、Python 3.10.11、NumPy 2.2.6、CoreCLR 9.0.7。复用 N2A.2 已核验宿主与 E3F 已核验构建。实际加载的游戏、宿主和 Solver 摘要见冻结协议及账本。复现使用独立输出目录。

```powershell
$env:STS2_DOTNET = (Resolve-Path logs/m0-v5/dotnet9/dotnet.exe).Path
$env:STS2_DOTNET_VERSION = '9.0.7'
$env:OPENBLAS_NUM_THREADS = '1'
$output = 'logs/m1-n2f-a-repro'
./experiments/m1-n2f-a/validate-schema.ps1
python -X utf8 -m unittest discover -s experiments/m1-n2f-a -v
foreach ($phase in @('train', 'audit', 'selection')) {
    python -X utf8 experiments/m1-n2f-a/rollout.py $output $phase
    if ($LASTEXITCODE) { break }
}
if ($LASTEXITCODE -eq 0) {
    python -X utf8 experiments/m1-n2f-a/learning.py $output train
    if ($LASTEXITCODE -eq 0) {
        python -X utf8 experiments/m1-n2f-a/rollout.py $output report
        if ($LASTEXITCODE -eq 0) {
            python -X utf8 experiments/m1-n2f-a/learning.py $output report
        }
    }
}
python -X utf8 experiments/m1-n2f-a/delivery.py $output
```
