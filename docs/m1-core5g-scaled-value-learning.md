# M1-CORE-5G　规模化经验与充分战略价值学习

**保留冻结 V2，归档长程微调模型为研究挑战者。** 在相同 230,400 次自然 C 呈现下，从 945 增至 4,096 个独立族使充分 MC 微调的开发 NLL 从 1.3407 降到 1.3003。长程微调代表在 208 个参考闭合的开发查询中改变了 36 次可执行方案。独立确认中它以 149/320 胜领先 V2 的 145/320 胜，两者各完成 296 场；在共同完成的 292 场上，配对效用差为 +1.60，95% 区间 [−0.66,+4.13]。从头训练也学到了战略判断，独立确认胜场与 V2 持平。

复现使用冻结 INFRA 工作树和配套 H5 宿主。CORE 根目录下，以 Python -B 执行 experiments/m1-core5g 中的 cohort.py、prepare.py，然后 learn.py 0 与 1、stabilize.py 5719 与 7213、learn.py 0 与 1 加 --initialization。训练曲线逐点保存训练探针、呈现次数、遍数、两批开发误差、相对 V2 的预测变化和配对根得分差。运行 battle.py dev v2 0 生成共享菜单，再执行 campaign5g.py、menus.py、calibration.py、cross.py、verify5g.py。全量重跑使用新输出目录或独立工作树，读取相同冻结源。原始整战文件保留于本机 logs/core5g，提交的每份收据含原文件摘要与逐世界结果。

**下一阶段优先研究完整方案的错排。** 现有数据已经支持同容量网络从头学习，并能使实际战术方案发生数十次变化。建议沿用 4,096 族自然集和独立复评，先在开发数据上比较纯 MC、缩短冻结 V2 bootstrap 占用的训练阶段，以及根据独立世界噪声调整条件损失系数的做法。按章、开局 HP、回合、敌方阶段和长期资源检查收益与失胜；将本轮两次双向交叉见证留作回归。若进入新一轮教师生产，优先在**参考已闭合、两个模型选了不同可执行程序**的开发域中，事前抽取约 128 个新族根，每根以两套完整方案和至少 8 个配对世界估计效用差，另留随机代表根，固定续策并保留独立复评。先量排序能否稳定改善，再判断是否需要在当前 C 编码中增强敌方阶段或持续资源的表示。对 40.6% 参考未闭合的开发查询，单次价值重评无法改变门控；其收益上限可单列研究。现有结果不支持容量饱和结论，也不要求大范围重构模拟器。
