# M1-NOSL3C-III-A4 Critic-only 回报尺度对照

固定回报尺度让 Critic 在有限步数内更快拟合整体均值。384 步后，归一化臂留出 RMSE 为 **71.29**，原始臂为 **80.09**，拟合集均值常数为 **71.25**。归一化臂的留出胜败首值均值只差 **0.012**，实际回报均值相差 **226.25**。在本次冻结表示、读出头和预算下，整体尺度拟合明显改善，条件回报预测仍缺乏实用幅度。

## 冻结协议

起点为 `port/v0.113.1@c659568ca96b7919273f907c0b5a7c53c1e5cc5b`。从 A2 只读账本提取 1419 条严格认证轨迹，逐根核对账本、审计哈希及终局认证，按原 v4 mixed 目标重算无折扣回报。按根划分，角色、幕、21 更阶段及胜败的交叉组按比例分配，组内随机种子 `73192401`。所有派生决策继承根划分。

| 划分 | 根 | 胜 / 败 | 幕 1 / 2 / 3 | 四段训练时期 |
| --- | ---: | ---: | ---: | ---: |
| 拟合 | 1134 | 1015 / 119 | 626 / 246 / 262 | 271 / 289 / 283 / 291 |
| 留出 | 285 | 255 / 30 | 155 / 65 / 65 | 68 / 72 / 71 / 74 |

两组败局比例约 10.5%，角色比例接近。根清单哈希为 `5b49382751a4940247284dfe1594b527d2d847905a19735aa144fc4dcae11817`，逐根标签、角色、幕和时期见本地协议。共享模型为 A2 更新 84，模型 SHA-256 为 `180b1141d52fe836d5b7770c90c7be193c1c9a8b86bfd7e152274f2e8cd540a6`。沿公开观察和记录动作重建零起点 GRU 历史。对 17 条轨迹逐决策检查，批量缓存与单轨迹直接前向的状态最大绝对差为 1.19e−7，解码值差为 4.77e−7。共享模型始终冻结，拟合前后模型哈希相同。

两臂分别复制完整 `return_head`，各用新 Adam、学习率 0.001、最多 32 根/批、固定 384 步，随机排列种子 `73192402`。每条轨迹先按决策平均 MSE，每批再按根平均。原始臂用 G，归一化臂用 G/100，并将最后仿射层的权重与偏置除以 100，使初始解码预测保持一致。留出上最大初始解码差 9.54e−7。离线诊断采用单项 MSE，省去联合损失权重与全局裁剪。两个拟合器仅接收拟合集状态和回报，留出前向在两臂训练完成后运行，只比较预先登记的 0、32、128、384 步检查点。

## 学习曲线

MAE、RMSE、偏差按轨迹等权，每条轨迹的决策等权。偏差为解码预测减实际。AUC 用每根首决策值区分严格胜败。

| 臂 / 步 | 拟合 MAE / RMSE | 留出 MAE / RMSE | 留出偏差 | 留出首值 AUC |
| --- | ---: | ---: | ---: | ---: |
| 共用初值 / 0 | 79.07 / 85.05 | 78.80 / 84.71 | −45.82 | 0.583 |
| 原始 / 32 | 78.29 / 84.52 | 78.01 / 84.18 | −44.83 | 0.584 |
| 原始 / 128 | 76.40 / 83.26 | 76.11 / 82.92 | −42.42 | 0.584 |
| 原始 / 384 | 71.85 / 80.41 | 71.53 / 80.09 | −36.57 | 0.586 |
| 归一化 / 32 | 43.50 / 71.48 | 43.05 / 71.32 | +3.23 | 0.586 |
| 归一化 / 128 | 45.15 / 71.42 | 44.66 / 71.24 | +0.45 | 0.590 |
| 归一化 / 384 | 43.69 / 71.45 | 43.23 / 71.29 | +2.90 | 0.601 |
| 拟合集均值常数 | — | 44.72 / 71.25 | +0.36 | 0.500 |
| 拟合集中位数常数 | — | 35.40 / 75.74 | +25.71 | 0.500 |

训练批次解码 MSE 的三段均值（步 1–32、97–128、353–384）为原始臂 7267.58 → 6936.21 → 6561.26，归一化臂 5781.66 → 5014.43 → 5255.14。归一化 32 步即超越原始臂 384 步，后续围绕总体均值波动。末次拟合与留出误差接近，未见留出误差相对拟合集明显恶化。归一化较均值常数的 RMSE 收益未稳定出现，其末次 MAE 仍高于中位数基线。

## 留出胜败与参数变化

| 384 步 | 胜局首值均值 ± SD（255 根） | 败局首值均值 ± SD（30 根） |
| --- | ---: | ---: |
| 实际终局回报 | 73.689 ± 16.849 | −152.565 ± 3.015 |
| 原始臂解码 | 13.29893 ± 0.00023 | 13.29884 ± 0.00027 |
| 归一化臂解码 | 52.66758 ± 0.03371 | 52.65546 ± 0.03605 |

末次相对初始的隐藏层权重 L2 位移，原始臂 2.705、归一化臂 0.571。最后线性层的解码权重 L2 位移为 1.747 和 9.980，解码偏置位移为 0.352 和 2.027。冻结最终参数时，解码输出绝对上界由两臂共同的 4.40 扩至 13.31 和 55.32。两臂的胜败分布仍高度重叠，归一化臂末次留出 AUC 0.601 对比自身拟合集 0.500。留出只有 30 条严格败局，极小预测差也可改变排序，AUC 增幅尚不足以证明有用的条件价值。

这组结果表明，固定共享表示配合当前读出与预算可以有效拟合全局均值，尚未显示稳定胜败区分。初始值已有微弱留出排序，归一化后仍有小幅波动。两臂近常数也可能来自现有头、平方损失和优化轨迹，单凭本对照无法断定冻结表示缺乏相关信息。更直接的后续诊断是沿用根划分，对冻结首状态做简单线性胜败探针，并比较确定性分类和回报残差。两臂共享原始策略混合的样本，只有通过严格认证的轨迹进入设计，因此这里衡量的是认证历史行为混合分布的监督预测。

**值得做一次短程联合对照，目标是验证尺度改善能否影响策略与梯度。** 固定 `c=100` 可作为唯一候选，Actor 的优势必须使用解码后的原始回报单位，并保留正式 v4 对照。将其作为机制验证优先于直接部署或扩大训练。A4 同时改变损失数值、最后层参数化及 Adam 的有效解码步幅，结果不能归因于其中单项。若要分离这些机制，可在后续比较解码等效学习率或显式输出尺度，A4 未搜索这些设置。

## 复现

从仓库根指定新的输出目录。

```powershell
$env:PYTHONUTF8 = '1'
python experiments/m1-nosl3c-iii-a4/fit.py logs/nosl3c-iii-a2-01 logs/nosl3c-iii-a4-repro
```

本次输出在 `logs/nosl3c-iii-a4-01`，含协议与根划分、两臂各四个头权重检查点、逐批损失和按组解码指标。未运行新战斗、原生复放、Actor 更新或联合训练，A2/A3 原始文件保持原样。
