## 0. 一句话共识与设计边界

**让共享卡牌机制编码器学习“卡牌在当前卡组和战斗条件下怎样组合、怎样排序才能兑现潜力”，以输出／防御／运转（端口化）作为可解释的归纳偏置，训练一个仅根据合法公开历史直接选择动作的 NOSL 策略；SL 在该策略产生的路线之上进行合法试探、失败修复与胜路资源优化；两者产生的有资格经验继续改进策略，并最终迁移到局外长期价值模型。**

这不是“给所有卡固定打三个端口分，然后从高到低出牌”，也不是把全部未来规划交给在线搜索。核心价值来自**有上下文的条件行动评价**；模型实际 NOSL 决策时不必执行显式树搜索。训练时仍允许大规模模拟、探索、合法信息意义下的搜索教师和策略改进。

核心架构：

```text
原生游戏规则 / 已核实机制 / 公开卡组与历史
                         |
                  共享机制编码 E_phi
               (组合依赖、费用与牌序等)
                         |
           端口能力及时间压力表示（可选辅助头）
                         |
          NOSL 直接策略 pi_theta + 价值 V_psi
                         |
             +-----------+-----------+
             |                       |
        NOSL：逐动作决策        SL：以 NOSL 为初始提议
        无在线显式搜索          当前节点合法试探、修复、优化
             |                       |
             +-----------+-----------+
                         |
           版本化结果、合规反馈、经验学习
                         |
             局外奖励 / 路线 / 资源价值
```

**已确认设计取向：** 不以流派分类、旧 Q1/AGGRO/DEFENSIVE/ENGINE 四分类、或复杂 StrategySpec 作为最终 NOSL 决策的必经中间层；NOSL 与 SL 共享基础策略；端口是归纳偏置而不是信息瓶颈；卡牌规则由可信引擎执行、模型主要学习条件价值；正常 SL 信息约束不能被离线特权搜索偷换。

**待证实的技术假设：** 机制关系的共享学习是否优于 ID/简单静态特征；端口辅助头是否提升泛化；Actor–Critic 是否优于轻量打分器或 Q 直接评分；NOSL 蒸馏是否能显著降低 SL 搜索成本；最终能否达到人类级战斗表现与完整跑局增益。可以通过实验更换网络、训练法甚至撤销显式端口头，不影响上述原则。

## 1. 数学对象、观察历史和合法行动

用 \(x_t\) 表示模拟器内部的完整状态，其中可能有未揭示的 RNG、牌堆顺序、敌方未来；\(o_t=\mathcal O(x_t)\) 是玩家在时刻 \(t\) 合法可见的观察，\(h_t=(o_0,a_0,\ldots,o_t)\) 是合法公开历史。当前合法动作集合记作 \(\mathcal A(h_t)\)，其中动作必须包含具体的**卡牌实例、目标、选择内容、药水槽/目标、结束回合**等，不能只由卡 ID 决定。

- 已知抽牌堆组成、弃牌堆和耗尽区，与未知抽牌堆**排列次序**是不同的信息。允许使用公开计数、已揭示牌、公开状态修饰和历史推断；禁止从内部精确根直接传入隐藏次序、未揭示敌方意图或未来 RNG。
- 局内状态会随每个行动变化。即使同一张牌，前后顺序、敌人是否被击杀、剩余能量及后续抽牌潜力也会改变其价值。
- 对部分可观察过程，真正的理论充分状态是关于隐藏状态的条件信念 \(b_t=\mathbb P(x_t\mid h_t)\)；工程上可由合法历史记忆、公开计数与编码器近似，不强制实现精确贝叶斯过滤器。
- NOSL 策略是 \(\pi_\theta(a\mid h_t)\)，评估采用确定性 argmax 或预登记的采样规则；**每步重新调用策略**不等于每步重新搜索未来树。
- SL 可利用同一当前节点内**真实合法试探揭示**的额外历史 \(h_t^{SL}\)，并为搜索分支、回滚、重试和已揭示内容建立可审核权限。跨地图节点不允许事后回滚。离线完整根允许用作研究模拟/审计，但不等于合法在线信息。

## 2. 第一层：卡牌规则、组合关系与“理想牌序”

共享编码器 \(E_\phi\) 的输入应尽量包含已核实的 CardSpec/CardInstance/DeckSpec、公开手牌与区域、当前菜单、敌人、遗物、药水、能量、效果及历史。**规则引擎计算确定的效果；表示网络学习机制如何在具体条件下转化为价值。** N2E 的部分机制仍用明确缺失标记；未覆盖的卡不能被解释为“没有效果”。

“理想牌序”不是整场预先写死的卡牌排列，而是状态条件性的机制依赖：若行动 \(a\) 增强后续 \(b\)，则在给定可观察状态和资源下，\(a\!\to\!b\) 可能胜过 \(b\!\to\!a\)，但在当前可斩杀、费用冲突或抽牌受限时可反转。例如增加单段伤害的增益通常应先于多段攻击，却不能无条件优于立刻斩杀。

模型应能表达五类关系：**前置/时序依赖、组合协同、资源竞争、功能替代、条件冲突**。卡牌的贡献不是静态 \(w(c)\)，而依赖 \(D,h_t,a\) 与后续策略的条件量。探索性局外增牌协同可以用固定策略与固定分布下的交互差分描述，不能据此自动声称确定因果贡献或通用“卡牌排行榜”。

可研究集合编码器、注意力、条件交互图、行动对关系建模；不预先锁定 Transformer 或图神经网络。应通过机制跨构筑迁移、升级、重复卡、组合留出和行动先后对照，证明关系表示有用，而不是只看训练损失。卡组级知识能够预示潜在组合，执行阶段仍须根据实际抽牌、敌人与资源重新选择。

## 3. 第二层：输出、防御、运转是解释和归纳偏置

记三端口为 \(P=(A,B,R)\)，但**不把所有游戏信息压缩成三个常数**。

- 输出 \(A\)：即时爆发、限定回合内伤害、持续成长、目标清除与可靠兑现率。
- 防御 \(B\)：当前及未来关键回合的生存、减伤、击杀带来的威胁消除、生命/药水风险。
- 运转 \(R\)：抽弃牌循环、能量与其它资源、可打出性、关键牌到达时间、启动速度与稳定性。

应允许 \(P_\tau(D,h,\pi)\) 随时间视野 \(\tau\)、战斗、卡组和执行策略变化；端口间一般**非加性**：运转改善攻防，提前击杀降低防御需求，安全防御又允许成长。敌人产生的是具有时限的约束与风险，而不是永恒的三维需求常数。简单选择“差距最大的端口”会在斩杀、爆发与资源冲突场景失败。

推荐先实现**可选的端口辅助头或诊断视图**，例如预测受限回合的有效输出、关键回合生存风险、抽牌/资源可达性。辅助目标必须定义清楚量纲、时间视野和测量来源。可用规则可计算或受控 Rollout 导出适当标签；不必人为指定“输出=80 分”的无定义真值。网络内部保留足够维度以编码顺序、目标、多敌人、事件和复杂机制。

端口辅助头需要消融：有/无端口监督，控制容量、数据与预算，比较真实 NOSL 决策和新组合泛化；若无稳定增益可以降低其权重或只保留解释工具，**三端口概念不是强制的架构瓶颈**。

## 4. 第三层：NOSL 无显式搜索的直接决策

推荐共享状态/动作编码 \(z_t=E_\phi(h_t,D)\)，采用合法动作掩码与动作实例编码，输出

\[
\pi_\theta(a\mid h_t)=\operatorname{softmax}_{a\in\mathcal A(h_t)}
f_\theta(z_t,\operatorname{enc}(a,h_t)).
\]

实际 NOSL 循环：读取合法菜单和公开历史 → 编码 → 为每个合法**实例动作**打分 → 选择动作 → 由游戏推进 → 更新观察/记忆 → 重复至正常终局。结束回合、药水、交互选择与多目标动作必须同口径支持；没有合法可用动作时应正确结束，不得猜测非法动作。

重要区别：

- \(\pi_\theta(a\mid h)\)：直接给动作概率/优先级，适于快速部署。
- \(Q^\pi(h,a)=\mathbb E[U\mid h,a,\text{后续用 }\pi]\)：行动的**长期**条件价值而不是当前伤害；先增益再多段的关系可以体现在该量。
- \(V^\pi(h)=\mathbb E[U\mid h,\text{后续用 }\pi]\)：状态的长期价值。Actor–Critic 可用策略头 \(\pi\) 直接行动，用价值头 \(V\) 辅助训练；也可以学 \(Q\) 后贪心选择。三者不是互斥的模块。

核心是**部署时无逐动作显式多分支模拟**，而不是声称神经网络推理等于精确 Bellman 最优。允许轻量的合法规则计算、基础效果预览与特征缓存；若实现用逐动作全局试探才能做出选择，应计入搜索成本并另标模式。

训练效用 \(U\) 首先保证存活/胜利与可靠结果，再考虑 HP、药水、持续资源及相应风险。可以采用明确的词典序评价或受控的标量化目标，但不能通过赚取 HP 使死亡路线比胜路更优。局外训练的最终价值函数另行定义，不能将单场存活当作整局最优。

## 5. 第四层：SL 是对同一 NOSL 策略的合法搜索增强

以 \(\mathcal S_B(\pi_\theta,h^{SL})\) 代表预算 \(B\) 的 SL 搜索层。它首先执行 NOSL 路线，再在**当前节点允许的试探/重载信息集**内，有目的地调整动作或局部前缀，继续精确模拟或真正合法重试。

保持两阶段目标：**先发现、固定并验证完整合格胜路；再利用剩余预算改善 HP、药水和后续资源**。预算应包含所有引擎 Replay、重建、模型推理、状态保存与必要的在线试探成本。可用 NOSL 的动作概率、价值、风险、组合依赖来确定优先尝试哪处失误、哪个替代动作；搜索没有充分收益时可以停止，或使用基线回退。

务必把三种层次分开记录：

1. **NOSL 在线策略**：单次实际可见历史、无显式未来搜索。
2. **正常 SL 在线搜索**：已合法试探/揭示的当前节点历史，具备保存、重载和可检查权限边界。
3. **离线特权研究搜索**：内部精确根/RNG 可被研究软件用于生成、对照或标签，**结果不可冒充前两者**。

当前 F3B/F4/LS2B 的预测搜索主要属于第三类。预测后端的可用性、完整预测胜路、独立原生 L3 规则审计和正常 SL 在线合法性也属于不同资格维度。

## 6. 训练路径：将昂贵探索摊销为快速 NOSL 直觉

理想闭环为：合规多样化战斗根 → 当前策略采样完整轨迹 → 学习结果价值与动作关系 → 更新 NOSL 策略 → 用该策略指导搜索 → 保留具备合法解释的搜索反馈 → 继续训练。**训练可以昂贵，NOSL 实际部署必须便宜**；两种成本要分别计量。

建议分阶段推进，允许交叉反复：

**A. 可执行性/数据资格。** 基于 N2E 和 LS2A 管线扩大合法菜单、目标、选择、药水、区域状态和机制覆盖。区分模拟支持、N2E 编码完整、训练任务适用与原生严格验收；失败、截断和 unsupported 不能当成死亡。优先增加真实可达独立局史，特别是第二/三幕。

**B. 机制关系与直接策略基线。** 在可信公开信息下训练条件动作评分器或轻量策略；用简单人工规则、Card ID、已核实静态特征和机制关系表示作容量/预算公平对照。可通过规则生成的局部条件顺序任务辅助学习，但不能把固定全知牌序当真理。尽早跑真实完整 NOSL 单轨迹，而不只报告动作分类损失。

**C. 终局/价值学习与策略改进。** 允许 Actor–Critic、策略梯度、Q 学习、偏好学习、CEM/随机策略优化及更简单方法竞争；算法名称不是里程碑。对给定策略的战斗效用做估计，考虑奖励稀疏、长时信用分配、未见卡组及策略分布改变。潜在的中间奖励需防止鼓励刷分、拖回合或忽略生存；必要时使用可论证的势函数塑形或仅作辅助任务。

**D. SL 辅助。** 搜索可提供路线、失败位置与局部比较，但应区分依赖内部隐藏状态的离线标签、仅依据合法可见历史聚合后的统计教师、以及真正在线合法试探历史。对单个隐藏 RNG 下的“最佳行动”直接行为克隆会产生信息泄漏式教师偏差。可研究跨随机种子/隐藏状态配对估计、信息集聚合、条件偏好、优势估计和受限蒸馏；所有目标必须版本化教师策略与预算。

**E. 交替训练与评测。** 冻结策略版本与采样来源，比较更新前后 NOSL 无搜索水平以及它引导的 SL 质量—成本曲线。训练、模型选择、独立报告按配方族/遭遇/局史祖先/种子块隔离；已多次用于设计的报告根不重新称为盲测。迭代样本存在强相关，不能按动作数或派生根数虚报独立样本。

网络可采用共享编码器 + 直接策略头 + 价值头 + 可选端口辅助头；**不是强制采用 Transformer/大型 Actor–Critic**。若更简单的模型已达到同等质量与速度，优先采用更简单的部署方案。

## 7. 已有工程如何复用；LS2B 的位置

- **N2E**：CardSpec/CardInstance/DeckSpec、机制节点、缺失资格，是编码起点而非全卡规则完成证明。
- **LS1**：冻结战略排序、搜索与学习接入、真实反馈再训练，证明学习能影响搜索；四固定战略不是未来模型输出。
- **LS2A**：1,031 个去重根（986 synthetic + 45 来自 15 条第一幕原生局史），覆盖五角色、三幕和 79/80 遭遇、448 个实际卡 ID，四 worker 644.1 秒与 43,295 Replay；530 条低成本路径 unsupported，1,029 根至少一张 N2E 不完整牌。它证明生产规模和接口，不证明已经拥有足够可靠的策略教师数据。
- **LS2B**：在 40 个独立合成报告根下，学习 StrategySpec 提议/修复与冻结 F3B/F4 的胜根在 128/256 Replay 各为 6/40、7/40；32/40 根产生不同于四条旧冻结单线的实际路径，找到一次可追溯修复胜路。256 档总墙钟 P50 为 421ms（基线 223ms）；总体胜率和成本未改善，19/40 根的新规格触及不支持。**已实现可组合阶段/风险权重与修复的工程实证，不是高水平 NOSL 网络或合法 SL 完成证明。**
- **LS2B 后续定位**：StrategySpec 作为可解释的启发式教师/消融、搜索候选生成器、失败修复日志与训练数据来源。可以保留其工程侧车，但不再要求 NOSL 模型先生成一个 StrategySpec 才能出牌。旧四战略继续作为冻结对照。
- **F3B/F4/CombatSolver**：复用可信预测规则、既有路线搜索和 F4 incumbent 重建/质量改进；初期生产默认不受新神经网络改变。搜索与 SL 合法控制边界需要独立实现验证。

## 8. 连接局外长期价值学习

局内价值 \(Q_{\rm combat}(h,a)\) 评估此刻行动及后续战斗结果；局外 \(Q_{\rm run}(s,a)\) 评估接受/跳过/升级/删牌、路线和事件在未来遭遇分布、地图信息与跨节点资源约束下的长期作用。二者**共享“卡如何产生作用”的知识**，不必共用同一个价值头或固定三端口分数。

对于加牌，应比较“加入前后，跨未来敌人/资源分布，卡组有哪些能力瓶颈被缓解，哪些抽牌稀释和机会成本被引入”，而非把某张牌永久标记为小刀流、力量流或输出端 +N。局外最终优化的是正常 SL、独立未见完整跑局通关表现及成本与尾部风险；战斗内高胜率是必要基础但不充分。

| --- | --- | --- |
| 机制组合知识有用吗？ | Card ID / 静态效果 / 条件关系表示 | 未见组合的 NOSL 胜负、资源与成本 |
| 端口辅助真的有效吗？ | 无端口头 / 三端口或时序端口辅助 | 泛化与校准，控制模型容量和训练预算 |
| 直接策略需要何种头？ | 简单打分、Q 贪心、Actor–Critic 双头 | NOSL 同预算单次轨迹结果与推理延迟 |
| 搜索是否真正受益？ | 冻结 F3B/F4、StrategySpec、直接策略引导搜索 | 同预算完整合格胜路/锁定资源/总耗时 |
| 机制与策略对真实游戏有用吗？ | synthetic vs 原生可达不同幕/角色、独立局史 | 资格内的风险、HP、药水、胜率与覆盖 |
| 走向整局有用吗？ | 局外基线、不同战斗策略版本 | 独立整局跨种子通关率和尾部风险 |

报告至少分离：正常终局/超时/不支持、完整胜路与独立 L3、预测研究 vs 正常 SL、真实可达 vs synthetic、独立根/配方/历史 vs 动作记录、热推理 vs 完整端到端墙钟。统计不确定性和分组泛化比个别 witness 更重要。100 倍加速和 99% 以上通关等为长期愿景而非已证结果。

## 10. 建议的工程推进与可调整空间

**近期：** 保留 LS2B 冻结交付，不要求重写。先指定一个新的 opt-in NOSL 策略接口：公开历史/合法动作实例 → 分数/概率 → 原生或可信模拟推进；复用 LS2A 根工厂，建立五角色、机制缺失明确的真实完整单轨迹对照。扩展选择、多目标与未支持机制的可信覆盖，与模型研究并行推进。

**中期：** 新策略学习、机制关系/端口辅助消融、分层训练数据与稳定的独立 NOSL 评价；再把最好的冻结 NOSL 接到 SL 搜索，研究首胜与质量成本。由实际数据决定采用 Q、策略头、双头、记忆模型还是更简单模型。

**长期：** 建立正常 SL 合法试探/重载执行器与端到端规则验证，扩大真实可达多幕、药水与遗物分布；当战斗求解器足够强且便宜时，用其生成版本化节点死亡/资源联合分布并推进局外长期规划。

**允许调整：** 端口是否显式、辅助头数量、表示网络结构、RL 算法、是否使用结构化搜索提议、相对训练预算、人工规则与学习器的混合比例；需要由公平消融与资源成本决定。**不随意改变的原则**：合法信息边界、忠实规则与标签资格、同等预算比较、NOSL 直接决策/SL 额外搜索的职责分工、卡牌条件交互与跨局内/局外共享知识、最终独立整局验证。
