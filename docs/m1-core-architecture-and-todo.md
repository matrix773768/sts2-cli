依据：已确认的 M1-SV、M1-N 理论设计及截至 N4C 的实验。N4C 的远端提交已核对为 `7e6f55605188393346b912ae591ce86aaf8a6fce`。2026-11-26 用户确认后续按 CORE-1 至 CORE-4 推进。本文件作为仓库 `docs/m1-core-architecture-and-todo.md` 的长期架构基线与任务验收依据；不回退代码，不覆盖历史证据。N4C 的收尾结论与当前状态见第 11 节。

## 1. 研究目标与范围

长期目标是在不继承其他 AI 权重、不依赖其策略监督的前提下，利用游戏规则、搜索和主动知识发现，以有限计算资源构建具有竞争力、最终超越顶尖人类的 STS2 AI。研究假设是：充分利用游戏结构可以提高样本效率及总体计算效率；这是假设，而非已经获得的实验结论。允许复用开源模拟器、战斗求解器和已有算法，允许使用合法取得的人类数据；外部 AI 成绩作为参照，不直接复用其训练模型或策略标签。

当前范围：STS2 v0.113.1、Ironclad、单场战斗、NOSL 公平信息策略，逐步纳入完整构筑与资源。长期保留 SL、局外构筑和完整跑局目标，但不与当前阶段混评。Ideal、Oracle 是独立诊断工具，不是正式公平策略。

核心分工：**规则直接给出已知机制，搜索负责完整回合战术，学习型评价器负责长期战略。**

核心可证伪假设：在合理的端到端计算预算下，完整回合搜索 + 机制化战略价值能够比单动作 Q 基线获得更好的实际战斗表现，并通过自主迭代持续提高。若搜索成本、价值误差或覆盖限制导致失败，应定位具体瓶颈，而非无限地追加独立模块。

## 2. 总体架构与接口

```text
L0  游戏规则、状态复制、公开观察与条件信念
                 │
                 ▼
L1  完整回合战术图：决策 / 随机 / 结算 / 终局
    等价化、合法见证、预算、循环发现
                 │
       完整战术后继与条件概率
                 ▼
L2  机制状态表示：玩家资源供给 × 敌人未来需求
    原始规则结构 + 实际动态状态 + 可验证派生量
                 │
                 ▼
L3  战略分布价值 Z：胜负、净战损、持久资源
                 │
                 ▼
L4  比较合法候选条件策略，执行并在新观察后重规划
                 │
                 ▼
L5  战略边界经验、配对反事实、搜索教师、独立评测
                 └──────────────► 更新 L3
```

| 层 | 核心职责 | 输入与输出 | 不承担的职责 |
| --- | --- | --- | --- |
| L0 | 真实规则执行、分支恢复、公开信息隔离 | 状态 + 动作/合法随机事件 → 转移与观测 | 战略评分；用近似规则替代原生语义 |
| L1 | 当前回合可达性计算 | 公开根与预算 → 合法条件策略图、后继、概率、见证和覆盖 | 从局部伤害直接推断最优战略 |
| L2 | 完整机制表示 | 战术后继及规则 → 结构化状态、动态特征、缺失标记 | 仅用固定攻防评分代替游戏状态 |
| L3 | 长期价值预测 | 具有正确边界及续策身份的状态 → 终局分布 | 重新学习已经能够精确计算的战术结算 |
| L4 | 策略执行和预算分配 | 候选图与评价 → 可执行条件计划、实际动作 | 提前知道未公开随机结果；假设有限候选即全局最优 |
| L5 | 学习与检验 | 战略边界、合法反事实及真实终局 → 新价值模型、评测证据 | 因离线指标改善就替换基线 |

L1/L2 并非完全串行：战术搜索需要 L0 提供足够的动态语义，L2 也可以利用 L1 的实际模拟结果。需要共享同一规则与公共状态合同，避免另外实现一套近似战斗逻辑。

## 3. 战术搜索：完整回合是决策单位

### 3.1 评价边界

- A：玩家提交 EndTurn 前的稳定出牌状态（或已明确的提交边）。保留手牌、格挡、未完成结算及所有机制状态。
- B：下一回合首个正常公开决策状态，或更早的真实战斗终局。作为首选战略学习边界；完整回合的价值包括玩家行动和实际结算。
- C：模拟器遇到无法直接确定的随机事件时的可恢复边界。C 可在回合内、回合结算内或下一回合发牌内出现，不是全游戏固定阶段，也不保证一定发生在敌人行动之后。C 首先是搜索分支接口，是否单独训练 C 价值头由成本实验决定。

凡可确定的规则结算交给引擎。在未知抽牌处建立合法条件分布并继续搜索。对于过早斩杀、玩家死亡、真实待选菜单、复杂触发等，依实际事件顺序处理，而不是套用统一结算流程。不要把 C 或 A 的普通截断当作已经完成回合。

第一代主价值函数优先在 B（以及真终局）定义；若跨随机边界的成本难以接受，可以比较 A/C 的期望价值近似或原 Q 回退，但其使用范围、覆盖及近似误差必须报告。不要在第一轮强制同时训练三个边界的网络。

### 3.2 确定性图、置换不变性和随机图

若两个动作 a、b 在当前状态均可合法交换执行，且 F_b(F_a(s)) 与 F_a(F_b(s)) 的后续合法动作、转移和收益等价，则合并后继节点，保留全部合法入边和见证。相同伤害、格挡、HP、牌名集合或候选循环形状都不足以证明等价。费用到期、遗物计数、顺序触发、牌实例、牌区、敌人阈值及累计资源变化可能打破等价。先复用保守键 K0/K1；更激进的 K2 需证明或穷举差分验证，不能依赖未认证神经网络硬剪枝。

公开历史 h 包括与后续决策相关的信息和条件信念。区分引擎内部完整状态键（用于同一分支的模拟缓存）与公开信息键（用于公平策略），不能用私有实现决定正式策略或候选搜索预算。相同公开摘要若有不同条件信念，不能直接合并为同一决策节点。

完整回合图包含四类节点：玩家决策、未知随机事件、确定性结算、真实终局。决策节点在合法候选中选优；随机节点按当前合法条件概率混合；随机观察公开后允许继续选择。完整回合方案是条件策略 μ，而非预先固定一条知道未来抽牌的动作序列。简单确定性回合可用单一路径表示。

应保留不同输出、防御、成长、牌序控制和资源变化的联合结果，不将互不兼容的最大输出、最大格挡等拼接，也不因固定攻防二维前沿而剪掉潜在成长方案。理想目标是尽量穷尽合法回合；现实使用有限预算时，应记录未扩展动作、未解决随机质量、终局/回合边界覆盖、回退策略及成本。搜索未找到胜利不等于证明失败。

### 3.3 性能与复用

优先调查并复用 SV1 的确定性状态图、HotKernel 1.0.2、HotDraw 的受控普通抽牌与恢复、N2A 的结构见证。研究期允许选择现有 SV4A 宿主作为正确性参照；热核宿主采用与否由实测决定。新热核单步峰值不等于完整公平搜索吞吐。

先做常驻根、复制/恢复、状态去重、批量边界导出与模型批推理等必要优化；只有证实某类回合过大时才增加引导、启发式或近似预算。循环候选的粗形状只用于发现见证；验证实际资源及触发变化，不把有限循环自动视作无限。

## 4. 战略评价：玩家供给与敌人需求

以完整的公开战略状态和机制描述作为输入，不将其压缩成仅有伤害、格挡、当前总攻击的少数统计量。静态规则缓存与动态状态分开。规则描述、派生统计、实际模拟结果三者互补；优先复用原生/预测引擎真实规则计算。

| 对象 | 必需表达的语义 | 研究优先级 |
| --- | --- | --- |
| 敌人 | 身份、生命/格挡、按顺序攻击段、当前相位、未来行动规则、成长及条件转换、一次性事件、干扰和状态牌 | 首批必须能区分跨回合压力及成长变化 |
| 玩家 | HP、最大 HP、能量、格挡、持续 Power、遗物/药水、临时与永久修正、费用来源与到期、触发计数 | 首批支持真实动态及终点差异 |
| 卡牌与牌区 | 实例、修饰、效果与合法规则、手牌/抽牌/弃牌/耗尽等、合法已知牌顶底与未知多重集 | 首批保留后续可达性所需信息 |
| 运转能力 | 即时联合可达集合、未来一至数回合的条件资源供给、增长、启动与循环证据 | 基础闭环建立后逐步加入昂贵结构搜索 |

继续采用用户确认的敌人行动确定或条件确定前提。根据玩家实际行动分支更新敌方阶段、成长、触发与后续规则；不能用一条与玩家干预无关的固定未来攻击曲线替代条件规则。未知抽牌与其他真实随机效果仍然随机。若实际实现遇到未资格化机制，显式报告，不能用错误假设将其作为已验证机制。

关键诊断：同当前意图、不同未来成长或相位；单段/多段攻击和力量变化；临时/永久修正；当前费用相同但生命周期不同；双节棍临界计数；牌顶回收减力量牌与下一回合多段攻击；玩家成长与敌人成长的竞争；相同牌组潜力、不同启动难度。要求可见信息实际可区分，合法分支与价值反转有真实证据。保留不同敌人/同构筑与不同构筑/同敌人的对照。缺失字段明确标记，观察资格与搜索资格分离。

不提前锁定 MLP、Transformer、关系图、宽度、层数。先验证信息表达与战略价值，再比较同信息的轻量模型和实体交互模型。N4B 的 16 维回归仅为攻防诊断基线，不能称作完整战略评价器。

## 5. 价值函数和策略改进

令 h 表示 B 边界的公开充分状态（含必要历史、信念和机制），固定合法续策 π，Y 表示终局资源及胜负。

$$Z_B^\pi(h)=\mathcal L(Y\mid h,\pi).$$

在当前战斗目标下，保留 DC2B 的死亡独立类别、胜局带符号净战损分布及冻结效用作为首要基线。初期不要求一次性建模所有持久资源的联合分布，但真实账本应保存终局 HP、最大 HP、金币、药水等供扩展。当前 HP 减终局 HP 是从当前边界开始的未来净战损；比较同一根的候选时统一换算到该根效用，已付成本只计一次。死亡、截断、unsupported 分别记录；不要把死亡赋值饱和误认为行动严格等价。可增加诊断性生存时长、敌人剩余 HP、启动情况等，不未经审查改变正式优化目标。

对于从根 h 可执行的完整回合条件策略 μ，其后继分布为 P_μ(dh'|h)，真终局按吸收状态处理：

$$Z^\pi(h,\mu)=\int Z_B^\pi(h')\,P_\mu(dh'\mid h).$$

在一致的终局效用 U_h 下选择：

$$\widehat\mu=\arg\max_{\mu\in\widehat{\mathcal M}(h)}\mathbb E_{Y\sim\widehat Z(h,\mu)}[U_h(Y)].$$

这里候选集有限，所学价值依赖续策，不等于最优 Q。若存在随机观察，则在合法已公开结果上适应；概率混合的是终局分布，不是平均牌序、状态或分位数。保留风险分布用于死亡/尾部等评估，未来若研究 CVaR 不默认可按节点递归。单动作 Q 可以作为回退或搜索排序，不能取代对完整战术条件策略的比较。

## 6. 数据与学习闭环

1. 冻结参考续策（首轮以 G2 为基线），从自然战斗和定义明确的人工课程收集真正的 B 边界及实际终局；历史轨迹仅在足够可靠地回填边界/机制时复用。
2. 在同一公开根搜索多个有实际联合状态差异的完整回合方案，用合法条件世界配对续战。选择与独立复评世界隔离。保留共享世界的原始差值、采样误差、续策身份及支持范围；N4B 配对损失可沿用。
3. 先验证搜索教师的决策收益，再学习。配对世界可降低方差，不必然减少弱续策偏差；有限候选选优、采样误差及网络学习误差分别报告。对于高质量教师标签，先检查训练集拟合，再检验未见构筑和敌人的泛化。
4. 冻结价值 Z_k，执行搜索生成完整回合条件策略 π_k^+，用真实执行经验训练 Z_{k+1}，并在相同基准比较。只有实际能力收益才允许更新部署基线；失败保留原基线。策略迭代、Bellman/TD 或 PPO 等可作为后续备选，不预设必须沿用一种训练方式。

普通自然状态用于保留覆盖；高压力但有可行方案的状态用于辨别战略取舍。保留未获胜、近似等价、不确定、无法资格化的样本及原因。不只采搜索成功的案例。构筑族、根及衍生随机世界隔离；另考察跨遭遇/模板泛化。人工干预分布和自然战斗分开统计。正式 NOSL 训练不利用隐藏未来；Ideal/Oracle 只用作潜力、结构发现或单独上限诊断，不能直接模仿其动作或将理想成功作为公平胜率。

- [ ] 用 CORE-1 的合法完整回合候选构造配对反事实标签；重点分析输出、防御、成长、跨回合牌序控制与敌方相位的战略差异。
- [ ] 先以共同世界选优、独立世界复评检验候选搜索教师相对 G2 的收益，区分局部单次改进与整场提升。若教师无收益，先诊断候选覆盖/续策/条件采样，不机械训练。
- [ ] 在相同数据上比较简单价值基线与机制增强的 Z_B 模型，视证据测试配对差损失、轻量关系编码或 A/C 近似；报告学习曲线、训练拟合、独立泛化与推理成本。

完成标准：能从真正的战略后继得到可学习、可检验的价值标签；新模型能够在独立构筑与机制对照上选择有意义的战术方案，并明确适用范围与剩余误差。不得用单动作 Q 的排名改善替代此验收。

### CORE-4 — 第一版完整战斗闭环与固定能力验证

- [ ] 将战术图、机制输入、战略价值及执行器整合；遇未知观察后合法重规划，使用冻结 G2 或旧搜索作为有界退路。
- [ ] 在正常战斗全程运行并与 G2、G2-search 配对比较；控制实际部署时间与搜索预算，分别报告搜索覆盖、回退率、真实胜负、同胜战损和严重战损。
- [ ] 必要时比较选择性部署与全程部署，明确实际用到了哪些新机制与价值能力。
- [ ] 冻结训练/选模/确认口径，提前规定可接受的退化范围与样本预算。若未显示改善，分别诊断 L1、L2、L3、L4 的失败贡献，不自动开启更多微调。

完成标准：首次获得可运行的完整架构，而非独立子模块。以固定基准上的能力—成本曲线判断是否值得继续；未达到升级资格则保留 G2，不宣布替换。

### CORE-5 — 战略知识增强与自主策略迭代

- [ ] 将 N2A 的理想潜力、循环见证、启动可达性和兑现条件作为正式战略表示/辅助监督候选，并保留理想与真实公平结果的差异。
- [ ] 在当前策略确实无法处理的难例上研究多回合公平搜索、更强续策和高辨别力方案；比较新增知识的单位计算成本。
- [ ] 进行最少一轮完整的“更强搜索 → 新战略价值 → 新搜索策略”迭代，分别测量教师收益及学习后损失。只有得到正面证据才扩大训练规模或网络容量。
- [ ] 根据实际瓶颈推广更多遭遇、卡牌和真实构筑；研究从人类数据取得真实分布（若权限与数据资格允许）、选择性高预算搜索以及可选的单动作蒸馏加速。

完成标准：至少在独立确认协议下证明新增结构知识或更强教师带来真实能力/成本收益，并检验能否支持下一轮策略改进。失败则保留负面证据，回到相应层定位，不能无限滚动训练。

### CORE-6 — 后续范围（不作为当前工程授权）

- [ ] 扩展正式 SL 重试规划与合法历史信息；与 NOSL、Oracle 分开评测。
- [ ] 将战斗资源结果分布交给局外路线、卡牌、事件及商店规划；建立自然完整跑局基准。
- [ ] 研究独立训练系统与外部 AI 在可比规则、任务、样本及总体计算成本下的能力关系；最终检验超越顶尖人类的长期目标。

进入条件：单场战斗系统具备足够可靠的能力、信息规则和计算效率；不得从合成战斗胜率直接推出整局胜率。

## 9. 防止研究偏离的管理约定

以后每次任务必须明确：对应 TODO、解决的具体瓶颈、输入输出接口、采用已有证据的范围、实验基线、计算预算、完成条件、停止条件、失败归因。任务交给 Codex 时给出研究目标和约束，允许它自主选择实现、实验、修复和必要迭代，不要求用户审批每个内部子步骤。

暂缓：继续大规模单动作 Q 微调、全卡池机制目录无目标扩张、未经实际收益验证的模型扩容、恢复 DC2B 夜间训练、外部 AI 权重/策略教师接入、提前启动正式封存评测。必要时可将这些作为小型对照或经论证的辅助措施，但不能取代核心路径。

每次实验结束分别填写“工程完成”和“研究假设证据”。TODO 只有验收证据成立才标记完成。报告结尾的下一步建议不自动成为主线。局部正收益、不充分的负面结果、预算失败和真实反例均须准确记录；如果必须调整主架构，应先说明原假设何处失效、哪些阶段受影响、为什么更改比继续原路线更合理，并更新本文件版本与 TODO 状态。

在第一版闭环前，避免为了单独提高离线损失而改变主价值边界。闭环建立后，优先根据实际能力和端到端计算成本选择投入方向。明确样本效率与总计算效率的区别；只有可比较的任务和评价规则才支持跨项目能力结论。

## 11. N4C 收尾与当前执行状态（2026-11-26）

N4C 工程验收完成，研究假设尚未达到部署升级门槛。主确认为 64 个构筑族、160 个配对根世界、12 臂共 1,920 场完整战斗；51 个族曾用于 N4/N4B 的开放确认，本轮评测种子重新生成。选择性终点评价相对 G2 的普通、熟悉压力、新遭遇胜场分别为 30/64 对 28/64、45/48 对 47/48、40/48 对 40/48。普通战斗胜率退化及严重战损增加的保守单侧上界为 5.22 和 8.40 个百分点，未达到预定 5 点容忍线。另 16 个独立族的压力复评从 57/64 胜增至 64/64 胜，七次翻盘集中于两个族。混合监督改善普通开发优势 MAE（63.70 降至 8.31），却未稳定改善全程部署。累计任务墙钟 28.1 分钟，9 项测试通过，14 条定向原生复放胜负及终局资源匹配。主实验仍为 prediction_only，不能视为逐轨迹严格认证。

**决策：冻结 G2 继续作为默认策略和参考续策。** N4C 的 16 维回归、有限候选和门控保留为诊断资产，不作为新主架构；不启动 N4D。单次干预与连续策略改进的差异、自然中晚期状态覆盖及未来敌方机制遗漏，在 CORE-2 至 CORE-4 的完整回合评价框架中统一研究。

当前冻结 G2 权重 SHA-256：`1077c191586885c49173afe5801849b3ea6a4535425731e27226fe1978abf084`。CORE-0 的架构确认和 N4C 收尾已完成；固定新基准和累计计算账本仍待落实，作为 CORE-1 的启动前置工作，不另开训练任务。CORE-1 为下一项核心技术任务，CORE-2 在共享合同确定后可部分并行，CORE-3 依赖两者的最小资格，CORE-4 完成首个闭环。CORE-5、CORE-6 暂不启动。
