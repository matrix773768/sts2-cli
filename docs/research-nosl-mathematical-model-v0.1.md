## 0. 为什么要建立正式数学模型

卡牌/卡组评价、牌序和局内策略互相依赖。固定一套弱策略训练卡组价值模型，会系统性低估该策略不会使用的机制；仅学习单牌即时伤害，不能合理评价“先增益后多段攻击”；直接模仿离线掌握隐藏 RNG 的最优路线，又会向 NOSL 注入不可获得的信息。

因此**不采取**“先给全部卡牌一个静态评分 → 聚合卡组评分 → 再据此写出牌启发式”的开发顺序；也**不采取**将 Q1、AGGRO、DEFENSIVE、ENGINE 或 LS2B 的 StrategySpec 当作最终 NOSL 网络必须输出的类别/脚本。

本方案采用一个统一的、以完整战斗反馈改进的条件策略。卡组知识、卡牌组合和行动价值**通过共享表示与策略迭代共同学习**，而不是要求提前获得专家牌序标签。数学模型现阶段需要确定信息集、输出、目标和正确性边界；网络深度、具体 RL 算法及端口是否显式监督则在严格对照中调整。

### 0.1 核心思想

```text
游戏原生规则/可信预测引擎（决定真实转移）
                    |
合法公开观察、区域和历史 + 当前完整合法动作菜单
                    |
共享卡牌身份/机制/公开修改编码
                    |
卡组长期潜力 + 当前手牌/区域 + 敌人/资源 + 合法历史
                    |
     条件交互与融合（非静态牌序/非四战略）
                    |
        +-----------+------------+
        |                        |
  直接策略 pi_theta         多输出价值 C_psi
  对合法实例动作评分       胜率、胜利加权 HP/资源
        |                        |
        +------交互训练----------+
                    |
         NOSL 单次战斗，无在线显式树搜索
                    |
    独立可关闭的 SL 搜索增强、局外价值模型（后续）
```

## 1. 决策过程：部分可观察、事件驱动、信息集明确

### 1.1 POMDP 与事件决策点

固定游戏/求解器版本、难度及一类战斗根采样分布 \(\rho\)。将每次需要玩家作出**合法操作**的时刻记作 \(t\)；一次操作可以打牌、选目标、做嵌套选择、喝药、结束回合，敌方动作及自动触发可能发生在两次玩家操作之间。

定义内部状态 \(x_t\in\mathcal X\)，其中可能包含未揭示牌堆排列、RNG/续体及未来生成信息；合法观察 \(o_t=\mathcal O(x_t)\in\mathcal O\)；合法实例动作集合 \(\mathcal A(o_t)\)；环境转移核 \(K(x_{t+1}\mid x_t,a_t)\)。这里的“核”也包含潜在随机结果和自动推进；在精确根内实现可为确定状态转移，但模型**不得看到**其隐藏输入。

一条合法 NOSL 历史为

\[
h_t=(o_0,a_0,o_1,\ldots,a_{t-1},o_t).
\]

策略 \(\pi_\theta(a\mid h_t)\) 的定义域是所有可观察历史及其合法动作集合，满足

\[
\pi_\theta(a\mid h_t)=0\quad\text{若 }a\notin\mathcal A(o_t),\qquad
\sum_{a\in\mathcal A(o_t)}\pi_\theta(a\mid h_t)=1.
\]

终局 \(\mathrm{done}\) 必须严格区分正常胜利、正常死亡、动作上限、搜索/墙钟上限、不支持、规则风险和不可核实错误；后几者**不是**数学意义上的死亡样本。

### 1.2 为什么不是完全可观察 MDP

即使玩家知道抽牌堆里有哪些牌，也可能不知道它们的真实顺序；当前可见敌方意图不代表未来意图全部已知；某些 RNG 状态从未被揭示。同一个 \(o_t\) 可以对应多个 \(x_t\)，且理性行动可能取决于此前已见过哪些牌、发生了什么。因此只把当前截图当作 Markov 状态通常不充分。

理论上的信息状态为

\[
b_t(x)=\mathbb P(x_t=x\mid h_t;\rho,K,\mathcal O),
\]

这是对未观察内部状态的条件分布。**v0.1 不要求精确构造 \(b_t\)**：允许使用合法计数、区域信息和历史编码记忆 \(m_t\) 近似其决策相关部分。不得因为模拟器可以提供完整 \(x_t\)，就把 \(x_t\) 直接当成网络特征。

严格区分三类信息模式：
1. **NOSL**：单次流程，策略只观察截至当前合法公开历史，不试探多个未来分支后挑选。
2. **正常在线 SL**：在规则允许的当前节点内，保存/重载并利用实际合法揭示的试探历史；跨地图节点不可撤回。
3. **离线特权研究**：允许研究程序读取精确根/隐藏 RNG 进行回放、数据生成与反事实检验；其结果须明确标为研究预测而非合法在线能力。

本数学模型首先解决模式 1；模式 2 是额外的后续控制层，不混入 NOSL 输入。

### 1.3 真实可见、已知、未知与不支持

输入必须逐项分类：公开可见值、依据公开历史可确定的值、仅知道计数/分布的值、不可获知值、观测缺失/机制不支持值。**未知不是 0，缺失不是不可获知，公开的卡组多重集不是隐藏牌堆顺序。**

特别审计：手牌卡牌实例与当前费用、抽牌堆的合法已知组成/数量、弃牌与消耗区、临时生成牌、牌堆变化、战斗能力、遗物、药水槽、敌方目标标识与当前已揭示意图。不得把 LS2A synthetic 配方中的内部信息默认等同于玩家当时可见信息。

## 2. 新模型的学习对象：不是“卡牌固定分值”

我们区分三个数学对象：

- **卡牌规则机制** \(M(c)\)：在固定版本下静态或当前可预览的确定效果（费用、触发、顺序、目标、持续时间等）。这部分应尽量从可信规则获取，而不是要求网络猜规则。
- **条件组合知识** \(R(c_i,c_j\mid h)\)：两个行动/卡牌在当前上下文中的前后依赖、资源竞争、相互增强等。它不是静态、对称的“协同分”。
- **策略下长期结果价值** \(Q^\pi(h,a)\) 或 \(V^\pi(h)\)：行动或状态在指定后续策略、隐藏状态条件分布及战斗效用定义下的长期统计结果。

例如“先获得每段伤害增益、再打多段攻击”在若干已知条件下提高总伤害，但若当前攻击可立刻斩杀、增益耗尽能量或更紧急的生存约束被触发，整场战斗效用的行动顺序可能反转。**局部机制事实不等于所有局面的最优动作标签。**

卡组价值也依赖所采用的后续策略：

\[
J^\pi(D,e)=\mathbb E_{\rho,\pi}[U(\tau)\mid D,e],\qquad
\Delta^\pi(c\mid D,e)=J^\pi(D+c,e)-J^\pi(D,e).
\]

因此局外加牌效果与 NOSL 策略要交替改善；不先训练一个脱离策略、号称“卡组内禀胜率”的固定评分器。

## 3. 编码器：共享卡牌语义、分层状态、条件交互

### 3.1 CardSpec / CardInstance / ActionInstance 的区别

静态 **CardSpec** 含版本、ID、费用规则、类型、目标、关键词、升级及**有序效果**；动态 **CardInstance** 含具体实例、升级、永久或公开临时修改、当前费用及所在区域；**ActionInstance** 则是当前菜单中的一个具体合法操作，包括动作种类、实例绑定、目标、选择参数、药水及结束回合。

这些不是同一对象：一张卡可能有多个实例，攻击不同敌人是不同动作，弃牌/选择时的对象也不能仅靠卡 ID 表示。同名重复牌须保留可执行索引或稳定实例键；菜单索引仅为当前合法绑定，不可视为可以跨决策点复用的永久身份。

N2E 已有 CardSpec/CardInstance/DeckSpec、有限有序效果节点与缺失标记，但并未描述全部卡牌，也尚未提供覆盖所有公开区域/嵌套选择的完整观察。v0.1 必须通过新版公开接口逐项补齐，不能直接把旧 LS2A 根级训练记录当成逐动作数据。

### 3.2 卡牌基础编码

对卡牌实例 \(c_i\) 建议定义

\[
e_i=E_{\rm card}\bigl(E_{\rm id}(\mathrm{ID}_i),\,
E_{\rm mech}(M_i),\,E_{\rm inst}(q_i),\,\mathrm{mask}_i\bigr)\in\mathbb R^d.
\]

这里 \(M_i\) 是机制效果序列，\(q_i\) 是升级/公开修改/费用/区域等适当实例字段，\(\mathrm{mask}_i\) 区分完整、部分、未知及具体字段缺失。身份通道用于尚未完全结构化的机制及特异效果；机制通道用于跨 ID 迁移。可选融合、门控或残差，不要求一开始固定维度、层数或模型家族。

有序机制节点不宜被无序求和后丢失次序；可以从受限词表的带类型效果序列开始，再逐步支持触发图、条件、嵌套效果。规则模型只提供**已核实语义**；未覆盖部分带显式缺失表示。由于预测器的可执行性与 N2E 语义完整性不同，须分别记录两种资格，不能将 N2E partial 自动视为战斗不能执行。

### 3.3 长期卡组、区域与历史不对称

同一张牌在“卡组拥有”“当前手牌可打”“公开弃牌堆”“未知位置的抽牌堆”中具有不同意义；因此设计共享基础卡牌编码、**不同区域的条件聚合**，而非简单混成一包卡。

\[
\begin{aligned}
z_D &=F_D(\{(e_i,n_i)\}_{i\in D_{\rm known}}),\\
z_{H,t}&=F_H(\{e_i:i\in H_t\},o_t),\\
z_{Z,t}&=F_Z(Z_t^{\rm public},\mathrm{known\ masks}),\\
z_{E,t}&=F_E(\{e_j^{\rm enemy}\},\mathrm{intents}^{\rm revealed}_t),\\
m_t&=G(m_{t-1},o_t,a_{t-1}),\\
z_t&=F_{\rm fuse}(z_D,z_{H,t},z_{Z,t},z_{E,t},m_t,\mathrm{resources}_t).
\end{aligned}
\]

- **卡组与手牌的无序列举**应满足置换不变/等变：仅更换输入列表排列，不得改变相同动作的评分。重复数量、升级、实例修改仍有意义。
- **敌人实体**需允许目标级区分：重排实体列表时，绑定到同一敌人的动作评分应随目标一起等变，而不是凭列表槽位改变策略。
- **实际行动历史**有序，不能以集合平均代替；先用可审计历史摘要，必要时加入 GRU/Transformer 记忆。训练时避免把上一轮隐藏精确状态传入记忆。
- 稳定不变的静态卡组部分可缓存；临时生成、消耗、升级、牌堆转移及区域计数必须随合法观察更新。**静态潜力与当前可达性不同**。

### 3.4 有方向的条件关系

允许

\[
r_{ij,t}=F_{\rm rel}(e_i,e_j,z_t),\qquad
r_{ij,t}\ne r_{ji,t}.
\]

此项表示条件关系，不预设为真实因果效应，也不强制每对牌都有人工标签。关系可能包含前置、协同、互斥、替代、抽取/费用可达性和顺序。注意**普通 self-attention 本身并不证明已学会有向牌序**：输入应包含动作/效果顺序与资源上下文，并通过顺序对照任务、完整行为结果和有/无关系层的消融检验。

第一版可用小型 self-/cross-attention 或受限关系网络，重点保证：
1. 当前能识别哪些牌是**手中可打**、哪些只是未来潜力；
2. 合法实例动作能访问其相关卡牌、目标及资源上下文；
3. 增益→多段攻击的局部机制关系在支持范围内可被核验，但不被升级为无条件牌序命令。

计算成本需同时测量 \(O(|D|^2)\) 的关系计算、手牌关系、候选动作数量及逐动作前向；若可采用更轻量条件池化且表现等同，应优先保留低延迟方案。

## 4. NOSL 策略头：对实际合法动作进行条件评分

动作编码为

\[
u_t(a)=E_{\rm action}(a,o_t,\text{相关 CardInstance/Enemy/Choice}),
\]

策略 logits 为 \(\ell_\theta(h_t,a)=F_\theta(z_t,u_t(a),\widetilde E_t)\)。用**当前真实菜单**进行合法掩码并归一化：

\[
\pi_\theta(a\mid h_t)=
\frac{\exp\ell_\theta(h_t,a)}
{\sum_{b\in\mathcal A(o_t)}\exp\ell_\theta(h_t,b)}.
\]

可选部署决策为确定性 \(\arg\max\)；训练时使用明确记录的采样/探索分布以保证覆盖。两者不应在评测时暗中切换。**NOSL 不在每个操作处展开多个完整未来分支**；可使用合法规则元数据、即时公开预览与特征缓存。只有实际启用多分支模拟时才归入搜索层并单独计成本。

动作空间必须含打牌/目标、药水、合法嵌套选择、结束回合；特殊动作/不可打牌不能隐式丢弃；不存在有效其它动作时应能合法结束。需要保证相同动作实例的日志概率在数据回放中可重建；不同动作索引和重复卡不误配。

## 5. 价值究竟预测什么：政策条件的联合战斗结果

### 5.1 首选的理论对象

设终局指示 \(W=\mathbf 1\{\text{正常胜利}\}\)，终局资源 \(R_T=(H_T,P_T,\ldots)\)，其中 \(H_T\) 为实际剩余 HP、\(P_T\) 为药水槽/具体药水等资源。**理论上**希望评价在后续采用固定 \(\pi\) 时的联合条件分布：

\[
\mathcal L^\pi(W,R_T\mid h_t).
\]

这样能同时区分死亡概率、胜利时资源以及分布尾部；仅预测胜利者平均 HP 会忽略失败者的风险。它也更适合未来局外节点价值，而局外回报仍需另外定义。

### 5.2 v0.1 的可训练近似：三个输出组

先选一个明确的归一化 \(0\le \bar H_T\le1\)（例如胜局 HP 除以对应终局 max HP）及固定的有界资源特征 \(g(P_T)\in[0,1]^k\)，**不能把所有药水永久假设为等值**。

推荐政策条件价值向量：

\[
C^\pi(h)=\bigl(p^\pi(h),\,m_H^\pi(h),\,\mathbf m_P^\pi(h)\bigr)
\]

\[
p^\pi(h)=\mathbb E_\pi[W\mid h],\quad
m_H^\pi(h)=\mathbb E_\pi[W\bar H_T\mid h],\quad
\mathbf m_P^\pi(h)=\mathbb E_\pi[Wg(P_T)\mid h].
\]

这里 \(m_H,\mathbf m_P\) 是**胜利加权的无条件期望**，死亡时目标为 0，而非只在获胜样本计算的条件均值。若 \(p>0\)，条件胜利 HP 均值形式上为 \(m_H/p\)，但在低胜率下不稳定，不能把此比值作为唯一学习目标。

实现可直接预测这些量并检查 \(0\le m_H\le p\)，也可参数化 \(p=\sigma(\ell_p)\)、\(\mu_H=\sigma(\ell_H)\)、\(m_H=p\mu_H\)，药水等资源采用合理有界/结构化输出。后一种天然满足约束，但需要对获胜样本的条件资源拟合和校准，死亡样本只监督胜率部分。两种形式是可比较的实现选择，不应混淆目标定义和参数化技巧。

胜率、HP 和药水是**终局结果价值**；输出、防御、运转是**战斗能力端口**，不是三个价值头。

### 5.3 标量决策偏好不等于多输出预测

策略训练需指定一个标量目标或明确的受约束优化规则。简单的参考标量效用是

\[
U_{\alpha,\beta}(\tau)=W[1+\alpha\bar H_T+\beta g_0(P_T)]
\]

其中 \(g_0\in[0,1]\) 为预先约定的简单药水代理特征，\(\alpha,\beta\ge0\)。本式使每次胜局回报高于死亡，但**最大化其期望并不保证严格优先最大胜率**；小胜率下降可能被胜局资源收益抵消。因而 \(\alpha,\beta\) 是明确的风险取舍，需要冻结、报告与敏感性比较，而不是“数学上自然”的真理。

备选为词典序：先优化 \(p^\pi\)，在胜率近似等价时再考虑 \(m_H,\mathbf m_P\)；这里“近似等价”必须定义估计误差/容许区间，不能把无法区分的微小胜率差异当作确定排序。另可研究满足死亡风险约束下最大化资源，但需足够数据与校准。**v0.1 先独立输出预测，再在小范围开发数据上冻结一种清晰的训练效用**；完整跑局模型成熟后再以跨节点资源真实机会成本替代粗略常数。

对于纯“是否能获得一条完整胜路”的 SL 搜索，可先保持胜路可行性优先、随后质量优化；它与概率 NOSL 的训练目标相关但**不完全相同**。

### 5.4 正确的价值解释与 Bellman 关系

对于固定的合法后续策略 \(\pi\)，定义

\[
Q^\pi(h,a)=\mathbb E_\pi[U\mid h_t=h,a_t=a],
\quad V^\pi(h)=\mathbb E_\pi[U\mid h_t=h].
\]

若只有终局效用而无非零中间奖励，那么在扩展的历史状态下可写

\[
Q^\pi(h,a)=
\mathbb E\!\left[V^\pi(h_{t+1})\mid h_t=h,a_t=a\right]
\]

（在已经终局的转移上以正确终局效用作为边界值）。期望对**当前隐藏状态的条件分布**和状态转移求值；不能读取当前尚未揭示的 \(x_{t+1}\) 并宣称线上已经知道其价值。更一般的非零中间奖励需加当前奖励和相应折扣项。

\(V^\pi\) 评价的是**当前策略的表现，不是卡组不依赖策略的理论上限**。如果 \(\pi\) 不懂增益与多段攻击的协同，当前 \(V^\pi\) 可能准确地反映较差表现；策略探索和迭代才能改善机制兑现率。

## 6. 训练目标与最小学习算法

### 6.1 优化对象和分布

给定预登记训练根分布 \(\rho_{\rm train}\)（角色、遭遇、卡组、资源压力、版本、真实/合成来源），目标是

\[
J_{\rho}(\theta)=
\mathbb E_{\substack{x_0\sim\rho\\ \tau\sim\pi_\theta,K}}
[U_{\alpha,\beta}(\tau)].
\]

期望包含环境未知随机性、策略随机性和入场根；不同根分布产生不同最优策略。长期真实可达分布和局外分布尚未建立时，合成分布上的成绩不能被叫作自然实战胜率。

**策略从新的数学接口初始化**；N2C 15 维评分器、F3B 四战略和 LS2B StrategySpec 只作对照/可选日志来源，不能决定新模型输出空间，也不把它们作为必须模仿的教师。

### 6.2 先跑通 on-policy Monte Carlo / Actor–Critic 的最小闭环

用当前采样行为策略 \(\pi_{\theta_k}^{\rm beh}\) 实际执行合法单轨迹，记录每一步的公开观察、动作、当时 log probability、终局结果和数据资格。对正常终局，若只在终局给奖，则每步 Monte Carlo 回报 \(G_t=U(\tau)\)（若有折扣需使用统一的 \(\gamma\) 约定）。

用价值头估计

\[
V_{\psi,\alpha,\beta}(h)=p_\psi(h)+\alpha m_{H,\psi}(h)+\beta\,\mathbf w^\top\mathbf m_{P,\psi}(h),
\]

其中 \(\mathbf w\) 是定义 \(g_0\) 的固定映射。基本优势为 \(\widehat A_t=G_t-\mathrm{stopgrad}(V_{\psi,\alpha,\beta}(h_t))\)。策略梯度的一个参考估计为

\[
\widehat{\nabla_\theta J}
=\frac1N\sum_{\tau_i}\sum_{t\in\tau_i}
\nabla_\theta\log\pi_\theta(a_{it}\mid h_{it})\widehat A_{it},
\]

同时训练 \(p,m_H,\mathbf m_P\) 的监督损失。应对每条轨迹长度、角色/遭遇分层及长回合过多的样本权重作明确约定，不能因为同一根贡献大量动作就把它误当更多独立战斗。

这是**起步算法**，不是保证收敛的定理。只有使用与采样策略匹配的 on-policy 数据或正确的偏差修正，才能把上述朴素梯度解释为对应目标的策略梯度。若旧策略数据参与训练，应标注 off-policy 并采用合适方法，不得简单混在一起当作当前 \(\pi_\theta\) 采样。

可以加入熵正则维持探索、价值校准、梯度裁剪、轻量课程学习；若数据和表现证明需要，再引入 GAE、TD、PPO、Q 学习、分布式价值学习或更复杂模型。即便多输出价值头能共享状态表示，也不能假设预测头训练得好就保证策略改进。

### 6.3 冷启动和“缺少专家数据”的正确处理

无需事先拥有“最优牌序”标签；需要**可信、覆盖充分的环境交互**。随机初始化可能产生极弱策略，全死或近乎全死的数据无法有效区分动作优劣。允许从容易到中等难度的合理课程、探索策略、规则上可证明的局部效果/先后关系辅助任务开始，必要时使用不同策略交互采样增加支持，但不得把它们的动作称为最优真值。

例如“已知单段增益对后续多段伤害的规则效应”可作局部规则学习；它只证明**局部效果**，不证明该动作序列对整场终局效用最优。用真实终局评价验证训练是否提升完整 NOSL 表现。奖励塑形若采用必须分析其是否改变最优策略（可考虑合理势函数方式），并始终报告原始胜负/战后资源结果。

**循环难题的解决方式**：当前策略 \(\pi_k\) → 合法交互数据 → 价值评估 → 策略更新 \(\pi_{k+1}\) → 再采样。功能逼近和有限样本下**不保证每轮单调改进**；应冻结版本、独立评测、允许回退。局外模型暂不联合更新，以免难以区分卡组变动和局内策略变动的贡献。

## 7. 数据合同：逐动作而不是只有战斗根标签

现有 LS2A 公开经验主要是根级观测与战略候选结果；LS2B 记录策略规格执行与修复。**它们不是**直接策略训练所需的全部逐动作、合法历史数据。必须新增版本化 `nosl_transition.v1`、`nosl_episode.v1`（名称暂定）：

| 级别 | 必需内容 | 注意事项 |
| --- | --- | --- |
| Episode | root/group、游戏/求解器/编码器版本、公开初始条件、采样策略与探索参数、来源、终局资格、完整胜负和实际战后资源 | synthetic 自然可达性 unknown；每个派生根与局史祖先成组 |
| Decision | 决策序号、公开观察或可复算快照、已揭示历史摘要与记忆重构规则、当前**完整合法菜单**、所选动作实例和目标、行为策略 logp、当前步可审计前后公开状态 | 不得含隐藏 RNG、私有牌序、搜索后见结果作为输入 |
| Mechanism | CardSpec/CardInstance/效果来源/缺失掩码、合法即时预览/目标绑定、公开区域知识状态 | 规则不完整与模拟不支持须分别计数 |
| Feedback | 完整终局 W、HP/max HP、每槽药水及其它已核实资源、truncated/unsupported/error/censor 类别、风险与原生核验证据 | 只给真正完成且可信的终局赋训练终局标签 |
| Audit（隔离） | 精确根、真实 RNG、回放续体、隐藏信息、内容/代码/模型哈希、差分记录 | **不能**随模型输入序列化，也不能在推理接口中暴露 |

训练/评估时记录模型版本、固定动作空间和行为分布；如果一个根多次运行，标识相同根及 RNG/配方簇，避免训练/报告泄漏。保留完整 raw 记录并允许压缩分片、增量训练、断点恢复与崩溃重试，不得以数据压缩丢失合法动作目标及历史重构所需信息。

### 7.1 必做的信息泄漏防线

- 为每个模型输入字段提供来源及可见性审计；静态卡牌知识库可以存储公认规则，不可以在状态输入中附带该局隐藏 RNG。
- 同一公开历史但内部抽牌顺序不同的根，若当前合法菜单/公开信息完全相同，**策略 logits 必须相同**（受确定性推理及浮点容差约束）。
- 重排卡组列表、手牌实例的展示顺序或敌人列表时，在保持动作绑定的情况下，评分应满足预期不变/等变；不得依靠宿主序号“记住正确答案”。
- 公开输入不应包含同根未来 search outcome、终局标签、LS2B 修复成功等信息；这些仅用于明确资格的训练标签/研究审计。
- 终局状态已结束或当前无合法决策时，不能训练一个虚构的出牌动作。

## 8. 评估协议、消融与统计口径

**NOSL 评价最先独立于 SL。** 评估仅允许每个决策选择一次、推进一次，完整终局；同一根可以按事先约定对不同冻结策略分别执行，但模型不能在当前分支上先看另一策略结果再决策。确定性 argmax 与训练采样模式需分别报告。

主指标：可信完整终局覆盖率、完整尝试胜率与置信区间、胜后 HP（同时报告死亡）、药水剩余及类型、预测风险/unsupported 分布、每场动作/引擎 Replay、每步模型 P50/P95、根准备与完整墙钟、硬件和吞吐。不能因删去失败或仅比较胜者 HP 而产生选择偏差。对于不支持/截断样本同时列全尝试分母和合格终局分母，不能擅自把缺失计为失败，也不能只报合格子集而忽略其机制集中性。

**必须有的基线与消融：**
1. 原历史轻量规则/15 维基线（仅作冻结对照）、Card ID 直接策略、已核实静态机制直接策略、ID+机制共享表示。
2. 无关系层 vs 有条件关系层；只看手牌 vs 加入长期卡组/区域/合法历史；有无价值头。
3. 不用显式端口监督 vs 输出/防御/运转辅助（后续）；同容量/训练样本/计算预算。
4. 随机初始化到多次策略迭代的学习曲线；保持同一开放训练/选模规则、独立报告根直到冻结才揭示。
5. 后续同预算 NOSL 引导 SL vs 冻结 F3B/F4、LS2B 结构化提议；报告首胜 Replay、完整重建、资源优化与端到端成本，**预测研究搜索不能冒充合法在线 SL**。

至少按角色、幕、遭遇/敌人机制、卡牌组合、N2E 完整性、HP/药水压力、根来源分层。除了未见随机种子，还要留出**未见组合及真实局史祖先**。旧 LS1/LS2A/LS2B 报告数据已经被开发者观察，不能重新命名为新盲测。用根/构筑家族/局史/成组 seed 的适当簇级方法讨论不确定性；状态、动作和同根重放不是独立样本。

特别的机制验证集应覆盖：增益→多段顺序及其反转（斩杀/费用/致死情形）、抽牌/能量先后、目标选择、多目标、重复卡、手牌溢出与选择、消耗/生成、动态费用、公开牌堆已知/未知、长回合和药水。局部规则对照能验证模型**有能力表达**某种机制关系，但不等于完整策略已在训练后学会并泛化。

## 9. 端口化与局外价值：研究方向而非三维硬瓶颈

将输出 \(A\)、防御 \(B\)、运转 \(R\) 视为具有视野和策略依赖的能力描述 \(P_\tau(D,h,\pi)\)；它们交互且并非静态三分。可选辅助任务如期限内输出、关键回合生存风险、抽牌/能量可达性，须先定义量纲、可见性及监督来源，不得自造“输出 80 分”伪标签。

首轮**不强制实现端口预测头**。若未来有可验证时序标签，再比较是否改善跨机制/构筑泛化；模型内部保留比三个分数更丰富的状态。三端口不是胜率/HP/药水三个结果价值头。

局外 \(Q_{\rm run}\) 使用共享机制知识，但在未来遭遇分布、地图不可回退、药水/HP 机会成本下独立评价加牌、跳过、升级、删牌、路线等。先冻结局外分布研究中的战斗策略版本，再逐步交替改进；不要因新策略只在合成根中改善某些平均战损，就宣称未来整局通关率提升。

## 10. 与历史工程的连接、缺口和实施入口

现有可复用且需诚实标记的成果：
- **N2E**：22 张已受测卡、44 个基础/升级版本；18 张在本版静态机制描述范围，4 张保留显式缺口。身份/机制与合法实例绑定有基础，但不是全游戏机制语义完备。
- **N2A 系列**：部分公开决策点、菜单绑定、单轨迹与原生抽查。需要扩展状态区域/历史/复杂选择、真正的逐步训练样本合同。
- **LS2A**：1,031 个去重根（986 合成、45 从 15 条第一幕原生局史恢复）；448 个实际卡 ID，但机制编码不等于全部覆盖；低成本 530 条路径出现预测不支持。规模化根/作业/存储可复用，**不能**当作高质量 NOSL 行动专家集。
- **LS2B**：40 个独立合成报告根的 128/256 Replay 下学习臂与冻结基线各 6/7 胜；可组合阶段和修复产生新实际行动路径，但总体胜率/成本未改善。StrategySpec 是对照、经验生成与诊断来源，**不是新直接策略的教师真值或输出空间**。
- **CombatSolver 与 F3B/F4**：可信预测后端及研究侧搜索工具；初期不修改生产默认。已知目标类型、选择边界、敌方终局生命周期等风险须保留资格。

建议新工程代号 **M1-NOSL3A（暂定）**，以最小实用训练闭环为目标，而非一次完成全局智能。依次交付：

1. `nosl_observation.v1` 与 `nosl_transition.v1` 的公开字段/缺失掩码及严格菜单绑定；字段来源审计和不泄漏测试。
2. 小型**从新定义的策略结构初始化**的 ID/机制双通道、分层卡组-手牌-环境编码与动作实例策略头；实现确定性 NOSL 单轨迹和冻结基线比较。
3. 多输出价值头、可复现的 on-policy 训练/评价循环；仅使用合格正常终局训练终局标签，记录 censored 比例与机制族差异。
4. 至少一次数据采集 → 训练 → 新策略 → 独立单轨迹评估，并报告负面结果、训练稳定性及推理成本。没有足够可训练轨迹时先修资格/采样，不要求凑出正收益。
5. 有限的结构消融：ID、机制、条件关系、历史/长期卡组输入；端口辅助、复杂 RL 和在线 SL 控制后续另行论证。
6. 保持可关闭、可版本化；现有 F3B/F4 生产路径和 LS2B 冻结证据不因原型变化。

暂不建立“不先训练出达到 X% 胜率就不能进一步实现”的硬门槛，但**不得把没有观测到的泛化/效率收益写成已实现**。先验证数学对象、完整训练闭环和独立测量，然后按数据与计算实测决定扩张策略网络或模拟覆盖。

## 11. 关键风险和可以推翻的假设

| 假设/风险 | 为什么可能失败 | 如何证伪或处理 |
| --- | --- | --- |
| 条件关系网络有增益 | 普通静态效果已足够，Attention 只是增加延迟 | 同容量 ID/机制/关系消融，看新组合胜负和延迟 |
| 三端口辅助有增益 | 人工分组与时序真实需求不一致 | 定义真实可测目标并消融；无优势可撤掉辅助头 |
| 从零 on-policy 可学 | 早期全死、奖励稀疏、动作/根相关、覆盖偏差 | 训练曲线/梯度与中间反馈检查，难度课程和合法机制辅助 |
| 多输出价值可校准 | 样本稀少，胜局 HP 选择偏差，药水类型价值未知 | 校准/分层，胜利加权目标，先报告分开输出 |
| NOSL 能加速 SL | 在线推理与重复前缀可能抵消搜索预算 | 端到端配对比较，含建根、F4、模型调用 |
| 研究侧数据能外推到正常 SL | 离线隐藏 RNG、合成不可达根、预测未覆盖 | 模式分离，真实局史与合法重试资格，独立原生差分 |

## 12. 本规范的版本与变更纪律

原则性约束（信息边界、合法动作、规则/结果资格、策略与价值的数学对象、真实终局评价）若需变化，应在文档记录**问题、反例、替代模型和实验依据**。网络尺寸、融合方式、价值参数化、效用权重、RL 算法、端口辅助及实验预算属于可调实现选择，不必为了与 v0.1 保持一致而牺牲性能。

本规范与 [NOSL–SL 总架构](research-port-aware-nosl-sl-architecture.md) 配合使用：总架构定义系统职责和长期方向；本文专门约束 **NOSL 学习模型的数学对象、数据和首轮可执行验证**。当前实际完成进展始终以 [PROJECT_STATUS.md](PROJECT_STATUS.md)、冻结实验报告、代码及测试结果为准。
