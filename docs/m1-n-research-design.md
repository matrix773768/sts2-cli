**完整研究设计 · M1-N v1 · 2026-11-25**

建议仓库路径：`docs/m1-n-research-design.md`。配套基础文档：[M1-SV v2：搜索与分布价值学习](m1-sv-research-design.md)。本稿整理近期从计算预算、现有网络审查、Stockfish 式评价，到敌人机制、牌组能力和理想牌序搜索的连续讨论。它是研究设计与决策记录，不是新实验完成报告。原 M1-SV 文档不作替换。

项目：`matrix773768/sts2-cli`，分支 `port/v0.113.1`，STS2 v0.113.1（Build 26660232）。历史学习基线为 CombatSolver 0.51.5-iik.3b；新模拟后端研究冻结于 CombatSolver 1.0.2（上游提交 `131d10ae4499b56332787af61fe4a9306e65860f`）。当前主要讨论单人 Ironclad 战斗，长期目标仍为完整跑局的超人胜率，包括局外选牌、路线、商店、事件与资源管理；先研究 NOSL，保留 SL 与 Oracle 的独立定义。

## 摘要

DC2B 的持续学习出现收益递减，不能仅靠增加训练代数或搜索预算解决。近期形成的新方向是以 Stockfish 式架构为目标：规则直接提供基本机制，搜索计算复杂战术与潜在运转结构，学习型评价器承担难以精确计算的长期战略判断。人工设计机制语言和必要派生特征，但不试图穷举所有可能的战略交互，也不将所有原始信息压缩为少量手工难度评分。

敌人侧利用确定性或条件确定性行动规则，保留攻击段数、完整行动循环、条件转换、持续效果和资源干扰，构建随时间变化的需求描述。玩家侧利用合法可达集合，研究即时能力、常态运转、成长和启动难度。双方的时间结构、资源约束及机制交互共同决定局面价值。

新提出的核心模块是**理想可达性搜索（Ideal Reachability Search）**：在公开信息允许的可能牌序中主动选择有利结果，寻找协同、生产性循环、有限爆发和无限的潜力见证；再恢复实际随机分布与生存约束，研究启动概率、成本和实战收益。潜力不等于真实可达性，更不等于 NOSL 行动价值。该路线可以与 SV2 共享随机边界基础设施，并有望成为从战斗研究走向局外构筑评价的工具。第一批 N2A 实验不训练网络，先验证机制与搜索证据是否可靠。

# 第一篇　问题重定位与设计原则

## 1. 为什么调整研究重心

M1-SV 已确立“战术由搜索解决，战略由价值网络解决”。此前主要通过完整确定性回合搜索、行为条件 V/Q 分布和蒙特卡洛终局经验推进。近期 HotKernel 使局部搜索成本有望显著降低，提供了重新审视搜索与学习分工的机会，但微基准吞吐不等同于实际公开信息搜索、特征计算及神经网络推理吞吐。

历史证据：SV4A 固定 G0 加入搜索后，确认集从 453/512 胜增至 464/512 胜，共同胜局 446 根平均少损 7.95 HP；两代搜索路线继续训练均为 464 胜。DC2B 固定开发集 G0/G1/G2/G3 胜场分别为 250/264/266/264（分母 512），显示近期新增收益较早期减弱。G3 是已有阶段性检查点，不是最终最优模型。这里的数字是此前报告和阶段记录，非本稿新跑结果；不同实验使用不同根分布与效用，不宜横向直接比较。

用户认为计算预算分配不是当前整个问题的核心，自己难以判断这类工程优化，愿将其交给技术研究；当前更希望研究学习收益下降与网络设计。自适应搜索仍然有价值，但暂不作为主要理论主线。

需要区分的潜在瓶颈：

- **信息缺失**：编码后的状态无法区分本应采取不同决策的公开局面。
- **表示与容量**：实体压缩、关系结构及模型规模可能限制函数逼近。
- **监督不足**：实际选中动作的终局不能直接提供同状态未选动作的反事实排序。
- **续策偏差**：弱策略的终局分布不等于最优策略价值，采样量增加不必然消除偏差。
- **经验分布与计算**：训练构筑、难度、策略覆盖和搜索视界不一定适合困难机制。

这些是并行假设，不是已确认的因果排序。不能由平台期直接推出网络太小，也不能以训练 NLL 的降低代替实战改进。

## 2. Stockfish 式设计哲学

用户明确希望构建更接近 Stockfish 而不是 AlphaZero 式的系统：精心设计领域表示与搜索，利用神经网络而不依赖它从头学习全部游戏知识。这是架构侧重点，不是声称 AlphaZero 没有人工设计或 Stockfish 不依赖深度学习。STS2 也不是敌方主动最优化的双人零和棋类，不能机械照搬 minimax 或 alpha-beta。

形成的分工原则：

1. 游戏规则可精确提供的知识直接提取，不为学习这些规则重复生成大量标签。
2. 短期、具体机制交互通过模拟与搜索计算；搜索输出应包括可达方案及可验证见证，而非只有最高评分。
3. 只有难以低成本计算的长期取舍、风险、泛化和经验判断主要交由学习型评价器。
4. 人工定义机制语言和研究问题，而非人为穷尽所有机制组合、固定战略权重或构筑类型。
5. 网络不能仅凭预测硬剪枝合法路线；搜索或近似失败不等同于机制不存在。

建议模块划分：

| 模块 | 责任 |
| --- | --- |
| HotKernel / 原生规则 | 执行状态转移、触发、合法菜单和终局 |
| 机制提取器 | 暴露可公开获得的实体、规则、依赖、时间及条件结构 |
| 派生特征计算器 | 计算低成本的压力、资源、概率和敏感性指标 |
| 战术与潜力搜索器 | 搜索可行结果、理想运转、随机可达性和实际交互 |
| 学习型评价器 | 评价长期战损、胜负、资源与战略取舍；泛化已发现结构 |

机制提取器只负责语义描述，不能发展成第二套独立游戏模拟器。优先复用 HotKernel 已有编译规则、状态机、字节码和执行接口。机制表示应与具体神经网络解耦，允许之后替换线性模型、MLP、实体 Attention 或其他架构。

## 3. 信息规则与研究边界

沿用 M1-SV §1、§9、§14、§22–24。$s$ 为内部完整状态，$h$ 为合法公开历史，$b_h$ 为条件隐藏状态分布。未知牌序、RNG、未公开的随机结果可用于内部模拟与复现，但不得作为 NOSL 决策输入。

**用户确认的游戏前提**：STS2 所有敌人行动均为确定性或条件确定性，不存在敌人意图本身的随机性；常见 2–4 回合循环，满足特殊条件时可执行一次性特殊行动。直接接受该前提，不为敌方行动凭空引入随机模型。玩家行动可能改变状态和后续确定性规则，因此“未来意图已知”表示完整条件规则可知，不意味着任何分支都共享一条不变的实际未来轨迹。未知抽牌、随机塞牌位置、生成、随机目标、其他真实随机效果仍须处理。此处并非全敌人代码重新认证；若发现游戏规则反例再按证据修订。

NOSL 可以使用敌人公开规则推出的未来意图、当前已知牌顶、公开牌堆组成和合法历史；禁止用真实私有未来决定动作、打分、生成特征或训练部署目标。SL 可使用此前实际尝试合法得到的信息；Oracle 使用固定私有未来；理想牌序研究主动选择公开条件支持集中的假想结果，另行标记，不与普通 Oracle、NOSL 混淆。

研究遵守 prediction_only 的既有决定，不重新引入逐条严格 L3 认证；专项见证需要验证合法性、相关资源及实际胜负，可对新机制作定向原生对照，不要求恢复全量审计。截断、unsupported、未完成与死亡分开。既有训练、开发、封存分组仍须保持隔离。

# 第二篇　现有网络审查与新的学习原则

## 4. DC2B 实际网络结构（源码审查）

依据当前分支的 `experiments/m1-pre1/features.py`、`network.py`、`experiments/m1-sv3a/sv_model.py` 和 `experiments/m1-dc2b/{value.py,fit.py}`。当前模型沿用 PRE1 SharedEncoder，SV3A 历史模型 322,154 参数，DC2B 更换输出头，不能把历史参数数目直接当作 DC2B 精确总数。

卡牌使用 ID embedding（24 维）、附魔/affliction 符号 embedding、实例特征及静态机制表独立编码到宽度 96；敌人、玩家、历史也分别通过 MLP。牌区为 deck、hand、discard、exhaust、candidates；每个区先聚合：

$$z_R=\frac{\sum_{i\in R}e_i}{\sqrt{\max(1,|R|)}}.$$

敌人也以类似方式聚合。之后仅对玩家、5 个牌区、敌人组、历史共 8 个 token 进行两层 Transformer Encoder（4 heads，宽度 96，FFN 192），取玩家 token 为全局状态向量。动作由引用的手牌、待选牌、目标敌人及动作数值编码，再与同一个全局状态向量拼接。动作不是独立的实体级上下文 Attention。V/Q 均追加 12 维行为策略身份 embedding。

DC2B 保留 D2 编码器和 V/Q 中间层，重新初始化末层。输出是死亡独立一类及 87 个带符号未来净 HP 损失代表值（合计 88 类）。正常 HP 线性损失、高 HP 混合惩罚及既有死亡效用仍见 DC2B 报告；评价时将过去累计净损与未来分布结合。新设计不默认改写效用。

训练采用实际终局标签 $Y$：

$$\mathcal L=\tfrac12[-\log p_V(Y\mid h,\pi)-\log p_Q(Y\mid h,a,\pi)].$$

Q 仅监督实际执行的动作。实际训练与部署的续策存在差异，且不同历史策略使用不同身份条件。保留原有数据、权重与协议，不能把新的机制辅助任务混入历史实验而改变其含义。

## 5. 目前可确认的输入与表示局限

- 敌人输入包含 HP、格挡、攻击总值、攻击段数、当前意图类别及部分状态，但无敌人 ID 或完整未来行动规则。用户希望学习机制而不是背诵 ID，故优先补充完整条件规则，而非把 ID 当作主要解法。ID 可作为规则查找键或必要诊断，不应代替语义。
- 玩家与敌人的显式 Power 仅力量、敏捷、虚弱、易伤、脆弱五类；其他公开机制部分可能由预览间接体现，不能假定完整保留。
- 公开历史为三种时间尺度的 24 维指数加权摘要，主要记录汇总和少量特定牌信息，不是完整可用于恢复信念的历史。牌堆/牌顶应按实际公开可知性保留，不可将私有顺序编码进特征。
- PRE1 静态机制表仅保留前四个有序效果槽位并有 partial/overflow 标记；不是完整可执行规则。未表达机制要明确标注，不能默认无效。
- Attention 之前已完成牌区求和压缩；卡牌的上下文相关表示与动作对实体的选择性访问能力可能不足。

设 $X=f(H)$ 为特征，目标 $Y^*=V^*(H)$。平方损失下，若信息压缩造成价值相关差异不可区分，则

$$\inf_g \mathbb E[(Y^*-g(X))^2]=\mathbb E[\operatorname{Var}(Y^*\mid X)].$$

对于分布价值，信息丢失也可能使不同局面只能被表示为混合分布。增大模型无法恢复没有进入输入的信息。敌人未来成长不同而当前 HP/攻击相同是典型假设例子；目前尚未测量真实特征碰撞的频率或影响。

## 6. 候选架构与监督审查

原模型的集合求和结构并非理论上不能表达交互，但在有限维压缩下的学习效率和归纳偏置未验证。候选方案包括：每张牌及各敌人、Power、未来行动独立 token，先交互再聚合；或动作作为 query，通过 cross-attention 读取不同状态实体；或机制/资源依赖图的关系 Attention、GNN。必须保留明确的时间关系、目标和触发条件。Attention 权重本身不保证可解释或等价于真实规则。

模型规模没有先验答案。此前讨论的宽度 96/192/256、层数 2/4/6 只是候选容量档，并非确定配置。由于 Stockfish 式分工，线性模型或浅层 MLP 也值得与更复杂网络比较。模型需要同时考虑离线预测质量、同根实际对局能力、特征计算与推断成本，以及同墙钟搜索性能。不得只因更复杂就采用。

在固定策略 $\pi$ 下，标量价值可分解为 $Q^\pi(h,a)=V^\pi(h)+A^\pi(h,a)$。终局监督可能先学会容易的共同状态价值，而相对动作优势仍不准确；未选动作缺少标签是关键限制之一。分布预测改善与动作排序改善分开验证，必要时构造共同续策下的合法反事实对照，不能把弱教师的选择当唯一正确标签。

建议的控制变量比较：N0 冻结 DC2B；N1 保持主体结构但提供补充机制信息；N2 同信息下浅层 MLP；N3 同信息下实体级关系网络。阶段编号 N0–N3 在此仅代表候选对照臂，与研究阶段 N1A/N2A 不混用。先隔离输入变化，再比较结构/容量，再比较监督方式；参数量与训练预算、数据和随机种子需记录。当前没有完成容量或结构消融。

## 7. 固定设计审查流程与协作方式

用户有较强数学与游戏机制判断能力，但深度学习知识较少，希望避免因架构问题发现过晚而走弯路。采用问题驱动的研究方法：每次重要设计先写出数学对象、输入、前向计算、监督目标、信息边界与误差来源，再交由 Codex 实现。用户提供高手视角的反例、机制与战略差异；ChatGPT 负责抽象、理论、设计、对照和验收；Codex 负责工程实现与测试。重大设计可安排独立的反例审查，不以 AI 自审替代实证。

| 审查项 | 必须回答的问题 |
| --- | --- |
| 信息充分性 | 应采取不同决策的状态是否可能被编码为同一个输入？ |
| 任务必要性 | 哪些知识可直接读取、计算或搜索，不必再学？ |
| 监督可识别性 | 标签是否足以区分目标行为及反事实？ |
| 归纳偏置 | 结构是否适合集合、顺序、关系与条件规则？ |
| 误差诊断 | 怎样区分信息、容量、优化、覆盖、续策偏差？ |
| 实际收益 | 是否通过独立机制诊断、冻结根及成本匹配的实战检验？ |

随项目补充条件期望与统计学习、函数逼近和泛化、embedding/集合网络、Attention、损失与梯度、强化学习/策略迭代及消融方法；不要求先完成通用深度学习课程才参与项目。每个新任务先做小规模诊断，不以训练损失单独作为开启大规模下一代经验生产的依据。

# 第三篇　N1：敌人机制化评价

## 8. 简单敌人的需求侧模型

先考虑单敌人、周期性攻击/格挡/强化，无阶段切换及其他触发。记录 HP $H$、当前格挡、Power、周期长度 $T$、相位及完整行动序列。令 $d_t$ 为从当前相位起，在规定干预协议下的潜在攻击压力，$m_t$ 为攻击段数。该序列是条件预测，不是假定玩家后续行动不改变敌人。

可直接计算平均、峰值、最低压力、标准差、非攻击回合比例和集中度

$$\bar d=T^{-1}\sum_{t=1}^T d_t,\qquad C_d=\sum_{t=1}^T\left(\frac{d_t}{\sum_j d_j}\right)^2,$$

其中 $C_d$ 在总伤害正时定义，范围 $[1/T,1]$。这些摘要可辅助但不能替代序列。以下均为假想敌人，平均每回合伤害均为 15：

| 周期伤害 | 类型 | 峰值 | 战术差异 |
| --- | --- | --- | --- |
| (15,15,15,15) | 持续输出 | 15 | 持续防御与输出竞争 |
| (0,0,0,60) | 周期爆发 | 60 | 安全窗口与爆发前斩杀期限 |
| (30,0,30,0) | 间歇攻击 | 30 | 交替资源需求 |
| (45,5,5,5) | 前置爆发 | 45 | 初期生存与启动压力 |

定义累计潜在攻击 $P(n)=\sum_{t=1}^n d_t$。假设玩家先行动、固定每回合输出25、敌人100 HP、无格挡与成长，则第4回合先手斩杀：持续型此前攻击45，末回合爆发型此前攻击0；若错过第4回合则后者突然增加60压力。称这种离散窗口为**关键击杀期限（kill deadline）**，不是连续平均输出能完全表达的现象。真实可承受战损需结合玩家格挡、敌人状态及后续行动。

格挡应保留产生时机、持续/清零规则和实际有效量，不能简单将周期格挡总数累加为有效 HP。攻击压力窗口与输出机会窗口可能重合或错开；何时成长、何时输出依赖双方资源。单敌人的抽象不直接适用于多敌人分摊、召唤和目标优先级。

## 9. 成长、攻击段数与条件敏感性

若每周期末永久增加 $g$ 点力量，第 $i$ 个回合的攻击为 $m_i$ 段，每段初始伤害 $b_i$（忽略截断、虚弱及其他修正），第 $k$ 周期为

$$d_{k,i}=m_i(b_i+kg),\qquad D_k=D_0+kg\sum_i m_i.$$

周期增量 $\Delta D=g\sum_i m_i$，前 $K$ 周期累计潜在压力为

$$P_K=KD_0+\frac{K(K-1)}2\Delta D.$$

例如初始周期40伤害、每周期+2力量，每周期2段攻击的增量为4，每周期8段攻击则为16。战斗延长的代价取决于双方成长能力，而非只看敌人成长。

用户的关键反例：总伤害60的单段60与四段15，普通格挡通常等效，但减力量、每段触发、无实体、反伤、单次伤害上限等机制可能截然不同。忽略其他修正时，降低3力量分别减少3和12伤害。无法穷举全部交互特征；人类掌握一般机制再应用，而不是记住所有组合的评价权重。

更一般地，定义规定协议下的有限差分 $S_t^{\mathrm{Str}}(x)=D_t(x)-D_t(x-e_{\mathrm{Str}})$，表示未来第 $t$ 回合对力量减少的敏感性。可推广至其他属性、资源或约束，通过模拟按需计算。人工扰动可能不对应合法行动，因此只作辅助特征或诊断，不直接视为真实行动收益。实际行动比较要保证合法续策和同评价视界，保留全部相关结果。

典型跨回合案例（用户提出）：本回合可将弃牌堆中的减力量牌放至牌堆顶；敌人下一回合多段攻击，故本回合牌顶控制可能产生远高于普通情况下的价值。规则给出未来行动、牌顶控制和减力量效果；搜索发现合法跨回合协同；评价器衡量本回合放弃其他行动的机会成本及更长期价值。应列入标准诊断案例，不把它简化为固定牌序优先级。

## 10. 从固定指标转向机制语言

保留三类互补信息：原始机制结构（完整尽可能保留），低成本派生统计（辅助归纳），动态模拟结果（按具体局面计算）。不把第二类作为唯一输入。机制依赖图是候选表示：卡牌效果修改属性，属性影响伤害/费用，事件触发额外效果，未来行动和玩家需求建立时间关系。它与 M1-SV §4 动态行动关系图相通，但推广到整个战斗系统。

初步基本单元：Damage（值、段数、目标、修正与事件）、Block、ModifyPower、MoveCard、Draw、Energy、Trigger、Condition、Transition、Repeat。应复用现有规则语义，不预设这个列表完整，也不强制复杂机制只能归入一个类别。卡牌、敌人、Power 和遗物尽可能共享基本机制语言。

敌人行动规则适合用有限控制状态加动态寄存器/条件转换表示：当前行动节点、可达下一节点、攻击及效果、条件表达式、一次性标记、特殊阶段。假想例子为攻击20→格挡15→攻击8×4→力量+3→重复，其三周期未干预攻击分别是 (20,0,32,0)、(23,0,44,0)、(26,0,56,0)。HP 阈值触发等规则需要在不同玩家行动分支中更新。无限长未来无需预先铺开，完整规则加有限视界展开即可。

## 11. 持续效果、触发事件与结算顺序

属性当前值与属性未来演化规则分离。敌人力量从5降为2可能是永久减少3，也可能在某事件后恢复3；相同当前值并不代表相同未来。持续效果至少记录作用对象、属性/机制、操作、生效条件、结束条件及结束行为。结束条件可以是回合边界、特定事件次数、状态阈值或其他规则；不只使用整数 duration。还要保留效果叠加、优先顺序、消耗方式及有影响的计数器，具体语义由原模拟器确定。

按机制性质可区分属性、修正、触发、替代、条件，多类可重叠。四段攻击不仅是四个数，也是按顺序发生的结算事件；首次受击减伤、每段反伤、攻击者提前死亡等都可能改变结果。示例中的“第一次受击最多减20”仅为假想机制：单段60减20，四段15减15。实际游戏事件顺序不凭概念图推定，必须读取与验证现有模拟实现。

实现分工：机制描述器暴露依赖与时序，HotKernel 执行真实规则；模拟器可以提供 $F(s)$ 与合法动作后 $F(F_a(s))$ 的对比，记录 HP、敌人 HP、成长、牌区、持续资源等变化。禁止以局部 HP 差代替所有机会成本；未知随机结果应走条件分支而非读取真实未来。

## 12. 资源干扰与牌组污染

敌人不只消耗 HP，还会改变玩家未来资源供给：塞牌、增加费用、限制出牌、阻止额外抽牌、施加虚弱或脆弱等。其危险程度取决于所影响资源是否恰好是该构筑的瓶颈，不能给每个敌人固定难度。

简化均匀洗牌模型：原有 $N$ 张有效牌，混入 $m$ 张无效牌，不放回抽 $k$ 张，则期望有效牌为 $kN/(N+m)$（$k\le N+m$）。若需要同时获得 $r$ 张指定不同实例（$r\le k$），

$$P_r(N,k)=\frac{(k)_r}{(N)_r},\qquad \frac{P_r(N+m,k)}{P_r(N,k)}=\frac{(N)_r}{(N+m)_r}\approx\left(\frac{N}{N+m}\right)^r.$$

最后近似在 $r$ 相对牌组大小较小时使用。它提示高阶组合可能对污染更敏感，但不是实际启动成功率公式。重复牌、已知牌顶、牌序相关触发、额外抽牌和选择权必须由合法信念与搜索处理。相关抽牌公式继承自 M1-SV §9、§23。

塞牌位置与时间很重要：手牌可能立即影响，抽牌堆影响近期供给，弃牌堆通常在洗牌后影响。若在其生效前结束战斗，某些长期污染没有实际代价；可称为污染生效期限。状态牌可能有自耗尽、主动移除、抽到/打出/保留触发、手牌占用和正向协同，不能一律赋负值。薄牌组和厚牌组的影响也非无条件排序。

把牌组视作资源流动系统：抽牌堆、手牌、弃牌堆、消耗堆（以及能力牌等实际区域），通过抽牌、出牌、回收、洗牌、耗尽、生成流动；能量、抽牌、可用手牌、行动次数、HP 等资源相互转换。普通攻击和防御竞争能量；抽牌可能扩展选择，加能量增加行动预算，成长以当前资源换未来收益，耗尽改变牌组循环质量。敌人干扰修改这些资源约束。

在规定战术目标 $g$ 下，可用 $M_E(h,g)=J_g(h;E+1)-J_g(h;E)$ 研究额外能量的局部能力增量，同理研究额外抽牌或出牌上限。目标、合法性、视界和随机协议必须明确。此类反事实扰动用于识别资源瓶颈，不等同真实行动价值。

# 第四篇　N2：玩家牌组能力与理想搜索

## 13. 需求与供给的联合评价

敌人的确定性机制描述时间上的资源需求；玩家牌组提供随机、可控、相互竞争的资源供给。研究对象不是孤立敌人难度或静态牌组强度，而是二者的时间匹配。

玩家能力分四个维度（研究概念，不是已确定的四个输出头）：

- 即时能力：当前手牌及资源下的合法可达结果。
- 运转能力：正常抽牌、能量、费用与循环下的资源供给。
- 成长能力：持续机制使未来可达结果如何变化。
- 启动能力：进入高效运转状态的时间、成本、风险与稳定性。

从当前回合、未来1–2回合、一个洗牌周期、多个循环到启动后，评价时间尺度不同。速攻、稳定、成长、启动爆发等只是示意曲线，不是需要人工分类并记住的固定流派。玩家成长可超过敌人成长，因此长战斗并不总是坏事。

## 14. 以可达集合表示能力，而不是独立极值

继承 M1-SV §6、§7。当前合法行动计划的可达结果集合 $\mathcal R(h)$，保留输出、防御、HP、成长、资源、牌区变化等联合结果与见证。例：两张1费10伤害、三张1费8格挡、3能量，可达到的二维非支配结果 (0,24)、(10,16)、(20,8)，不能同时达到单独最大输出20与最大格挡24。二维前沿只在简化假设下成立，不是完整游戏的安全剪枝。

在明确此前续策及未来时间边界的条件下，下一回合手牌 $X$ 随机，可达集合 $\mathcal R(h,X)$ 也随机。若所有后续结果在相应节点合法可见且只要求已观察手牌的确定性区域能力，可以定义

$$\Pr\{\exists y\in\mathcal R(h,X):D(y)\ge d,\ B(y)\ge b\}.$$

该量表达输出与格挡同时达标的机会，不是某固定策略的实际达标率。如果尚有未知结果，需要使用 M1-SV 的非预知目标可达概率，不能先对每个完整隐藏世界找最优路线再平均。实际联合目标应包含生存、成长及持续资源；不同目标的最大可达概率未必由同一策略实现。

## 15. 启动：理论上限与实际到达成本分离

用户提出：CombatSolver 已能搜索出无限，因此让搜索器自由探索理想牌序，先发现当前牌组的理论潜力，再根据真实牌组判断达成难度。这是 N2 的核心新思路。高 HP 课程仅放宽部分生存压力；理想牌序进一步放宽随机约束。两者不可混为一谈。

设 $G$ 是经过验证的候选高效运转状态集合（而非人工定义的流派标签），首次到达时间

$$\tau_G=\inf\{t:H_t\in G\}.$$

学习对象可以是 $\Pr^\pi(\tau_G\le T,\tau_G<\tau_{\rm death})$ 及启动前损失、耗时、启动后收益的联合分布。需指定时间单位与终止条件；胜利早于启动也要作为独立结果，不算强行启动失败。对理想搜索发现的一个具体状态或见证，可先定义严格的小范围目标，然后研究是否能够安全推广为更一般的启动集合。

999 HP 可以让模型在较少生存约束下探索启动后的行为，但不保证学会80 HP下的安全启动，且 HP 改变可能影响机制。应区分牌组不存在已发现强运转、潜在运转难以启动、以及当前策略不会启动三类情况；有限搜索不能证明第一类不存在更好方案。

## 16. 理想牌序搜索的数学定义与信息边界

记 $\Omega(h)$ 为与当前公开历史一致的可能隐藏牌序及后续抽牌实现的支持集。仅在所有随机性都被放宽的理想模式中，可写成

$$V_{\rm all\text{-}ideal}(h)=\sup_{\omega\in\Omega_{\rm all}(h)}\sup_{\pi\in\Pi_{\rm Oracle}}U(h,\omega,\pi).$$

这里 $\Omega_{\rm all}$ 包括全部允许的随机实现。对于本研究优先考虑的**仅理想牌序**，其他真实随机机制仍按原条件概率处理，不把上述全随机上确界直接当作其值。以下标量效用均假定固定，终止条件和评价视界明确。

| 模式 | 抽牌与信息规则 | 用途 |
| --- | --- | --- |
| NOSL | 未知抽牌服从真实条件分布，行动仅依赖公开历史 | 正式实际能力 |
| 固定世界 Oracle | 给定固定隐藏实现并知晓它 | 离线寻找该世界内的好路线 |
| 理想牌序 | 在符合当前公开约束的可能抽牌结果中主动选择 | 寻找潜在运转见证 |
| 全随机理想 | 放宽全部目标随机节点 | 更宽松的能力诊断，非首期目标 |

将玩家行动、抽牌及其他随机事件分为三类节点 $\mathcal A,\mathcal C_d,\mathcal C_o$。真实 NOSL 递推为终局 $U$，玩家决策取 max，所有自动随机结果取条件期望。理想牌序递推改为：

$$
V_{\rm ideal}(h)=
\begin{cases}
U(h),&h\text{ 为终局},\\
\max_a V_{\rm ideal}(h_a),&h\in\mathcal A,\\
\max_{i:p_i>0}V_{\rm ideal}(h_i),&h\in\mathcal C_d,\\
\sum_i p_iV_{\rm ideal}(h_i),&h\in\mathcal C_o.
\end{cases}
$$

抽牌结果选择仍必须尊重实例数量、费用、牌区、手牌上限、已知顶/底、条件牌序信息、实际洗牌、触发顺序及所有相关约束。不能随时重排已知牌顶，也不能凭空抽到不在可抽区域的牌。逐步选择未知抽牌需要与一个相容的牌序或条件随机过程一致，不能通过改变同一已承诺隐藏变量来取得额外收益。若洗牌后的隐藏顺序仅在普通逐张抽取时显现，可按合法条件支持集延迟决定；对于检查或移动未知牌的其他机制，需要额外追踪约束或暂列 unsupported。

若初始手牌已公开，不能回溯修改。允许理想开局手牌只能定义为另一个更早的研究根。直接控制抽牌是一种放宽随机条件的研究操作，并不是游戏合法行动；严禁将其写入部署动作菜单。

理想搜索与 SV2 共享随机边界、公开信念、分支状态、事件恢复与合法性检查。区别只是对相同合法结果集合的聚合算子。普通单抽优先，复杂顺序、洗牌、随机插入、连锁触发、其他随机机制按明确支持范围分步实现。数学上的 max 与 expectation 不应混淆；需要选择的是真实可实现的结果，不是把期望输出当成一次抽牌。

有限预算下的最佳已发现见证不是最优值证明；在普通确定性或所有目标随机结果已经合法指定的路径上，可验证见证是相应潜力的下界证据。若仍有未放宽随机性，一条成功轨迹只证明存在性，不直接给出期望价值下界；需要合法续策及其期望评价或严格界。对无终止的循环应设研究视界、资源目标及退出条件，不能把无限循环本身作为战斗胜利。

## 17. 无限、近似无限与生产性循环

无限不必由神经网络从普通经验中偶然学出，也不需要先枚举所有流派。将其看作资源再生产结构：一段合法行动消耗资源、补充资源、恢复关键牌或运转条件，并产生额外输出、格挡或成长。

| 结构 | 含义 |
| --- | --- |
| 空循环 | 恢复运转状态，无有意义收益 |
| 生产性循环 | 恢复或保持必要资源，产生有效收益 |
| 消耗性循环 | 可重复有限次数，某一必要资源不断耗尽 |
| 确定性无限 | 启动后在所述规则范围内可重复，不依赖未知随机结果 |
| 条件性循环/理想无限 | 后续必须满足随机条件，理想模式可以选择，真实成功率待测 |
| 近似无限、有限爆发 | 有资源或规则上限，但可能已足够击杀当前敌人 |

例如若循环需要1点启动能量，每次净耗1、产生20伤害，初始3能量可执行3次；净能量为0或正时，仅能说明能量不构成这一例子的上限，还需要证明其他条件不恶化。有限敌人 HP、行动计数、阈值、强制结束、封顶和模拟器安全限制都可能使数学无限并非实际无限。反复依赖特定随机结果的理想路径不等于真实概率为1的无限，甚至无限次成功概率可能为0（例如独立每次成功率固定小于1）。

我们最终需要优化真实战斗效用，而不是追求无限标签。只要有限路线已能无伤击杀并满足资源目标，其实际价值可以与理论无限相同。

## 18. 从搜索路径提取循环见证

普通 CombatSolver 主要返回高质量路线；N2A 希望同时发现可迁移的运转结构。多条路线共享抽牌、加能量、回收等机制时，可提取共同候选结构，但共现不能证明必要性或因果性。

将完整状态形式化为 $s=(x,y)$，$x$ 是维持某循环所需状态，$y$ 是产生收益的相关变量。候选投影 $x=\phi(s)$，某段动作 $p$ 满足

$$ (x,y)\xrightarrow{p}(x,y+\Delta y),\qquad \Delta y>0 $$

（$y$ 采用收益为正的符号约定，例如累计输出）。同样可研究能量非减、卡牌恢复或其他单调量。如果能证明未来每次仍满足合法性且相关条件不改变，可构成生产性循环的充分证据。完整 hash 通常会因敌人 HP、计数器、RNG 等变化而不同；候选投影仅用于发现潜在循环，不能作为完整状态等价、安全合并或剪枝依据。

至少记录循环前后：所有牌区实例与影响顺序的变量、实际费用及其持续性、能量、Power、遗物、事件/出牌/洗牌计数、敌人 HP 和阶段、相关隐藏约束与随机依赖、完整行动与中间状态。须检查阶段切换、计数器、触发条件、资源净变化与下次启动的峰值资源需求，不能只比较末端能量与手牌数量。

证据分级建议：候选循环（投影匹配）；有限重复见证（实际模拟验证指定次数）；当前战斗终局见证（重复直至合法击杀）；严格可重复证明（明确不变式或充分条件）。条件随机循环另标依赖，不自动晋级确定性无限。优先保存原始轨迹和前后状态，再研究自动提取必要条件；初期不强求通用循环证明器。

## 19. 关键机制、反事实与启动条件

对统一协议下的能力指标 $J$，可研究移除卡牌实例的反事实边际：

$$I(c;\mathcal D)=J(\mathcal D)-J(\mathcal D\setminus\{c\}).$$

移除或替换属于构筑干预，应重新初始化或按定义生成相容状态，固定其他比较条件及预算，不能随意从执行中删除牌后将其视为合法行动。移除牌也可能改善运转（$I<0$）。一张牌的低边际不代表无用，功能冗余和高阶协同需要成组干预；对多张同功能卡应研究资源功能而非 ID。M1-SV §5 已讨论高阶相互作用，初期不做穷举全部子集。

候选启动条件可以包括：足够的能量、关键牌位于可获取区域、阻塞牌已清理、持续 Power 已建立、敌人未触发特定限制。逐步从精确见证推广到等价启动目标；不能仅凭相关性将路径中出现的所有牌宣告为必要条件。理想搜索记录尽可能多种实际可达运转结构，不仅最高潜力路线；多个替代目标及启动方式均保留。

在真实随机条件下，目标搜索可研究 $\sup_{\pi\in\Pi_{\rm NOSL}}\Pr^\pi(\tau_G\le T,\tau_G<\tau_{\rm death})$。若实际目标是战斗最优，应比较完整结果分布，不能把启动成功率当唯一效用。对随机续策需要合法公开决策、共同协议和独立复验。理想见证路径不是 NOSL 的唯一正确动作标签。

例如某理想无限成功率30%、成功战损0、失败40，期望战损28；有限循环成功率80%、成功5、失败30，期望10；直接战斗战损18。在三者均存活且线性战损的假设下，有限循环更好。若存在死亡或非线性效用，应回到完整分布。所谓潜力—可达性 Pareto 前沿仅是候选比较框架，不能仅凭低维指标安全删除其他方案。

## 20. 用约束解除诊断学习瓶颈

建议区分实验模式（暂定）：

| 模式 | 约束 | 目的 |
| --- | --- | --- |
| R0 | 真实 NOSL 信息与资源 | 当前实际能力、公平搜索能力 |
| R1 | 固定世界的隐藏牌序已知 | 该世界 Oracle 改进机会 |
| R2 | 自由选择公开支持集内的未知牌序 | 已发现的牌组潜力 |
| R3 | R2 加高 HP | 研究启动生存约束 |
| R4 | R3 加初始资源等人工条件 | 探索尚未启动的运转结构 |

理论上固定状态/分布、目标与终止规则，在仅放宽抽牌约束且允许原策略的情况下，有 $V_{\rm current}\le V^*_{\rm NOSL}\le V^*_{\rm ideal}$。理想值与当前能力的差分解为

$$V^*_{\rm ideal}-V_{\rm current}=(V^*_{\rm ideal}-V^*_{\rm NOSL})+(V^*_{\rm NOSL}-V_{\rm current}).$$

前项是放宽抽牌随机约束的理论收益，后项是实际信息规则下的策略改进空间。R1 的固定世界值不能直接与 R0 的公开期望比较；只有在同一条件分布下汇总、且信息放宽层级确实嵌套时才有相应的期望不等式。实际有限搜索结果可能因算法、预算、覆盖而不单调，也无法直接分离这两项未知最优差距。R3/R4 修改真实资源乃至机制，仅是诊断，不承诺严格上界。高 HP 已知可能改变某些卡牌、敌人行为及效用，须逐项记录。

研究目的不是给所有失败根一个确定的不可解标签，而是发现可验证的改进空间，区分可能的牌序约束、启动生存压力、策略不足与搜索覆盖不足。与 DC1/DC2B 课程研究、DC3A 固定世界参考搜索互补，不更改此前冻结评测定义。

## 21. 学习任务与局外推广

可考虑将未来评价任务拆为三类：潜力（在理想协议下已发现的结构、收益与资源要求）、可达性（合法信息下的启动时间/概率/成本）、真实结果（胜负、带符号净战损和持续资源分布）。这不是立即确定三网络或三输出头。先验证搜索能够产生可靠、可解释、可泛化的监督，再决定哪些可精确计算、哪些应预测、哪些只用作诊断。

潜力特征或标签必须由公开状态及统一的离线研究协议生成，不依赖实际私有未来；若用于训练或部署，应明确其放宽条件、成本和有限预算覆盖。用理想结构引导真实搜索时，执行仍须依赖公开信息，不能直接蒸馏知道有利牌序的动作。真实随机分布和弱续策偏差需要独立处理，保留未发现、预算不足与不可达的区别。

局外选牌、删牌和升级是自然推广：加入卡牌可能创造新的资源循环；额外抽牌可能主要改善启动稳定性；删牌可能不提高理想上限却显著提高实际到达概率。对不同构筑变体做相同协议的潜力搜索与真实可达性比较，有机会自动发现卡牌协同与构筑结构。仍须结合自然战斗/遭遇分布、资源机会成本与后续爬塔状态；不以理想无限的存在直接决定选牌。

先调查现有牌区、洗牌、随机流、执行 scratch/choice、回放与搜索轨迹接口，查明能否在未知抽牌节点按公开约束分支。避免简单改 RNG 种子而保留真实隐藏牌序；避免通过把研究模式的未知选择混入真实待选菜单而破坏公平性。若实现需要在部分执行动作中暂停，应明确 pre-action 快照、可恢复事件序列、分支隔离、重复触发与 RNG 消耗语义，优先利用已有恢复机制。新路径对未支持机制显式返回 unsupported，不近似为普通抽牌并当作正确结果。

本轮未确认通用循环检测算法、实际受控抽牌接口、完整机制导出覆盖、数据回填成本和公开状态下性能；这些是 N2A.0/N1A 的实际技术调查事项。

## 23. N1：机制表示与诊断（建议阶段）

| 阶段 | 交付与验收 |
| --- | --- |
| N1A | 优先复用现有敌人行动状态机和机制表；导出基本攻击/格挡/成长、相位、攻击段数、效果、已验证条件和 unsupported；核对公开信息边界 |
| N1B | 先设计参数化机制诊断集，含正反例、条件反转、跨回合协同；小规模确定性夹具由合法穷举或原生规则给出参考，复杂情况标注未解决 |
| N1C | 在诊断及独立真实战斗上做特征、网络结构、容量、监督消融；保留冻结 DC2B，避免同时变更多个因素 |

诊断集最小候选：单段60 vs 四段15与减力量/一次性受击；相同平均压力但持续/爆发；同初始输出不同成长；相同周期不同相位；临时/永久属性变化；相同当前意图不同未来规则；牌顶控制与下回合多段攻击；HP 阈值一次性转换；同量状态牌进入不同牌区；不同抽牌/能量瓶颈；相同手牌不同能量时动作优势反转；直接斩杀与先成长；相同首动作不同续策。每一类区分规则计算真值、搜索可达性、策略选择标签，不把人工简化案例成绩当作完整战斗能力。

对于机制抽取与网络消融，先回答能否表达关键不同，再检验是否学会正确利用。必要时保留同一牌组/不同敌人及同一敌人/不同牌组对照，检验机制迁移而非 ID 记忆。具体根数、训练预算、容量档和阈值尚未冻结。

## 24. N2A：理想牌序与运转结构发现（首个最小实验）

本阶段不训练任何网络。目的不是建立全游戏机制语言，而是验证能否产生可靠的潜力、循环和启动结构证据。拟四个小阶段，先进行 N2A.0 调查，不未经调查即启动大规模开发。

| 阶段 | 任务 |
| --- | --- |
| N2A.0 | 调查冻结 HotKernel 的普通抽牌、洗牌、事件恢复、公开信念与循环路径导出；盘点可直接复用的上游夹具与机制表示，提出最小接入方案 |
| N2A.1 | 实现普通抽牌结果分支，在支持范围内共享真实概率模式与理想 max 模式；验证已知牌顶、重复实例、牌区守恒、事件结算、分支一致性与无隐藏信息泄漏 |
| N2A.2 | 在已知稳定无限、强有限循环、难启动构筑及普通构筑上发现、导出和验证候选运转结构；区分循环候选、有限重复和当前终局证据 |
| N2A.3 | 改变牌组厚度、关键牌/功能冗余、初始能量、耗尽/回收条件和敌人压力；比较理想潜力与实际启动可达性，记录预算/覆盖与真实战损 |

构筑数量先采用十余个小型候选，具体卡牌与预算由 N2A.0 结果后冻结，不从未解结果反向挑选成功样本。循序增加难度：A 已启动双卡核心；B 添加无关阻塞牌；C 添加耗尽/抽牌/回收，要求自主寻找启动路径；D 增加真实敌方压力。加牌并不一定破坏循环，应实际验证。另加入有限爆发、空循环、条件随机循环、计数器/阈值破坏循环、无已知循环等反例。不能把未找到循环的构筑标作已证无解。

比较建议：同一根上，固定世界普通 Oracle、理想牌序、可支持的公平条件搜索或冻结合法策略。保持终止目标、预算和效用可比；R3/R4 单列诊断，不混入主比较。记录尝试数、完整/截断/unsupported、节点/转移/时间、已发现潜力、终局、启动步骤及条件、循环重复次数、每次资源变化、随机依赖、合法重放与可迁移性。在真正公平搜索尚未完成时，使用当前合法策略估计其实际可达性，并明确这不是最优值。

最小证据记录（字段名非正式 schema）：

- 根身份、构筑实例/规则版本、公开状态与约束、模式、目标、预算、搜索算法和实际覆盖。
- 启动前缀、循环段、退出/击杀路径、动作与随机事件见证；每个阶段的状态及关键资源差分。
- 是否需要指定抽牌、支持集/概率信息（可取得时）、验证范围和失败原因。
- 实际运行时间、终局战损与持久资源；人工夹具与真实战斗分开。

成功标准不是“找到所有无限”，而是能在正例产生可重放合法见证、对反例不误报、明确解释理想与真实的区别、稳定导出足够分析的结构信息。只有这些成立后，才值得扩大数据规模或设计学习目标。

## 25. 公开信息与实验质量的最低门槛

1. 冻结代码、规则、基线权重、根分布、预算、评价协议；所有搜索模式明确独立身份。历史 DC2B 数据和封存结果不改写。
2. 使用不同真实隐藏实现但相同公开历史的配对测试；候选结果集合、理想公开特征、实际 NOSL 决策不得随未公开私有实现改变（固定内部随机化控制）。合法事件公开后才重规划。原始私有状态仅为复现/审计，不进入模型。
3. 用小型可穷举抽牌夹具验证分支完整性、概率总和、实例守恒、已知牌顶、洗牌及触发顺序。比较相同指定结果的模拟重放；特殊机制不支持则显式隔离。
4. 循环投影仅用于候选发现；验证具体完整状态、资源、计数、合法行动和终局。记录有限预算，拒绝把搜索失败当不可达证明，把单次成功当期望收益，或把理想条件当正式 NOSL 标签。
5. 真实胜率与同胜战损继续用固定根配对；随机结果概率、启动时间、资源损失和失败风险按共同协议分层。数据划分按构筑族/根及衍生关系隔离；必要时按未见机制组测试泛化。训练呈现数不当作独立样本数。
6. 速度测量分解模拟、特征提取、条件分支、网络前向、状态重建与落盘；避免用 HotKernel 单步峰值外推完整系统速度。网络增加的预测收益须与推断开销一起考察。

## 26. 与 HK/SV/DC 路线的关系及当前顺序

工程线仍可按 HK1B0 常驻热核宿主、HK1B1 高速经验生产、HK1B2/SV2 公平随机搜索推进。N1 机制表示和 N2A 潜力研究共享热核、公开状态及随机事件接口。近期自适应预算研究留作支持性优化，不丢弃原 M1-SV §24；概率加权区间宽度与单位成本缩减是启发式，不是最优预算公式，也不能把网络预测区间当严格最优价值界。

当前建议优先完成 N2A.0 技术调查，同时在 N1A 复用敌人规则导出方面做轻量调查。根据依赖决定 N2A.1 与 SV2 的共同实现顺序，避免为理想模式另建一套不相容随机系统。若热核常驻是实际运行前提，则优先完成必要宿主基础；不因此自动启动长时间 DC3A 扩展或正式评测。已有 DC2B G3 作为基线保存。暂不建议恢复大量持续学习，直到得到关于表示、监督或搜索的具体改进证据；这是研究建议，不是已经修改任务队列的操作。

与既有设计的对应关系：M1-SV §3–7 的预训练、机制交互、边际价值和目标可达性在此扩展至全战斗机制与牌组潜力；§8–11、§22–24 提供确定性搜索、随机条件与求解界；§12–16、§25–28 提供战略价值、信息规则和迭代闭环；DC1/DC2B 的难度、课程和效用继续有效。新内容重点是机制化需求与供给、理想牌序的明确放宽、循环见证及启动可达性，而非替换这些既有理论。

## 27. 开放问题与决策状态

**已明确的方向**：接受敌人条件确定性；不以敌人 ID 代替机制；Stockfish 式搜索与评价分工；人工定义基本语言而不是穷举战略指标；关注理论潜力与真实达成难度；理想搜索与正式信息规则严格隔离；先小实验再训练。

**待验证的研究假设**：机制结构能够显著改善价值/相对动作泛化；理想搜索能高效发现有用循环并转化为可达性监督；结构知识有助于突破当前学习平台期及局外构筑评价。尚未证明任何一项的正式收益。

**待解决的技术问题**：现有 HotKernel 的受控抽牌接入、条件牌序追踪及分支恢复覆盖；复杂随机事件的实际支持范围；循环候选提取及安全充分条件；机制导出在真实公开状态下的充分性和成本；历史数据能否补充新特征；公平可达性估计误差；候选运转结构的泛化与选择；模型结构/损失/容量的独立对照。

**暂未确定**：完整机制语言 schema、具体网络层数/头数、搜索预算、正式诊断集规模、训练计划及部署方式。先保存原始证据，避免过早做不可逆架构选择。下一项可执行交付为 N2A.0 的只读技术调查与最小实验方案，经审查后进入实现。
